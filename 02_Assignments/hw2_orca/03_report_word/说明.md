# HW2 报告（Word）

每道题一个 Word，最后汇总成一份交上去的 PDF。报告用英文，格式照 HW1（Letter 纸、Calibri 10.5、网格表）。

## 文件

| 文件 | 干什么用 |
|---|---|
| `HW2_Ex1_ground_state_2-chlorophenol.docx` | Ex1：四种方法的电荷、频率、偶极矩、熵、HOMO-LUMO 能隙，12 号振动模式、HOMO/LUMO、密度+静电势图 |
| `HW2_Ex2_theory_solvent_effects.docx` | Ex2 理论题：CPCM 怎么处理溶剂，ORCA 里还有哪些溶剂模型 |
| `HW2_Ex3_theory_resolution_of_identity.docx` | Ex3 理论题：RI（密度拟合）的原理和加速从哪里来 |
| `HW2_Ex4_excited_states_UV.docx` | Ex4：TD-DFT 前 5 个激发态、溶剂效应对比、UV 光谱 |
| `HW2_Ex5_...docx`、`HW2_Ex6_...docx` | 算完后补上 |
| 同名 `.pdf` | 用 Word 转出来的预览，检查排版用；最后交的是汇总版 |
| `scripts/` | 生成 Word 的脚本（见下） |

## scripts/ 里的文件

| 文件 | 干什么用 |
|---|---|
| `report_common.py` | 共用排版：标题、段落、表格、图、图注；上下标写法 `cm^{-1}`、`E_{HOMO}` |
| `hw1_style_template.docx` | 从 HW1 报告里清空正文得到的样式模板，每道题的 Word 都从它开始 |
| `make_ex1_word.py` … `make_ex4_word.py` | 每道题一个，数字全部从 ORCA 输出里现读，不手抄 |
| `docx_to_pdf.ps1` | 用 Word 把 docx 转成 PDF（检查排版用） |

## 怎么重新生成

改了计算或脚本以后（用 D 盘的虚拟环境）：

```
cd 03_report_word\scripts
D:\venvs\cm5235_hw2\Scripts\python make_ex1_word.py
```

转 PDF：`powershell -ExecutionPolicy Bypass -File docx_to_pdf.ps1 "<docx 完整路径>"`
