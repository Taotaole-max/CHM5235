## 这一讲在干什么

Lecture 02–03 把薛定谔方程削到了 Hartree-Fock。但 HF 有个系统性缺陷：**平均场近似丢掉了
电子的关联运动**。这一讲讲**怎么把丢掉的那部分能量（相关能）找回来**，以及各种方法的代价。

主线：

```
HF 能量总是高于精确能量
  ↓ 差额 = 相关能  E_corr = E_exact - E_HF
  ↓ 分成两类：静态相关（单行列式本身不够）+ 动态相关（电子瞬时躲避）
  ↓
方法 A：多组态波函数方法（往 HF 里加激发 Slater 行列式）
   ├─ CI（对每个行列式配系数）→ CISD / CISDT / Full CI
   ├─ MCSCF / CASSCF（同时优化行列式系数 + 轨道）→ 治静态相关
   ├─ Coupled Cluster（对激发"过程"配参数，指数展开）→ 治动态相关，size-consistent
   └─ 微扰论 MPn（把 H 拆成 H0 + 微扰）→ MP2 最常用
方法 B：DFT（用近似泛函描述交换 + 相关，仍是单行列式）—— 下一讲
```

## 一、相关能与两类相关（p.2–5）⭐⭐ 必考

### 定义

$$E_{\text{corr}} = E_{\text{exact}} - E_{HF}$$

*读法：相关能 ≡ 精确能量 − Hartree-Fock 能量。因为 HF 偏高，相关能是个负数。*

相关能 = **HF 理论没能正确处理的电子间相互作用**。（精确 = 非相对论薛定谔方程的精确解 = Full CI）

### 静态相关（static / non-dynamical）

单个 Slater 行列式（单一 MO 布居模式）**不足以近似基态**时出现，
常见于基态**简并或趋于简并**的情形。

- 例：**H₂ 解离**——限制 HF 给出一对离子（H⁺ + H⁻）而不是一对自由基
- 处理：MCSCF / CASSCF

### 动态相关（dynamic）

来自库仑排斥的**电子关联运动**。平均场理论天然算不对。

- 例：H₂ 解离的动态部分；非弹性 X 射线散射必须含动态相关才能描述
- 处理：CI / CC / MPn 加激发行列式

### 变分原理对"性质"不成立（p.5）⭐ 反复强调的考点

变分原理保证**更大基组给更低（更好）的能量**（但边际收益递减）。
**但因为误差补偿，变分原理一般不适用于能量以外的性质，甚至不适用于能量差。**
→ 算性质时，更大基组 ≠ 更准的答案，只 = 更长的机时。

## 二、组态相互作用 CI（p.7–22）

### 精确波函数

$$\Psi = a_0\psi_{HF} + \sum_{ia} a_i^a \psi_i^a + \sum_{i<j,a<b} a_{ij}^{ab}\psi_{ij}^{ab} + \cdots$$

*读法：精确波函数 Ψ = （HF 基态行列式）+ Σ（所有单激发行列式 × 系数）+ Σ（所有双激发行列式 × 系数）+ …更高阶激发。$\psi_i^a$ 表示"一个电子从占据轨道 i 跳到空轨道 a"得到的行列式，$a_i^a$ 是它的混合系数。*

- $\psi_i^a$：电子从占据轨道 $i$ 激发到空轨道 $a$ 的行列式
- 全部激发都含 = **Full CI (FCI)**，只有极小分子 + 小基组做得了
- 实践中截断激发级别，通常到 2

### CI 的求解（p.12–13）

对波函数做**拉格朗日乘子法**约束优化（$\langle\Psi|\hat H|\Psi\rangle \to \min$，$\langle\Psi|\Psi\rangle = 1$），
得到 **CI 久期方程**：

$$\mathbf{Ha} = E\mathbf{a} \qquad (\text{标准本征值问题})$$

*读法：把哈密顿量在"所有行列式"这组基里写成矩阵 H，对角化它 —— 最低本征值 E 就是基态能量，对应的本征向量 a 就是各行列式的系数。CI 求解 = 一次大矩阵对角化。*

唯一的困难是 **CI 矩阵随分子和基组增大而爆炸**。
- CISD = HF + 单双激发，O(n⁶)
- CISDT = HF + 单双三激发，O(n⁸)
- full CI，O(n!)

### 自旋适配（p.14）

不同自旋态在非相对论哈密顿量下不混（$\langle\text{singlet}|\hat H|\text{triplet}\rangle = 0$），
把 Slater 行列式组合成**自旋适配的组态状态函数 CSF** 可大幅省算量。
$N_{SD} \ge N_{CSF}$。

CI 计算量的例子（p.15–16）：随激发级别，CSF 数目先增后减，总数迅速累积到千万级。
但用 Ne 在 [5s4p3d] 基组的权重表看：**0 级（HF）权重约 0.96，双激发约 0.034，其余都很小**——
所以 CISD 通常够用。

### CI 如何让电子分开？——H₂ 最小基组（p.17–20）⭐ 经典推导，会考

$\varphi_g = \chi_A + \chi_B$（成键），$\varphi_u = \chi_A - \chi_B$（反键）。

- 基态 $\Psi_0 = |\varphi_g\bar\varphi_g|$ 展开 = **50% 离子项 + 50% 共价项**
- 双激发 $\Psi_D = |\varphi_u\bar\varphi_u|$ 展开：离子项系数与共价项系数**相反号**
- Full CI：$\Psi = a_0\Psi_0 + a_D\Psi_D$，混入 $\Psi_D$ → **共价贡献增加**（左右相关）
- 混入比例强烈依赖 H-H 距离；**无穷远时 $a_D = -a_0$ → 离子项系数变零**（解离对了）

Brillouin 定理：**所有单激发组态不与 HF 基态混**（$\langle\Psi_0|\hat H|\Psi_i^a\rangle = 0$）。

RHF / UHF / Full CI 对 H₂ 势能曲线的对比（p.21）：RHF 解离能爆高（塌成离子），
UHF 在 Coulson-Fischer 点后分岔下来接近 FCI。

### 截断 CI 的致命伤：size-inconsistency（p.22）⭐⭐ 必考

两个相距 100 Å 的水分子：
- 方法 1：一起算 → $E_{\text{tot}}$
- 方法 2：单个水算完 ×2 → $E_{2\times}$

**只有 Full CI 满足 $E_{\text{tot}} = E_{2\times}$。** 截断 CI（如 CISD）会得到 $E_{2\times} < E_{\text{tot}}$。
原因：单独算每个碎片时是"CISD × CISD"的乘积，会隐含产生三激发、四激发项，比 case 1 的 CISD 更完整。
→ **CISD 不能用于比较不同大小的体系 / 解离能。**

## 三、多组态 SCF：MCSCF / CASSCF（p.9–10）

单个 Slater 行列式描述差时，用**多个行列式**（轨道布居不同），
权重由变分原理调整，**同时优化行列式系数和轨道形状**。

- 芳香/共轭体系、断键/成键体系常必须用 MCSCF
- **CASSCF** = 对一个选定的轨道子集（**活性空间**）做 full CI + 优化轨道
- 选活性空间不是易事（HW3 的命门，见 `03_Software_Methods/OpenMOLCAS/notes.md`）
- CASPT2 / NEVPT2 = 在 CASSCF 之上再加微扰修正动态相关

## 四、耦合簇 Coupled Cluster（p.23–27）⭐⭐ "黄金标准"

### 核心思想

CI **对每个行列式配参数**；CC **对激发"过程"配参数**。

$$\Psi_{CC} = e^{\hat T}\psi_{HF}, \qquad \hat T = \hat T_1 + \hat T_2 + \cdots$$

*读法：CC 波函数 = 指数算符 e^T 作用在 HF 行列式上。$\hat T_1$ 生成所有单激发、$\hat T_2$ 生成所有双激发。把 $e^{\hat T}$ 泰勒展开：*
*$e^{\hat T} = 1 + \hat T_1 + \hat T_2 + \tfrac12\hat T_1^2 + \hat T_3 + \hat T_2\hat T_1 + \cdots$*
*—— 关键在那些平方/乘积项（如 $\tfrac12\hat T_1^2$、$\hat T_2\hat T_1$）：它们自动带进高阶激发，但系数是低阶系数的乘积，不用单独优化。*

对比 CI（$\Psi_{CI} = (1 + \hat T)\psi_{HF}$）：CC 在每个激发级别**多出激发乘积项**。
所以 CC "包含更高阶激发，但它们的系数是低阶激发系数的乘积"。

### 关键优点：size-consistent（p.23, 26）

$$E_{CC}(1+2) = E_{CC}(1) + E_{CC}(2) \quad\text{（即使在截断级别也成立）}$$

*读法：两个互不相互作用的体系放一起算，总能量 = 各自能量之和。CC（哪怕是 CCSD 这种截断版）满足这条，CISD 不满足。*

这正是截断 CI 做不到的。

### 截断层级

- **CCSD** = 单 + 双
- **CCSD(T)** = 单双 + 微扰三激发 ← **实际计算的黄金标准**
- CCSDT / CCSDTQ = 显式三 / 四激发（很贵）

### 收敛表（p.27）水分子 cc-pVDZ，$E_{CC} - E_{FCI}$（Hartree）

| 方法 | 误差 |
|---|---|
| RHF | 0.218 |
| CCSD | 0.0037 |
| CCSDT | 0.0005 |
| CCSDTQ | 0.00002 |

**多参考体系**（扭转双键、拉长单键）里 CC 随激发级别收敛会慢得多——
和 CI 一样，单行列式不是好起点时应改用 CASSCF/CASPT2。

几何/原子化能对比（p.27）：CCSD(T)/6-311G(2df,p) 的 RMS 原子化能误差 11.5 kcal/mol，
远好于 HF（82–86）和 MP2（22–24）。

## 五、微扰论 / Møller-Plesset（p.28–36）

### 一般微扰论

$\hat H = \hat H_0 + \lambda\hat H_1$，$\hat H_0$ 的解已知。展开波函数和能量为 $\lambda$ 的幂级数：

$$E_n^{(1)} = \langle\psi_n^{(0)}|\hat H_1|\psi_n^{(0)}\rangle$$
$$E_n^{(2)} = \sum_{m\ne n}\frac{|\langle\psi_m^{(0)}|\hat H_1|\psi_n^{(0)}\rangle|^2}{E_n^{(0)} - E_m^{(0)}}$$

*读法：一阶能量修正 = 微扰算符 $\hat H_1$ 在未微扰态上的期望值。二阶修正 = 对所有其他态求和，分子是"本态与 m 态之间的耦合矩阵元平方"，分母是"本态与 m 态的能隙"—— 能隙越小、耦合越强，贡献越大。*

### Møller-Plesset（p.36）

把 PT 直接用到闭壳层 HF 波函数（$\psi^{(0)} = \Psi_{HF}$，$\hat H_0 = $ Fock 算符之和）：

$$E_{MP2} = E_0 + \sum_{i<j}^{\text{occ}}\sum_{a<b}^{\text{virt}}\frac{|\langle\varphi_i\varphi_j\|\varphi_a\varphi_b\rangle|^2}{\varepsilon_i + \varepsilon_j - \varepsilon_a - \varepsilon_b}$$

*读法：MP2 相关能 = 对"占据轨道对 (i,j) → 空轨道对 (a,b)"的所有双激发求和。分子是双电子积分（该激发的强度）的平方，分母是占据轨道能之和减去空轨道能之和（恒为负，所以每一项都让能量下降）。只需要 HF 的轨道和轨道能就能算，所以便宜。*

- **MP2 是最便宜的相关方法**，捕捉动态相关的主要部分
- MPn 系列**不是变分的**（能量可能低于精确值），且**高阶不保证收敛**（MP7 可能 >100%）

### MPn / CI / CC 回收相关能的对比（p.39）Be 原子

| 方法 | $E_{\text{corr}}$ 回收率 |
|---|---|
| MP2 | 67.85% |
| MP3 | 86.90% |
| MP4 | 94.58% |
| CISD | 96.05% |
| CCSD | 99.75% |
| CCSD(T) | 99.99% |
| CCSDTQ / CISDTQ | 100% |

**N.B.**：单参考方法只在 HF 参考态是好起点时才准。有均裂断键或简并时，MPn、CI、CC 都可能**灾难性失败**。

## 六、标度与实用建议（p.37–43）

### 计算标度（无基组筛选，p.40）⭐ 会考

| 方法 | 标度 | 实用体系规模 |
|---|---|---|
| HF | O(n⁴) | 几百个原子 |
| MP2 | O(n⁵) | ~100 原子 |
| MP3 / CISD / CCSD / QCISD | O(n⁶) | ~20 原子 |
| MP4 / CCSD(T) / QCISD(T) | O(n⁷) | ~20 原子（MP4）|
| CISDT / CCSDT | O(n⁸) | — |
| FCI | O(n!) | 3–4 个简单原子 |

导数可用性：HF 有解析一/二阶导；MP2 有解析一/二阶导；MP4/CISD/CCSD 多为数值导；FCI 全数值。

### BSSE 与 counterpoise 校正（p.37–38）⭐ 会考（HW4 练习题也考）

- **BSSE（基组重叠误差）**：两个分子靠近时互相"借"对方的基函数 → 变分灵活性增加 →
  **即使没有真实相互作用，能量也会下降** → 非物理的吸引
- **Counterpoise 校正**：
  1. 正常算复合物能量
  2. 对每个碎片，在**对方的轨道存在下**（有轨道，无电子无核）再各算一次
  $$E_{AB}^{CP} = E_{AB} - (E_A^{AB} - E_A) - (E_B^{AB} - E_B)$$

  *读法：$E_A^{AB}$ = 只算 A、但让它借用 B 的空轨道时的能量；$E_A$ = A 单独算。两者之差就是 A 白捡的那部分能量（BSSE）。把 A、B 各自白捡的量从复合物能量里减掉，得到校正后的 $E_{AB}^{CP}$。*

### 完备基组（CBS）外推（p.43）

能量（不是其他性质）可外推到 CBS 极限。Dunning-Feller 方案（$n$ = (aug-)cc-pVnZ 的 zeta 指标）：

$$E_n = E_{CBS} + \alpha e^{-\beta n}$$

*读法：拿几个 zeta 数 n 不同的基组（cc-pVDZ 是 n=2、pVTZ 是 n=3、pVQZ 是 n=4）各算一个能量 $E_n$，用这个指数衰减公式拟合，外推 n→∞ 得到完备基组极限 $E_{CBS}$。α、β 是拟合参数。*

**速查（p.43）**：
- 快而糙：HF/6-31G(d,p) 或 HF/cc-pVDZ
- 慢而准：CCSD(T)/cc-pVQZ 及以上
- 高精度复合方法：G1–G3、G2MP2、G3MP2、MP2-R12

### 密度与分布（p.44）

- 概率密度 $|\psi|^2$、电子密度 $\rho(r)$、**自旋密度** $\rho_\alpha - \rho_\beta$、电荷密度 $-e\rho(r)$
- 电子等密度面 + 静电势着色（ESP map）——GaussView/Multiwfn 常画
