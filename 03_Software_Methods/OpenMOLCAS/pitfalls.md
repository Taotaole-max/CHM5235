# OpenMOLCAS 踩过的坑

## 已知高频坑（预填，遇到时对照）

| 现象 | 原因 | 解决方法 |
|---|---|---|
| RASSCF 收敛到奇怪的解 / 能量比预期高 | **活性空间选错了**——最常见也最难查 | 用 Luscus 逐个看活性轨道，确认是你想要的 d/f 轨道而不是配体轨道 |
| RASSCF 轨道"跑掉"（活性轨道被换成别的） | 优化过程中轨道旋转出活性空间 | 用 `SUPSym` 或先做小活性空间再逐步扩大；每次都用 Luscus 复核 |
| CASPT2 出现 intruder state 警告 | 参考空间外有能量相近的态混进来 | 加 `IMAG = 0.1`（虚位移），这是标准做法 |
| CASPT2 结果和文献对不上 | IPEA 位移取值不同（默认 0.25 vs 常用 0.0） | 明确记录并在报告里写出你用的值 |
| 作业跑到一半磁盘满 | WorkDir 放在了家目录，CASPT2 中间文件极大 | `MOLCAS_WORKDIR` 指向 scratch |
| RASSI 报找不到 JOB001 | `>> COPY` 命令没写或路径不对 | 每个 RASSCF 之后必须显式 COPY 到 JOBnnn |
| SOC 结果全是零 / 没有耦合 | `&GATEWAY` 里忘了写 `AMFI` | 做 SOC 必须在 GATEWAY 加 `AMFI` |
| 输入文件被忽略某段 | 模块名拼错，或 `&` 后有空格 | `&RASSCF` 不能写成 `& RASSCF` |
| 计算慢到无法忍受 | 没开 Cholesky 分解 | `&GATEWAY` 里加 `RICD` |

## 活性空间怎么选（HW3 的命门）

CAS(n,m) = n 个电子放进 m 个轨道。计算量随 m **组合爆炸**，CAS(14,14) 已经是常规上限。

选择原则：
- **过渡金属**：金属的 5 个 d 轨道 + 与之强作用的配体轨道（σ 给体、π 受体）
- **双壳层效应**：3d 金属常需再加一组 4d "双壳层"轨道（5 个），即 CAS(n, 10)
- **镧系**：7 个 4f 轨道，f 电子数就是 n。4f 高度局域，通常不需要加配体轨道
- **有机分子激发态**：全部 π 和 π* 轨道

**每次改活性空间都要用 Luscus 看一遍**，这是唯一可靠的验证方式。
