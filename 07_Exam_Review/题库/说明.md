## 其他文件

| 文件 | 用途 |
|---|---|
| `*.html` | 与 PDF 内容相同的单文件网页版（图片已内嵌），浏览器直接打开 |
| `*.src.html` | 源文件（图片通过 img/ 引用），要改题目就改这个，再运行 build_pdf.py |
| `img/` | 题目用到的图：`L*_p*.png` 是讲义截图，`fig_*.png` 是示意图 |
| `make_figs_L1L2.py` | 生成第一批的图 |
| `make_figs_L3L6.py` | 生成第二、三批的图 |
| `build_pdf.py` | 把 src.html 转成单文件 html 和 PDF：`python build_pdf.py <文件名>.src.html` |

部分情景题的数据取自 HW1（HF 分子势能面扫描、CH₂FOH 的 TD-DFT）和 HW2（2-氯苯酚四种方法、Cu₂ 的 BS-DFT、水团簇 MD）的实际计算结果。
