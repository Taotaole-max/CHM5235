拓展 · "量子化"到底是什么意思

初学者容易把"量子化"理解成"很小"。不对。量子化的意思是"分立"（discrete），即某个物理量只能取一串特定的值，中间的值取不到。

类比：楼梯 vs 斜坡。斜坡上你可以停在任何高度（连续）；楼梯上你只能站在第 1、2、3 级（分立）。量子力学说：微观世界的能量是楼梯，不是斜坡。

但注意——不是所有物理量在所有情形下都量子化。自由粒子的能量是连续的；只有被束缚在某个势阱里的粒子，能量才量子化。这是 p6–p9 那几页的正题。

p3–5波粒二象性与 de Broglie 关系

原文翻译（p3）

科学家一直难以描述光的本质——它是波还是粒子？

1924 年，de Broglie 推理：如果光既能有波的性质又能有粒子的性质，为什么物质不行？

由 Einstein 的相对论能量方程，一个静止质量为零的粒子的能量是它的动量与光速的乘积：

E = pc = mc²

把这个方程与光子能量 E = hν 结合，就得到 de Broglie 波长关系：

λ = h/p

de Broglie 断言这对粒子和光子都成立。

（de Broglie 因"物质波动行为的思想"获 1929 年诺贝尔奖。）

原文翻译（p4）

这个关系的后果影响深远（它引导薛定谔建立了波动力学理论），但它在自然中的依据是无可置疑的：

  • Davisson 与 Germer（1925）以及 Thompson（1927）观测到了电子衍射
  • 电子的波动性质被用于电子显微镜
  • 电子的波长可以通过外加电压控制，很小的 de Broglie 波长提供了比普通光学显微镜精确得多的探针
  • 此外，与相近波长的电磁辐射不同，电子束可以用电场和磁场方便地聚焦
原文翻译（p5）

de Broglie 波为量子化的玻尔轨道提供了一个简单的物理解释。

公式解析 · de Broglie 关系

de Broglie 关系（本讲最基础的一条） λ = h / p = h / (mv)
符号名称含义与单位
λ波长希腊字母 lambda。物质波的波长，单位 m。这是"波"的属性。
h普朗克常数h = 6.626×10⁻³⁴ J·s。整个量子力学的"尺度常数"——它决定了量子效应在多小的尺度上才显现。
p动量p = mv，单位 kg·m/s。这是"粒子"的属性。
m质量粒子质量，单位 kg
v速度单位 m/s
c光速2.998×10⁸ m/s
ν频率希腊字母 nu（注意别和拉丁字母 v 混），单位 Hz = s⁻¹

这个公式的震撼之处在于等号两边：左边 λ 是纯粹的波的概念，右边 p 是纯粹的粒子的概念。一个 h 把它们连起来了。

讲解 · p10 那道"算一算"的题，我们现在就做

讲义 p10 让你算两个 de Broglie 波长，这是理解"为什么宏观世界不需要量子力学"的最快方式：

情形 1：一个 80 kg 的人，以 5 m/s 跑步

λ = h/(mv) = 6.626×10⁻³⁴ / (80 × 5) = 6.626×10⁻³⁴ / 400 ≈ 1.7×10⁻³⁶ m

对比：一个原子核的直径约 10⁻¹⁵ m。这个波长比原子核还小 20 个数量级。没有任何东西能观测到这么短的波长，所以人不表现波动性。

情形 2：一个电子（m = 9.11×10⁻³¹ kg），同样以 5 m/s 运动

λ = 6.626×10⁻³⁴ / (9.11×10⁻³¹ × 5) = 6.626×10⁻³⁴ / 4.56×10⁻³⁰ ≈ 1.5×10⁻⁴ m = 0.15 mm

0.15 毫米！这是肉眼可见的尺度。同样的速度，仅仅因为质量差了 10³² 倍，波长就从"不可想象地小"变成"用尺子能量出来"。

结论：波动性显不显现，取决于 λ 和你的系统尺寸相比是大是小。电子在原子里的 λ 恰好和原子尺寸（约 10⁻¹⁰ m）同量级——所以原子里的电子必须用量子力学描述。这就是整个量子化学存在的理由。

讲解 · p5 那张图：de Broglie 怎么解释了玻尔轨道

玻尔在 1913 年硬塞了一条假设："角动量只能取 nħ"。当时没人知道为什么。de Broglie 给出了答案：

驻波条件 → 玻尔的角动量量子化 2πr = nλ = n·h/p　⟹　pr = n·h/(2π) = nħ
符号名称含义
r轨道半径电子绕核圆周运动的半径
n主量子数正整数 1, 2, 3…　"整数"就是量子化的来源
pr角动量动量 × 半径 = 角动量的大小
ħ约化普朗克常数念作 "h-bar"，ħ = h/(2π) = 1.055×10⁻³⁴ J·s。量子力学里几乎处处用 ħ 而不是 h，因为角频率 ω=2πν 用起来更自然。

逻辑链条：波必须首尾相接（否则自我抵消） → 周长必须是波长的整数倍 → 代入 λ=h/p → 角动量必须是 ħ 的整数倍。玻尔硬塞的假设，变成了驻波条件的必然结果。

p6–9什么时候必须用量子力学？（Boltzmann 判据）

原文翻译（p6）
  • 经典力学和量子力学并不是在竞争谁能描述我们周围的世界
  • 当状态之间的能量差可以忽略、使得谱可以看作"连续"时，经典力学适用
  • 当能谱是"分立"的时，才需要量子描述
原文翻译（p7–p9）

Boltzmann 分布：n₂/n₁ = (g₂/g₁)·exp[−(e₂−e₁)/(kBT)]

n₁, n₂ —— 能量为 e₁ 和 e₂ 的气体原子数目

g₁, g₂ —— 每个能态的简并度

简并度 ⟹ 原子能量落在区间 e₁−Δe < e < e₁+Δe 内的方式数

能量越高 = 分配能量的方式越多 = 简并度越高（= 熵越高）

动能：eᵢ = ½mvᵢ² = ½m(vᵢₓ² + vᵢᵧ² + vᵢᵤ²)

p8 例子：考虑一个有 1000 个原子的系统，只有两个允许的能态 e₁ 和 e₂。各态布居为：

n₁ = 1000/(1+e−Δe/kBT)，　n₂ = 1000·e−Δe/kBT/(1+e−Δe/kBT)

p9 结论：

  • 若 ΔE < kBT 或 ΔE ≈ kBT ⟹ 谱看起来是连续的 ⟹ 经典描述就够了
  • 若 ΔE > kBT ⟹ 分立谱 ⟹ 需要量子描述

公式解析 · Boltzmann 分布

Boltzmann 分布（统计热力学最重要的一个公式） n2 / n1 = (g2 / g1) · e−ΔE / (kBT)　，　ΔE = e2 − e1
符号名称含义
n1, n2布居数处于能级 1 和能级 2 上的粒子个数
e1, e2能级能量两个能级各自的能量值
ΔE能级间隔= e2 − e1，两个能级差多少。这是判据里的主角。
g1, g2简并度degeneracy。"能量相同但状态不同"的状态个数。比如 2p 轨道有 2px、2py、2pz 三个，能量相同 → g = 3。
kB玻尔兹曼常数1.381×10⁻²³ J/K。它的作用是"把温度翻译成能量"：kBT 就是温度 T 对应的典型热运动能量。
T绝对温度单位 K（开尔文）
ex指数函数自然指数。注意别和电子电荷 e 或能级 eᵢ 混淆——这个领域符号复用非常严重，只能靠上下文判断。

讲解 · 这个公式在说什么（用大白话）

指数上的那个分数 ΔE/(kBT) 是全部信息所在。它在比较两个能量：

  • 分子 ΔE：粒子从下面那级爬到上面那级需要的能量
  • 分母 kBT：环境的热运动能提供的典型能量
情形指数值 e−ΔE/kBT物理图像
ΔE ≪ kBT≈ e⁰ = 1两个能级布居几乎相同。热运动轻松就能跨过去，粒子在两级间随意游走。这时"分立"这件事完全不重要 → 经典力学够用。
ΔE ≈ kBT≈ e⁻¹ = 0.37上面那级有可观布居。过渡区。
ΔE ≫ kBT→ 0几乎所有粒子都待在基态。这时"只有特定能量被允许"这件事就是决定性的 → 必须用量子力学。
拓展 · 把数字代进去：室温下 kBT 是多少

这是做计算化学必须记住的一个数：

室温 T = 298 K：　kBT ≈ 0.0257 eV ≈ 2.48 kJ/mol ≈ 0.59 kcal/mol ≈ 207 cm⁻¹

现在拿它去衡量化学中各种能级间隔：

运动/跃迁类型典型 ΔE相对 kBT(298K)结论
平动（分子在容器里跑）10⁻²⁰ eVΔE ≪ kBT经典（所以理想气体定律不需要量子力学）
转动（分子转圈）10⁻⁴–10⁻² eV
(1–100 cm⁻¹)		ΔE ≲ kBT接近经典，室温下大量转动能级被布居
振动（键的伸缩）0.1–0.5 eV
(500–4000 cm⁻¹)		ΔE ≈ 4–20 × kBT需要量子。这就是为什么室温下绝大多数分子处于振动基态（零点能是真实存在的，且不可消除）
电子跃迁（HOMO→LUMO）2–10 eVΔE ≈ 100–400 × kBT绝对需要量子。这就是量子化学存在的原因。

最后一行是关键：电子的能级间隔比室温热能大两三个数量级，所以电子被牢牢锁在基态，绝不能用经典力学描述。这就是为什么这门课整整四讲都在解电子的薛定谔方程。

拓展 · 简并度 g 与熵的联系

讲义 p7 有句话："能量越高 = 分配能量的方式越多 = 简并度越高 = 熵越高"。这句话把量子力学和热力学接上了：

Boltzmann 墓碑上的公式S = kB ln W
S熵单位 J/K
W微观状态数实现同一宏观状态的微观方式数——就是简并度

所以 Boltzmann 分布里的 g₂/g₁ 其实是个熵因子，而 e−ΔE/kBT 是焓（能量）因子。两者的竞争就是自由能 ΔG = ΔH − TΔS 的微观来源。

p10–12从经典波方程到定态方程

原文翻译（p10）

de Broglie 关系使物质可以用波来描述。

动量：mv = h/λ；λ = h/(mv)

波动性质对小物体重要得多。λ(80 kg 物体以 5 m/s 运动) = …　λ(电子以 5 m/s 运动) = …

大多数分子性质都由波动力学导出。

∂²Ψ(x,t)/∂x² = (1/v²)·∂²Ψ(x,t)/∂t²　⟸ 一维经典非色散波方程

Ψ(x,t) = 波函数（例如 = A sin(kx − ωt)）；v = λν = 速度；k = 2π/λ = ω/v = 波矢；ω = 角频率

为什么要换成波？因为对我们要做的事，数学更简单。

公式解析 · 经典波动方程

一维非色散波方程 ∂²Ψ(x,t) / ∂x² = (1/v²) · ∂²Ψ(x,t) / ∂t²
符号名称含义
Ψ波函数大写希腊字母 Psi。描述波的形状随位置和时间的变化。对水波是水面高度，对声波是压强，对电子——p32 才会告诉你它是什么。
∂偏导数符号念 "partial"。∂Ψ/∂x 的意思是"t 固定不动，只看 Ψ 随 x 怎么变"。因为 Ψ 有两个自变量，必须说清楚对谁求导。
∂²/∂x²二阶偏导求两次导。几何意义是"曲率"——函数弯得有多厉害。
v波速波形传播的速度，v = λν
A振幅波的最大高度
k波矢 / 波数k = 2π/λ。可以理解为"每单位长度里有几个弧度的相位"
ω角频率希腊字母 omega。ω = 2πν，单位 rad/s
φ相位希腊字母 phi。波的初始相位偏移

这个方程在说什么：波在某点的"弯曲程度"（左边）正比于它在该点的"加速度"（右边）。弯得越厉害，回复得越快——就像绷紧的弦，拉得越弯，弹回去的加速度越大。

推导 · p11：验证 A sin(kx − ωt + φ) 是解

原文翻译（p11）

练习：证明波函数 Ψ(x,t) = A sin(kx − ωt + φ) 是上述非色散波方程的解。

解：左边：∂²[A sin(kx−ωt+φ)]/∂x² = −Ak² sin(kx−ωt+φ)

右边：(1/v²)·∂²[A sin(kx−ωt+φ)]/∂t² = −(ω²/v²)·A sin(kx−ωt+φ)

把关系 k = ω/v 代入上式即得等式成立。

一步步做（如果你对求导有点生疏）

左边：对 x 求导两次。t 当常数看。

  • 第一次：∂/∂x [A sin(kx−ωt+φ)] = A·cos(kx−ωt+φ)·k　（链式法则：括号里对 x 的导数是 k）
  • 第二次：∂/∂x [Ak cos(…)] = −Ak·sin(…)·k = −Ak² sin(…)

右边：对 t 求导两次。x 当常数看。

  • 第一次：∂/∂t [A sin(…)] = A cos(…)·(−ω)
  • 第二次：∂/∂t [−Aω cos(…)] = Aω sin(…)·(−ω) = −Aω² sin(…)
  • 再除以 v²：−(Aω²/v²) sin(…)

令左=右：−Ak² sin(…) = −(Aω²/v²) sin(…)　⟹　k² = ω²/v²　⟹　k = ω/v　✔

注意关键点：sin(…) 这个因子在两边都出现，可以约掉。剩下的只是常数之间的关系。这个"函数被求导后变回自己乘一个常数"的现象，就是下一页"本征值方程"的雏形。

推导 · p12：驻波（定态）

原文翻译（p12）

驻波：Ψ(x,t) = ψ(x)·cos(ωt)（= 定态的等价物）

把它代入波方程，经过整理得到：

∂²ψ(x)/∂x² + ω²ψ(x)/v² = 0

再把 ω = 2πν 和 v = λν 代入，得到：

(∂²/∂x²)ψ(x) + (4π²/λ²)ψ(x) = 0

这一步的关键思想：分离变量

原来的 Ψ(x,t) 同时依赖位置和时间，很麻烦。驻波的特点是"形状不动，只是整体上下振荡"——所以可以写成"一个只管形状的函数 ψ(x)"乘以"一个只管振荡的函数 cos(ωt)"。

代入后：

  • 对 x 求二阶导：cos(ωt) 是常数，提出来 → cos(ωt)·ψ″(x)
  • 对 t 求二阶导：ψ(x) 是常数，提出来 → ψ(x)·(−ω²)cos(ωt)
  • 整个方程两边都有 cos(ωt)，约掉 → 得到只含 x 的方程

这就是"定态"的数学含义：时间部分被分离出去并约掉了，剩下一个不含时间的方程。所以定态 = 概率分布不随时间变化的状态。原子的 1s、2p 轨道全都是定态。

最后一步的代换：ω/v = 2πν/(λν) = 2π/λ，所以 ω²/v² = 4π²/λ²。

p13–14薛定谔方程：这一讲最重要的一页

原文翻译（p13）

到目前为止得到的波方程仍然是"经典的"：(∂²/∂x²)ψ(x) + (4π²/λ²)ψ(x) = 0

要把它变成"量子的"，我们按如下步骤进行。

总能量的经典表达式是：E = T + V(x) = mv²/2 + V(x) = p²/(2m) + V(x)　⟹　p² = 2m[E − V(x)]

把它代入 de Broglie 关系 λ = h/p，再把 λ 代入上面的波方程：

(∂²/∂x²)ψ(x) + (8π²m/h²)[E − V(x)]ψ(x) = 0

代入约化普朗克常数 ħ = h/2π 并稍作整理，得到：

−(ħ²/2m)(∂²/∂x²)ψ(x) + V(x)ψ(x) = Eψ(x)

这就是不含时薛定谔方程，用于研究量子力学系统的定态，例如 H 原子的 1s 和 2pz 轨道就是定态。

讲解 · 这个方程为什么长这样（三个层次的理解）

层次 1：它其实就是"总能量 = 动能 + 势能"

把方程重新分组看：

[ T̂ + V̂ ] ψ = E ψ　　即　　Ĥψ = Eψ

左边中括号里就是"动能算符 + 势能算符"= 哈密顿算符 Ĥ（总能量算符）。所以薛定谔方程说的是：把总能量算符作用在波函数上，得到的还是这个波函数，只是乘了一个数 E。

层次 2：为什么动能里有个二阶导数

回想 p11 的推导：对 sin(kx) 求二阶导得到 −k²·sin(kx)。而 k = 2π/λ = 2πp/h = p/ħ。

所以 −ħ²·(二阶导) 作用在波上，会"取出" p²：

−ħ² ∂²/∂x² [sin(kx)] = ħ²k² sin(kx) = p² sin(kx)

再除以 2m，就是动能 p²/2m。二阶导数就是"测量动量平方"的操作，这不是巧合，是 de Broglie 关系的直接后果。

层次 3：为什么能量会量子化

这是最容易被跳过、但最重要的一点。方程本身对任何 E 值都有数学解。但物理上合法的解还必须满足边界条件（p34–35 会列出：单值、连续、有限、可归一化）。

大多数 E 值给出的解在 x→±∞ 时会发散（趋于无穷），这样的解不能归一化，物理上无意义，必须扔掉。只有少数几个特定的 E 值，解才恰好"收敛"——这些就是允许的能级。

类比：一根两端固定的琴弦，只有特定的几个频率能形成驻波（其他频率的波在端点对不上，自我抵消）。能量量子化 = 边界条件筛选的结果。这也是为什么自由粒子（没有边界）的能量是连续的。

公式解析 · p14：含时薛定谔方程（TDSE）

原文翻译（p14）

不含时薛定谔方程：−(ħ²/2m)(∂²/∂x²)ψ(x) + V(x)ψ(x) = Eψ(x)

注意乘积：Ψ*(x,t)Ψ(x,t) = ψ*(x)e+iEt/ħ·ψ(x)e−iEt/ħ = ψ*ψ　与时间相位无关。

符号名称含义
i虚数单位i = √(−1)。量子力学中波函数一般是复数——这不是数学技巧，是物理必需（下面解释）。
Ψ*复共轭把所有的 i 换成 −i。如果 Ψ = a+bi，则 Ψ* = a−bi。
e−iEt/ħ时间相位因子由 Euler 公式 eiθ = cosθ + isinθ，它是一个模长恒为 1、只是在复平面上转圈的数。

Ψ*Ψ = ψ*ψ——时间因子完全消失了。因为 e+iEt/ħ × e−iEt/ħ = e0 = 1。

这就是"定态 (stationary state)"这个名字的由来：波函数本身在复平面上一直转圈（在变），但可观测的概率密度 |Ψ|² 完全不随时间变化（不动）。

所以我们平时说"1s 轨道"，画的那个球形电子云，就是 |ψ1s|²——一个不随时间变化的分布。电子并不是"绕核转圈"，它的概率分布就那么静静地待着。

拓展 · 为什么波函数必须是复数

看含时方程右边：iħ∂Ψ/∂t。方程里明晃晃地有一个 i。如果 Ψ 是实函数，左边是实的，右边是虚的，方程不可能成立。所以 Ψ 必须是复的。

物理上为什么需要复数：因为需要同时编码"振幅"和"相位"两个信息。相位是量子干涉的来源——两条路径的波叠加时，是相长还是相消完全由相位差决定。没有相位就没有化学键（成键轨道 = 同相叠加，反键轨道 = 反相叠加）。

不过实践中：不含时薛定谔方程的解（如果 V 是实的）总可以取成实函数。所以你在教科书上看到的原子轨道图（2px、2py、3dxy…）都是实的——它们是复的球谐函数经过线性组合后的实数形式（p53 会讲）。

p17练习：判断是不是本征函数

原文翻译

练习：验证函数 ψ(x) = Aeikx + Be−ikx 是否是以下算符的本征函数：∂/∂x 和 ∂²/∂x²。如果是本征函数，求出本征值。

∂/∂x(Aeikx + Be−ikx) = ikAeikx − ikBe−ikx = ik(Aeikx − Be−ikx)

ψ(x) 不是 ∂/∂x 算符的本征函数

∂²/∂x²(Aeikx + Be−ikx) = ∂/∂x[ik(Aeikx − Be−ikx)] = (ik)²Aeikx + (−ik)²Be−ikx = −k²(Aeikx + Be−ikx)

ψ(x) 是算符 ∂²/∂x² 的本征函数，本征值为 "−k²"

讲解 · 判断标准只有一条

判断本征函数的唯一标准

算符作用后的结果，必须能写成"（一个常数）× （原来那个一模一样的函数）"。

不能是"常数 × 长得有点像的函数"，必须是完全相同的函数。

看第一个：为什么 ∂/∂x 不行

原函数：Aeikx + Be−ikx（中间是加号）

结果：ik(Aeikx − Be−ikx)（中间变成了减号）

符号变了，就不是同一个函数了。所以不是本征函数。

为什么会变号：因为 eikx 求导得 ik·eikx（乘 +ik），而 e−ikx 求导得 −ik·e−ikx（乘 −ik）。两项被乘上了不同的常数，所以提不出公因子。

看第二个：为什么 ∂²/∂x² 可以

求两次导后：第一项乘了 (ik)² = i²k² = −k²；第二项乘了 (−ik)² = i²k² = −k²。

两项被乘上了同一个常数 −k²，所以能提出公因子，原函数原封不动地保留下来。

本征值 = −k²。

拓展 · 这道题的物理含义（讲义没说，但很重要）

这个函数描述的是一维自由粒子：Aeikx 是向右传播的平面波，Be−ikx 是向左传播的。

  • 不是动量算符的本征函数（因为 p̂ = −iħ∂/∂x）：合理！因为它是"向右走"和"向左走"的叠加，动量的方向不确定。你测一次动量，可能得 +ħk，也可能得 −ħk。
  • 是动能算符的本征函数（因为 K̂ ∝ ∂²/∂x²）：也合理！向左走和向右走的动能是一样的（p²/2m 里 p 平方了，符号消失）。所以动能是确定的：E = ħ²k²/2m。

验证一下：K̂ψ = −(ħ²/2m)·(−k²)ψ = (ħ²k²/2m)ψ。而 ħk = p，所以 E = p²/2m　✔ 正是经典动能公式。

一句话总结：一个态可以是某个算符的本征态、同时不是另一个算符的本征态。这正是"哪些量能同时确定"的问题，答案由对易关系给出（p21–27）。

p18–19正交性与归一化

原文翻译（p18）
  • 量子力学算符的本征函数彼此正交：
    ∫ψi*(x) ψj(x) dx = 0
  • 正交性保证了所有本征态彼此"完全不同"
  • 量子力学算符的所有本征函数都是归一化的：
    ∫ψi*(x) ψi(x) dx = 1
  • 归一化保证所有本征函数有相同的"振幅"，即在整个空间上积分时，在某个轨道上找到一个电子的概率是 1（即 100% 确定）

练习详解 · p19 的归一化

原文翻译（p19）

练习：把函数 ψ(x) = a(a+x) 在区间 0 ≤ x ≤ a 上归一化。

N²∫[a(a+x)][a(a+x)]dx = N²∫(a²+ax)(a²+ax)dx = N²a²∫(a²+2ax+x²)dx = 1

计算定积分给出：N²a²∫₀a(a²+2ax+x²)dx = N²a²[a²x + ax² + x³/3] = N²(7a⁵/3)

N²(7a⁵/3) = 1　⟹　N = √(3/(7a⁵))

归一化的通用套路（三步，永远一样）
  1. 在原函数前面乘一个待定常数 N：ψ归一 = N·ψ原
  2. 要求 ∫|Nψ原|² dx = 1，即 N²∫|ψ原|² dx = 1
  3. 解出 N：N = 1/√(∫|ψ原|² dx)
这道题的具体计算

第一步，展开被积函数：
[a(a+x)]² = a²(a+x)² = a²(a² + 2ax + x²)

第二步，逐项积分（a 是常数，只对 x 积分），从 0 积到 a：

被积项原函数代入 x=a 减 x=0
a²a²xa²·a − 0 = a³
2axax²a·a² − 0 = a³
x²x³/3a³/3 − 0 = a³/3

三项相加：a³ + a³ + a³/3 = (7/3)a³

第三步，别忘了外面还有个 a²：
N² · a² · (7/3)a³ = N²·(7/3)a⁵ = 1

第四步，解出：N² = 3/(7a⁵)　⟹　N = √(3/(7a⁵))　✔

  • ψ(x) = 通过混合许多基函数构造出的一个一般函数
  • bn = 基函数 ψn(x) 混入一般波函数的混合系数

类比于实的三维笛卡尔空间：任何三维向量都可以表示为三个正交（垂直）向量 x、y、z 的线性组合。这三个单位向量 x、y、z 构成一个完备集。

给定算符的完备本征函数集可以是无穷的，但不是必然如此。

公式解析 · 基组展开

★ 完备性展开（整门课的技术基础） ψ(x) = Σn=1∞ bn ψn(x)
符号名称含义

ψn(x)基函数已知的、完备的、正交归一的一套函数

讲解 · 用向量类比把这件事讲透

一句话：任何函数都能"分解"成基函数的加权和

就像任何颜色都能分解成红绿蓝三原色的组合，任何声音都能分解成不同频率正弦波的组合（傅里叶级数）。"完备"的意思就是：这套基函数够用，任何函数都能被它们精确表示，一个都不会漏。

这一页是整门课最重要的实用概念，因为现实中我们只能用不完备的基组

理论上求和要到 ∞。实际计算中你只能用有限个基函数（比如 6-31G(d) 对一个碳原子只给 15 个函数）。

这个"截断"就是基组误差（basis set incompleteness error）的来源——它是量子化学两大误差源之一（另一个是方法误差，即电子相关处理不足）。

误差来源怎么减小代价
基组不完备用更大的基组（DZ→TZ→QZ→…），或外推到完备基组极限 CBS（第 4 讲 p43）时间 ∝ N⁴ 或更高
方法不精确爬精度阶梯（HF→MP2→CCSD→CCSD(T)）时间 ∝ N⁵、N⁶、N⁷

这就是量化计算里那个著名的"二维收敛"图：你必须同时在"方法"和"基组"两个方向上收敛，缺一不可。只提高一个另一个不动，结果可能反而更差（误差抵消被破坏）。

p21算符的性质（一）：线性与对易

原文翻译

线性：

  1. aÔψ = Ô(aψ)　⟹ 线性算符
  2. log(aψ) ≠ a·log(ψ)　⟹ 非线性算符

对易：

练习：对任意一组算符 Â 和 B̂，是否有 ÂB̂ψ = B̂Âψ？对位置算符（Â = x）和动量算符（B̂ = −iħ∂/∂x = p̂x）验证这个关系。

  • ÂB̂ψ = −iħ x (∂/∂x) ψ = −iħ x (∂ψ/∂x)
  • B̂Âψ = −iħ (∂/∂x)(xψ) = −iħψ − iħx(∂ψ/∂x)
  • (ÂB̂ − B̂Â)ψ = −iħx(∂ψ/∂x) − [−iħψ − iħx(∂ψ/∂x)] = iħψ

⟹ 算符 x 与 −iħ∂/∂x 不对易。这意味着这两个算符作用在函数 ψ 上的先后顺序是有影响的。

讲解 · 什么是"对易"

日常生活中的对易与不对易
操作对换顺序结果一样吗结论
穿袜子、戴帽子一样对易
穿袜子、穿鞋不一样（先穿鞋就麻烦了）不对易
3 × 5 和 5 × 3一样（都是 15）对易
矩阵 AB 和 BA一般不一样一般不对易

推导详解 · 逐步验证 [x̂, p̂] = iħ

这是量子力学最著名的一个计算，值得完全看懂。关键技巧：必须让算符作用在一个"试探函数" ψ 上，光看算符本身会算错。

第一步：算 x̂p̂ψ（先用 p̂，再用 x̂）

注意：算符从右往左依次作用（离 ψ 最近的先作用）。

x̂ p̂ ψ = x · [ −iħ ∂ψ/∂x ] = −iħ x (∂ψ/∂x)

先对 ψ 求导，再乘以 x。就这么简单。

第二步：算 p̂x̂ψ（先用 x̂，再用 p̂）

先乘 x 得到 xψ，再对 整个 xψ 求导。这里必须用乘积法则（product rule）——这就是全部玄机所在。

p̂ x̂ ψ = −iħ ∂(xψ)/∂x = −iħ [ (∂x/∂x)·ψ + x·(∂ψ/∂x) ] = −iħψ − iħx(∂ψ/∂x)

因为 ∂x/∂x = 1，所以第一项就是 −iħψ。

第三步：相减
(x̂p̂ − p̂x̂)ψ = [−iħx(∂ψ/∂x)] − [−iħψ − iħx(∂ψ/∂x)]
= −iħx(∂ψ/∂x) + iħψ + iħx(∂ψ/∂x) = iħψ

含导数的两项刚好抵消，只剩下 iħψ。

因为对任意 ψ 都成立，就可以把 ψ 约掉，写成算符恒等式：

★ 正则对易关系（量子力学的基石） [ x̂ , p̂ ] = x̂p̂ − p̂x̂ = iħ
这个结果为什么惊人

右边不是零，而且不含 ψ、不含 x——是一个纯常数 iħ。

如果 ħ = 0（经典极限），右边就是 0，位置和动量就对易了，一切回到经典力学。所以"经典物理"就是"ħ 小到可以忽略"的极限——讲义 p24 明确说了这一点。

ħ ≠ 0 是整个量子世界怪异性的唯一来源。

p22算符的性质（二）：厄米性

原文翻译

厄米性 (Hermiticity)：

如果一个算符 Ô 满足下列关系，就称它是厄米的：

∫ψi*(x) Ô ψj(x) dx = [∫ψj*(x) Ô ψi(x) dx]*

  • 厄米算符的所有本征值都是实数。（作为练习证明它。）
  • 所有对应于物理可观测量的量子力学算符都是厄米的，并且有实数本征值。
  • 例如，薛定谔方程以能量为本征值。哈密顿矩阵是厄米的。

公式解析 · 厄米性条件

厄米算符的定义 ∫ ψi* Ô ψj dx  =  [ ∫ ψj* Ô ψi dx ]*
符号名称含义
Ô算符被检验的算符
[ … ]*整体复共轭注意星号在整个积分外面——先算完积分，再取共轭
ψi, ψj任意两个函数关系必须对所有合法函数对成立

意思是：把算符"挪到"积分的另一边（从作用于 ψj 变成作用于 ψi），结果只差一个复共轭。用狄拉克符号写更清楚：⟨i|Ô|j⟩ = ⟨j|Ô|i⟩*。

讲解 · 为什么物理上必须厄米

一句话理由：因为测量结果必须是实数

你用尺子量长度，读数是 3.5 cm，不可能是 "3.5 + 2i cm"。任何实验仪器的读数都是实数。

而 p37 的公设 3 说：测量得到的只能是算符的本征值。所以：

测量值必须实 ⟹ 本征值必须实 ⟹ 算符必须厄米

厄米性不是数学上的装饰，它是"这个算符能代表一个可测量的物理量"的准入条件。

拓展 · 证明"厄米算符的本征值是实数"（讲义留的练习）

设 Ôψ = aψ，且 ψ 已归一化（∫ψ*ψ = 1）。

证明只要三行

① 左边：在厄米性定义里取 i = j：

∫ψ*Ôψ dx = ∫ψ*(aψ) dx = a∫ψ*ψ dx = a

② 右边：

[∫ψ*Ôψ dx]* = [a]* = a*

③ 厄米性要求两者相等：

a = a*　⟹　一个数等于它自己的复共轭，只能说明它的虚部为零　⟹　a 是实数　∎

拓展 · 厄米性的另外两个后果（都很重要）
  1. 不同本征值对应的本征函数自动正交——这就是 p18 那条性质的来源。你不需要额外假设正交，它是厄米性的推论。
  2. 厄米矩阵一定可以被酉变换对角化——这保证了 SCF 里每一轮对角化 Fock 矩阵都能成功，且得到实数轨道能。如果 Fock 矩阵不是厄米的，整个量子化学计算就没法做了。

实数情形的简化：当所有函数和算符都是实的（分子计算里常见），厄米性退化成对称性：Fij = Fji。这就是为什么程序里 Fock 矩阵只存下三角——上三角靠对称性推出来，直接省一半内存。

一个动量确定为 p 的自由粒子，波函数是平面波 ψ = eikx，其中 k = p/ħ（由 de Broglie）。

我们希望动量算符作用上去能"取出" p：p̂ψ = pψ。试一试 ∂/∂x：

∂/∂x eikx = ik·eikx = i(p/ħ)·eikx

差了个因子 i/ħ。要抵消它，需要乘以 ħ/i = −iħ（因为 1/i = −i）。所以：

p̂x = −iħ ∂/∂x　　⟹　　p̂x eikx = −iħ·i(p/ħ)eikx = p eikx　✔

那个 −i 的作用就是保证动量算符是厄米的（本征值是实数）。单独的 ∂/∂x 是反厄米的（本征值纯虚），乘上 −i 之后才变厄米。

推导 · p31 的第二题 [x̂, Ĥ]（有重要物理含义）

分两部分算

① [x̂, V̂] = 0：因为 V̂ 只是"乘以 V(x)"，而"乘以 x"和"乘以 V(x)"顺序无所谓（普通乘法可交换）。

② [x̂, K̂]：K̂ = p̂²/2m，用上面刚算过的 [x̂,p̂²] = 2iħp̂：

[x̂, K̂] = (1/2m)[x̂,p̂²] = (1/2m)(2iħp̂) = (iħ/m)p̂　✔ 与讲义一致

拓展 · 这个结果就是"量子版的 v = p/m"（Ehrenfest 定理）

量子力学中，任意可观测量的期望值随时间的变化率是：

d⟨Â⟩/dt = (i/ħ)⟨[Ĥ, Â]⟩

取 Â = x̂，代入我们刚算的 [x̂,Ĥ] = (iħ/m)p̂（注意 [Ĥ,x̂] = −[x̂,Ĥ]）：

d⟨x⟩/dt = ⟨p⟩/m

这就是"速度 = 动量/质量"，只不过现在是对期望值成立。同理，第三题 [p̂,Ĥ] = −iħ(∂V/∂x) 会给出 d⟨p⟩/dt = −⟨∂V/∂x⟩ = ⟨F⟩，正是牛顿第二定律 F = dp/dt。

这就是 Ehrenfest 定理：量子力学的期望值遵守经典力学方程。它解释了为什么宏观物体看起来服从牛顿定律——不是量子力学在宏观失效，而是期望值本来就满足经典方程。

另一个推论：如果某个算符与 Ĥ 对易（[Ĥ,Â] = 0），那么 d⟨Â⟩/dt = 0——这个量守恒。这就是 p59 说"自由原子和离子的角动量 L、S 是守恒的"的来源。

  2. 概率必须是实数。Ψ*Ψ 的虚部自动为零。
  3. 类比波动：在经典波动中，能量密度也正比于振幅的平方（声强 ∝ 压强振幅²，光强 ∝ 电场振幅²）。Born 借用了这个思路。

量子力学中的测量过程是"主动的"：测量时我们把波函数塌缩到被测性质的算符的某个本征值上！初始波函数因此被摧毁（波函数中包含的所有其他信息都丢失了）。

爱因斯坦关于测量在量子力学中重要性的一个提问："你真的认为，当我们不看月亮的时候，月亮就不在那里吗？"

薛定谔猫佯谬：把一只猫和一瓶毒气放进盒子。毒气可以被一个机制随机释放。在打开盒子之前，我们不知道猫是死是活。"打开盒子" = 量子力学中的测量过程。如果重复这个测量很多次，那么大约 50% 的情况下猫是活的。

"叠加"的正确理解

错误理解：❌ "猫要么是活的要么是死的，只是我们不知道。"（这是经典的无知，不是量子叠加）

正确理解：✔ 在测量之前，猫处于一个既不是活也不是死的新状态，这个状态由 Ψ活 和 Ψ死 的相干叠加描述。

怎么区分这两者：靠干涉。如果只是"我们不知道"，两种可能性就是简单相加，不会干涉；如果是真正的量子叠加，两个分支之间会产生干涉条纹（双缝实验就是证据）。

为什么现实中的猫不会处于叠加态：退相干 (decoherence)。一个宏观物体与环境（空气分子、光子、热辐射）有海量的相互作用，叠加态在 10⁻²⁰ 秒内就被"测量"掉了。所以薛定谔的猫是一个思想实验，不是可实现的实验。

在球坐标系 (r,θ,φ) 中，梯度 ∇ 是：

∂/∂x = sinθcosφ(∂/∂r) + (cosθcosφ/r)(∂/∂θ) − (sinφ/(rsinθ))(∂/∂φ)

∂/∂y = sinθsinφ(∂/∂r) + (cosθsinφ/r)(∂/∂θ) + (cosφ/(rsinθ))(∂/∂φ)

∂/∂z = cosθ(∂/∂r) − (sinθ/r)(∂/∂θ)

把上面三个偏导数平方后相加，得到球坐标下的拉普拉斯算符：

∇² = ∂²/∂r² + (2/r)(∂/∂r) + (1/r²)(∂²/∂θ²) + (1/r²)cotθ(∂/∂θ) + (1/(r²sin²θ))(∂²/∂φ²)

L̂² = −ħ²[∂²/∂θ² + cotθ(∂/∂θ) + (1/sin²θ)(∂²/∂φ²)]

因此拉普拉斯算符可以写成：

∇² = ∂²/∂r² + (2/r)(∂/∂r) − (1/(r²ħ²))L̂²

哈密顿量变成：

Ĥ = −(ħ²/2me)[∂²/∂r² + (2/r)(∂/∂r) − (1/(r²ħ²))L̂²] + V(r)

讲解 · p57 的三个要点，逐个说清

① "我们真的能区分它们吗？" —— 全同粒子

答案是不能。两个电子是全同粒子 (identical particles)——它们没有任何可以区分的内在标签（质量、电荷、自旋大小全都一样）。

我们在纸上写"电子 1"和"电子 2"只是记账的需要，物理上这个编号必须没有可观测后果。这个要求会在 p65 变成泡利原理。

② "个别的 li 不是好量子数"

回想 p50：[Ĥ,L̂²] = 0 的前提是 V = V(r)，即球对称。

现在 1/r₁₂ 这一项不是球对称的（它依赖于两个电子的相对位置，而 r₁₂ 这个矢量不是从坐标原点出发的——p61 明确说了这一点）。所以：

[Ĥ, l̂₁²] ≠ 0　⟹　l₁ 不守恒 ⟹ 不是好量子数
③ "但总角动量 L = l₁ + l₂ 守恒"

为什么总的守恒而分量不守恒？因为 1/r₁₂ 只依赖两个电子的相对位置。如果你把整个体系（两个电子一起）绕核转一个角度，r₁₂ 不变，r₁、r₂ 也不变，哈密顿量完全不变。

所以体系整体仍然有球对称性 ⟹ 总角动量守恒。但如果你只转一个电子（不动另一个），r₁₂ 就变了，能量就变了 ⟹ 单个电子的角动量不守恒。

物理图像：两个电子在互相排斥中不断交换角动量，各自的角动量在涨落，但总和是恒定的——就像两个溜冰者互相推拉，各自转速在变，总角动量守恒。

拓展 · "好量子数"的准确定义

好量子数 (good quantum number) = 对应算符与 Ĥ 对易的那个量子数 = 守恒量 = 可以用来标记本征态的标签。

体系好量子数
氢原子（单电子）n, l, ml, ms（全都是好的）
多电子原子（轻元素）L, S, J, MJ（总的才好）→ 这就是光谱项符号 2S+1LJ 的来源
多电子原子（重元素）只有 J, MJ（自旋-轨道耦合太强，L 和 S 都不再分别守恒 → jj 耦合）
分子S 和点群不可约表示（没有球对称，L 完全失效）

这解释了一个你可能困惑过的事：为什么原子光谱用 3P₂ 这种符号，分子轨道却用 a₁、t₂g？因为对称性不同，好量子数就不同。p66 会出现 1S₀，p69 会出现 3S₁ ——那正是原子的光谱项符号。

p58–59总角动量与总自旋

原文翻译（p58）

多电子原子的总轨道角动量：L = l₁ + l₂ + l₃ + … = Σi=1n li

多电子原子的总自旋角动量：S = s₁ + s₂ + s₃ + … = Σi=1n si

L 和 S 的 z 分量由下式给出：

Lz = Σlzi = Σmi = M　；　Sz = Σszi = Σmsi = MS

注意 L 和 S 的 z 分量是按标量相加的（即像普通数字一样相加）。

原文翻译（p59）
  • 因此，多电子原子的态可以有如下轨道角动量量子数：
    L = 0,1,2,3…　；　Lz = ML = 0, ±1, ±2, ±3, …, ±L
  • 尽管如此，每个电子的 li 仍是一个有用的量子数，因为它给出了电子 i 的平均轨道角动量
  • 通过对电子-电子相互作用取平均，我们可以得到一个近似的径向力哈密顿量
  • 对自由原子和离子，角动量 (L, S) 是守恒的

讲解 · "矢量相加"与"标量相加"的区别（p58 特意强调的点）

这是初学者最容易搞错的地方
量怎么加为什么
z 分量（ML, MS）直接相加（标量）

例子：两个 p 电子（l₁ = l₂ = 1）

不能简单说"L = 1+1 = 2"——那只是最大的一种可能。

例子：两个电子的自旋（s₁ = s₂ = ½）

总 S：|½−½| = 0，到 ½+½ = 1，即 S = 0 或 1。

S多重度 2S+1名称MS 可取值

你在 p66 会看到 1S₀，p69 会看到 3S₁。这个符号读法是：

He 基态 1S₀：两个电子都在 1s（l=0），所以 L=0（S）；自旋必须反平行（泡利），S=0，多重度 = 1；J = 0+0 = 0。

He 激发态 1s2s 的三重态 3S₁：L 仍是 0（两个 s 轨道），但自旋可以平行，S=1，多重度 = 3；J = 0+1 = 1。

p60–62轨道近似与平均场近似：本讲的第一个关键近似

原文翻译（p60）

多电子哈密顿量的真实波函数依赖于所有电子的坐标。例如 He 的哈密顿量：

Ĥ = [−½∇₁² − 2/r₁] + [−½∇₂² − 2/r₂] + 1/r₁₂

有如下形式的本征态：ψ(r₁,θ₁,φ₁,σ₁; r₂,θ₂,φ₂,σ₂)

轨道近似在于把上面的波函数写成有效单电子波函数的乘积：

ψ(r₁,θ₁,φ₁,σ₁; r₂,θ₂,φ₂,σ₂) ≈ φ₁(r₁,θ₁,φ₁,σ₁)·φ₂(r₂,θ₂,φ₂,σ₂)

这是一个近似，因为精确波函数可能有复杂得多的形式（它可能包含二次项、混合变量项等），但如果我们希望对真实分子求解 Ĥ，我们别无选择……

原文翻译（p61）· 轨道近似的后果
  • 上述哈密顿量中的 r₁₂ 项破坏了球对称性，因为矢量 r₁₂ = r₁ − r₂ 不是从坐标原点出发的
  • 这一项使得上述哈密顿量无法精确求解 ⟹ 需要进一步的近似
  • 平均场近似 (Mean-Field Approximation, MFA)：每个电子在"原子核 + 所有其他电子"产生的平均静电场中运动
  • MFA 忽略了电子间真正的关联运动（即电子相关）。而在现实中——电子会尽可能地互相避开，因为它们互相排斥
原文翻译（p62）
  • 有了这个近似，就意味着我们仍然可以像对氢原子那样使用 li = 0,1,2,3…
  • 于是我们对每个电子得到四个量子数：ni, li, mi, szi
  • 这个单电子近似被称为轨道近似，它与泡利不相容原理一起解释了元素周期表

公式解析 · 轨道近似

★ 轨道近似（Hartree 乘积） Ψ(1, 2, …, N) ≈ φ1(1) · φ2(2) · … · φN(N)
符号名称含义
Ψ(1,2,…)多电子波函数依赖所有电子的坐标，共 4N 个变量（每个电子 3 个空间坐标 + 1 个自旋）
φi轨道这就是"轨道"的严格定义：一个单电子波函数。它只依赖一个电子的坐标。
数字 (1)电子编号是"电子 1 的全部 4 个坐标"的速记：(1) ≡ (r₁,θ₁,φ₁,σ₁)
σ自旋坐标希腊字母 sigma。只能取两个值（α 或 β）
"轨道"这个概念其实是个近似产物 —— 这一点非常重要

严格的多电子波函数不能写成轨道的乘积。"轨道"只在轨道近似下才存在。

所以当你在 GaussView 里看 HOMO 图时，你看的是一个近似模型里的构件，不是一个可以直接测量的物理量。（电子密度 ρ 才是可观测的。）

这也是为什么第 3 讲 p46、p61 会说"轨道不唯一"——任意幺正变换后的轨道给出完全相同的总能量和电子密度，但轨道的形状可以完全不同（正则轨道 vs 定域轨道 vs 天然轨道）。物理内容在密度里，不在轨道里。

讲解 · 平均场近似的直观图像

用一个比喻

真实情况：两个人在一个小房间里走动，眼睛盯着对方，随时调整路线避免相撞。

平均场：两个人都蒙上眼，只被告知"对方平均而言在房间中央偏左"。于是各自按这个平均信息规划路线。结果：他们会比实际情况更容易"撞上"——所以 HF 高估了电子间的排斥，能量偏高。

这就是 Ecorr = E精确 − EHF < 0（相关能永远是负的）的物理来源。第 4 讲 p3 会正式给出这个定义。

拓展 · 相关能有多大？（一个必须建立的数量感）
量典型大小
分子总能量−100 到 −3000 Hartree
相关能约占总能量的 1%（每对电子约 −0.04 Hartree ≈ −25 kcal/mol）
一根化学键0.1–0.2 Hartree（60–120 kcal/mol）
"化学精度"要求0.0016 Hartree（1 kcal/mol）

关键洞察：相关能虽然只占总能量的 1%，但它和化学键能是同一个量级。所以在"总能量"上 HF 已经对了 99%，但在"化学"上它可能完全错。这就是为什么第 4 讲整讲都在处理这 1%。

p63–64电子自旋

原文翻译（p63）
  • 类比于轨道角动量算符，我们有自旋角动量算符 ŝ² 和 ŝz。它们量化"电子绕自身转动轴的角运动"
  • ŝ² 和 ŝz 对一个电子的本征函数记作 α 和 β：

∫α*α dσ = ∫β*β dσ = 1　（归一化）

∫α*β dσ = ∫β*α dσ = 0　（正交）

ŝ²α = s(s+1)α　；　ŝ²β = s(s+1)β

ŝzα = +½α　；　ŝzβ = −½β

原文翻译（p64）
  • 因此，自旋量子数 s = ½ 的自旋波函数有自旋磁量子数 ms = +½ 或 ms = −½
  • 我们用小写字母表示单个电子的自旋量子数（s 和 ms），用大写字母表示多电子体系的总自旋量子数（S 和 MS）

公式解析 · 自旋的符号系统

符号名称含义
α自旋向上函数俗称 "spin up"，↑。ms = +½
β自旋向下函数"spin down"，↓。ms = −½
σ自旋坐标一个只能取两个值的"假坐标"。∫…dσ 实际上是"对两个可能值求和"，不是真的积分。
ŝ²自旋平方算符本征值 s(s+1)ħ²，对电子 s=½ 恒定，所以 s(s+1) = ¾
ŝz自旋 z 分量算符本征值 ±½ħ（讲义用原子单位，ħ=1）
s自旋量子数对电子永远是 ½，不能改变——它是电子的固有属性，像质量和电荷一样
"电子绕自身转动"这个说法是错的（讲义用了引号，是有原因的）

讲义写的是 "the angular motion of electron around its own axis of rotation"，加了引号——因为这只是一个历史比喻。

自旋不是真的自转。理由：

  • 电子是点粒子（实验上半径 < 10⁻¹⁸ m），点没有"轴"可以绕
  • 如果按经典自转计算，电子表面速度会远超光速
  • 自转一圈（360°）后自旋波函数会变成 −1 倍，转 720° 才回到原样——经典物体没有这种性质

自旋的真正来源：它是相对论性量子力学的必然结果。Dirac 在 1928 年把相对论和量子力学结合时，自旋 ½ 自动地从方程里冒出来，不需要任何额外假设。在非相对论的薛定谔方程里，自旋只能靠手工塞进去——这正是讲义 p63 在做的事。

拓展 · 自旋函数的正交归一为什么这么重要

∫α*β dσ = 0 这一条，看起来平平无奇，但它在后面会反复决定哪些积分等于零：

出现的地方它做了什么
p43（H₂ 的双电子积分）交换积分变成 0，因为两个电子自旋不同
p44（Slater 行列式能量规则）"Kij 只对自旋相同的电子对非零"——原因就是这条正交性
第 4 讲 p14⟨singlet|Ĥ|triplet⟩ = 0，不同自旋态不混合
Hund 第一规则为什么自旋平行的组态能量更低（见下面）

Hund 规则的量子力学解释：交换积分 K > 0，而能量表达式里是 −K（p44）。K 只在自旋相同时出现，所以自旋平行的电子对会得到一个额外的 −K 稳定化。这就是"洪特规则：先单占再配对"的严格来源。p70 会算出 ΔE = −2K 这个具体结果。

p65泡利原理：反对称性要求

原文翻译
  • 泡利原理指出：电子波函数 ψ(1,2,…) 对任意一对电子的交换是反对称的：

P̂₁₂ ψ(1,2,…) = ψ(2,1,…)

ψ(1,2,…) = −ψ(2,1,…)

  • 注意，概率密度 ψ*(1,2,…)ψ(1,2,…) 不因交换算符而改变（只要电子 1 和 2 是全同的）：
    ψ*(1,2,…)ψ(1,2,…) = ψ*(2,1,…)ψ(2,1,…)
    因为概率密度是物理上可测量的量（可观测量）
  • 在轨道近似下，反对称性要求由波函数的 Slater 行列式形式来满足

公式解析 · 反对称性要求

★ 泡利原理（费米子的反对称性） P̂12 Ψ(1, 2, 3, …) = Ψ(2, 1, 3, …) = − Ψ(1, 2, 3, …)
符号名称含义
P̂12交换算符permutation operator。把电子 1 和电子 2 的全部坐标（空间 + 自旋）对调。
负号反对称这个负号就是泡利原理的全部内容。它是费米子（电子、质子、中子，所有半整数自旋粒子）的普遍性质。

讲解 · 逻辑链条：为什么必须是 ±1，为什么电子选 −1

第一步：交换两次必须回到原样

P̂₁₂P̂₁₂Ψ = Ψ（换两次等于没换）。所以如果 P̂₁₂Ψ = cΨ，则 c² = 1 ⟹ c = +1 或 c = −1。只有两种可能。

第二步：概率密度必须不变（全同粒子）

因为电子无法区分，"电子 1 在 A、电子 2 在 B" 和 "电子 2 在 A、电子 1 在 B" 必须是同一个物理状态，概率密度必须相同。

|cΨ|² = |c|²|Ψ|² = |Ψ|²　⟹　|c| = 1　✔ 两种可能都满足

第三步：自然界的选择
c 的值粒子类型自旋例子
+1（对称）玻色子 boson整数（0,1,2…）光子、声子、⁴He、W/Z 玻色子
−1（反对称）费米子 fermion半整数（½,3/2…）电子、质子、中子、³He

这是一条实验事实（由"自旋-统计定理"在相对论量子场论中证明）。电子是费米子，所以取 −1。

"泡利不相容原理"其实是这条的推论，不是原理本身

你在中学学的"一个轨道最多两个电子、自旋相反"，是反对称性的一个推论：

证明只要两行

假设两个电子处于完全相同的自旋轨道 φ（同样的空间部分 + 同样的自旋）。那么：

Ψ(1,2) = φ(1)φ(2)

交换后：Ψ(2,1) = φ(2)φ(1) = Ψ(1,2)（乘法可交换）

但反对称性要求 Ψ(2,1) = −Ψ(1,2)。两者同时成立只能是：

Ψ = −Ψ　⟹　Ψ = 0

波函数恒为零 = 这个状态不存在。所以两个电子不能占据完全相同的自旋轨道。∎

注意措辞：不是"不允许"，而是"这样的状态在数学上不存在"。这比"禁令"更强。

拓展 · 反对称性的三个惊人后果
  1. 物质的稳定性与体积。如果电子是玻色子，所有电子都会掉进 1s 轨道，原子会小得多，也不会有化学。"物质占据空间"这件事完全来自泡利不相容原理产生的"交换排斥"，而不是电子之间的静电排斥。
  2. 元素周期表。壳层结构完全来自"每个轨道只能放 2 个电子"。p62 明说了这一点。
  3. 费米空穴 (Fermi hole)：反对称性使得自旋相同的两个电子在空间上自动互相避开——因为当 r₁ → r₂ 且自旋相同时，Ψ → 0。这是一种"免费的相关"，HF 已经包含了它（通过交换积分 K）。但 HF 对自旋相反的电子完全没有这种避让——这正是"库仑相关"，是第 4 讲要补的东西。

p66–71氦原子的基态与激发态：J 与 K 积分登场

原文翻译（p66）· He 基态
  • 因为两个电子不可区分，我们不能给它们贴标签。下面两个波函数是等价的：
    ψ(1,2) = 1s(r₁)α₁ · 1s(r₂)β₂
    ψ(2,1) = 1s(r₂)α₂ · 1s(r₁)β₁
  • 它们之间有两种可能的线性组合：
    Ψ+ = ψ(1,2) + ψ(2,1)
    Ψ− = ψ(1,2) − ψ(2,1)
  • 交换算符作用在 Ψ+ 和 Ψ− 上给出：
    P̂₁₂Ψ+ = Ψ+　；　P̂₁₂Ψ− = −Ψ−

只有 Ψ− 符合泡利原理！L=0, S=0, J=0 ⟹ 1S₀

Ψ(1S₀) = (1/√2)·1s(r₁)1s(r₂)·[α₁β₂ − α₂β₁]

讲解 · 注意基态波函数的结构

He 基态波函数的分解 Ψ = 1s(r1)1s(r2) × (1/√2)[α1β2 − α2β1]
　　　空间部分：对称　　　　　自旋部分：反对称
这是本讲最需要理解的一个"配对规则"

总波函数 = 空间部分 × 自旋部分，而总波函数必须反对称。所以只有两种搭配：

空间部分自旋部分总波函数自旋态
对称 (S)反对称 (A)A ✔单重态 S=0
反对称 (A)对称 (S)A ✔三重态 S=1
对称对称S ✘不允许
反对称反对称S ✘不允许

（记忆法：对称×反对称 = 反对称，就像 (+1)×(−1) = −1）

这个规则直接导致了 p69–p71 的结论：三重态和单重态空间波函数不同 ⟹ 电子间平均距离不同 ⟹ 能量不同。自旋本身不产生能量，但它通过泡利原理约束了空间分布，从而间接决定了能量。

原文翻译（p67–69）· He 激发态 1s2s

p67：现在考虑 He 的第一激发态 1s2s。这种情况下，因为电子在不同的轨道上且不可区分，空间本征函数必须写成 1s(r₁)2s(r₂) 和 1s(r₂)2s(r₁) 的线性组合。这给出对称和反对称两组空间波函数：

(1/√2)[1s(r₁)2s(r₂) − 1s(r₂)2s(r₁)]　—— 反对称

α₁α₂ ；　β₁β₂ ；　(1/√2)[α₁β₂ + α₂β₁] —— 这三个是对称的

(1/√2)[α₁β₂ − α₂β₁] —— 这个是反对称的

讲解 · 为什么三重态比单重态低（Hund 第一规则的严格证明）

从 p70 的两个能量式看
态空间波函数能量相对高低
3S₁ 三重态反对称E1s+E2s+J − K低
1S₀ 单重态对称E1s+E2s+J + K高

因为 K > 0，所以 ΔE = −2K < 0，三重态更稳定。

物理原因（这才是关键，不要只记公式）

三重态的空间波函数是反对称的：Ψ空间 = (1/√2)[1s(1)2s(2) − 1s(2)2s(1)]

让两个电子跑到同一点（r₁ = r₂ = r）：

Ψ空间 = (1/√2)[1s(r)2s(r) − 1s(r)2s(r)] = 0

波函数在"两电子重合"处严格为零 ⟹ 两个电子永远不会靠得太近 ⟹ 平均排斥能更低 ⟹ 能量更低。

这个"电子相同自旋时自动互相回避"的区域叫 Fermi 空穴 (Fermi hole)。

对称的单重态则相反：r₁ = r₂ 时 Ψ = √2·1s(r)2s(r) ≠ 0，电子可以靠得很近，排斥能更高。

要记住的核心结论

交换能不是一种"新的作用力"。自旋之间没有直接的能量相互作用。

真实机制是：自旋 → 通过泡利原理约束了空间波函数的对称性 → 改变了电子的空间分布 → 改变了库仑排斥能。

所以：磁性归根到底是静电现象。这是理解所有磁交换耦合（包括你以后会算的 BS-DFT）的基础。

讲解 · 什么是"穿透 (penetration)"

机制：屏蔽 + 穿透

屏蔽 (shielding)：内层电子挡在外层电子和原子核之间，让外层电子感受到的核电荷从 Z 降到有效核电荷 Zeff。

Zeff = Z − σ　（σ = 屏蔽常数）

穿透 (penetration)：如果一个轨道的电子有一部分几率出现在内层电子云的里面（更靠近核），它就"穿透"了屏蔽，感受到更大的 Zeff，能量更低。

回到 p52 的离心势垒：l 越大，离心势垒越强，电子越被推离核，穿透越差。所以：

穿透能力：s (l=0) > p (l=1) > d (l=2) > f (l=3)
⟹ Zeff：s > p > d > f　⟹ 能量：Ens < Enp < End < Enf
证据：看 p55 那张径向函数图

3s 有 2 个径向节面，意味着它在靠近核的地方还有两个小的"驼峰"——那些驼峰就是穿透部分。

3p 有 1 个节面（1 个内层驼峰），3d 有 0 个节面（没有内层驼峰，全部集中在外面）。

节面数 = n−l−1，l 越大节面越少，内层驼峰越少，穿透越差。这三件事是同一件事的三种说法。

拓展 · 4s 与 3d 的著名"陷阱"

你在中学学的填充顺序是 4s 先于 3d（Aufbau 原理）。但真相更微妙：

情形谁的能量低
中性 K、Ca 原子（3d 空）4s < 3d ⟹ 电子先填 4s　✔ Aufbau 成立
过渡金属原子（Sc 之后，3d 开始被占据）3d < 4s！一旦 3d 上有电子，3d 就急剧下降到 4s 以下
所有过渡金属离子（Fe²⁺, Cu²⁺…）3d < 4s ⟹ 电离时先失去 4s 电子

所以 Fe²⁺ 是 [Ar]3d⁶，不是 [Ar]3d⁴4s²。这是配位化学里的基本事实。

为什么会这样：4s 和 3d 的能量本来就非常接近，谁高谁低取决于 Zeff 和电子间排斥的细微平衡。3d 轨道比 4s 更紧凑，所以 3d–3d 之间的电子排斥（J 积分）比 4s–4s 大得多。当 3d 上电子多起来时这个排斥就变得重要。

对你的计算的实际影响：这就是过渡金属体系 SCF 难收敛的根本原因——3d 和 4s 几乎简并，SCF 迭代时电子在两者之间来回跳，永远不收敛。第 3 讲 p66–68 的收敛技巧（damping、level shift、DIIS）就是为了对付这个。

没有 BO 近似，就没有"分子结构"这个概念——因为核和电子会纠缠成一个整体，你无法说"这个分子的 C–C 键长是 1.54 Å"。

拓展 · BO 近似什么时候崩（第 1 讲 p12 提到的"未来方向 4"）

BO 的成立条件是：不同电子态之间的能隙远大于核运动的能量尺度。当两个电子态的势能面靠近甚至相交时，它就失效了。

失效场景后果
锥形交叉 (conical intersection)两个势能面在多维空间中相交成锥形。分子在这里可以在 fs 时间内无辐射地从激发态跳回基态。光化学、荧光量子产率、视觉的第一步、DNA 的光稳定性全靠它。
Jahn–Teller 效应电子简并态与核运动耦合，导致分子自发畸变（如 Cu²⁺ 八面体配合物的四角畸变）。
非绝热跃迁 (surface hopping)需要专门的动力学方法（如 Tully 表面跳跃）

数值上的提示：当你算 TD-DFT 发现 S₀ 和 S₁ 能量非常接近、或者 SCF 在某个几何构型附近怎么都不收敛时，很可能就是撞上了 BO 失效区。

p80–85Hartree–Fock 能量与 Fock 算符

原文翻译（p80–82）

p80：引入了如下记号：

ĥi = −∇i² − ΣA ZA/|ri−rA|　；　ĝij = 1/|ri−rj|

我们现在来求哈密顿量的期望值（即总能量）：E = ⟨Ψ(1,2,…,N)|Ĥ|Ψ(1,2,…,N)⟩

p81（Hartree–Fock 近似的三句话总结）：

  • 电子在"所有原子核和其余电子"产生的平均静电场中运动
  • 每个电子并不显式地感受到其他电子的存在，也不知道其他电子在哪里
  • 而事实上，两个电子彼此靠得很近的概率是非常小的

p82：把 Ĥ 的三部分分别代入期望值，得到三项之和（推导略）。

原文翻译（p83）· ★ 闭壳层 HF 能量表达式

经过一些数学推导后，前面的方程被简化为（对闭壳层分子）：

E = 2ΣiN/2 Hi + ΣiN/2ΣjN/2 (2Jij − Kij) + VNN

其中：

Hi = ⟨φi(1)|ĥi|φi(1)⟩　—— core Hamiltonian = 单电子积分

Jij = ⟨φi(1)φj(2)|ĝij|φi(1)φj(2)⟩

Kij = ⟨φi(1)φj(2)|ĝij|φj(1)φi(2)⟩

} = 电子排斥积分 = 双电子积分

VNN = ½ΣAΣB≠A ZAZB/|rA−rB|

公式解析 · 闭壳层 HF 总能量（考试必考，逐项理解）

★ 闭壳层（RHF）总能量 E = 2 ΣiN/2 Hi  +  ΣiN/2 ΣjN/2 (2Jij − Kij)  +  VNN
符号名称含义
闭壳层closed shell所有电子都成对（每个空间轨道放 2 个自旋相反的电子）。N 个电子占 N/2 个空间轨道。
N/2占据轨道数求和上限。注意求和是对空间轨道，不是对电子。
前面的 2占据数每个空间轨道有 2 个电子，所以单电子能量要 ×2
Hi单电子积分轨道 i 上一个电子的动能 + 被核吸引的能量。是负数（吸引占优）
2Jij库仑排斥见下面的计数说明
−Kij交换稳定化负号！交换项降低能量。而且只有 1 个 K 对应 2 个 J——因为交换只发生在自旋相同的电子之间。

讲解 · 为什么是 "2J − K"（数电子对的方法）

考虑两个空间轨道 φi、φj，各放 2 个电子，共 4 个电子

把它们标记为：i↑、i↓、j↑、j↓。

跨轨道的电子对（i 里的一个 × j 里的一个）共有 2×2 = 4 对：

电子对自旋关系有 J？有 K？
i↑ 与 j↑相同✔✔
i↓ 与 j↓相同✔✔
i↑ 与 j↓相反✔✘（自旋积分为 0）
i↓ 与 j↑相反✔✘

总计：4 个 Jij，2 个 Kij。

而公式里 ΣiΣj 对每一对 (i,j) 数两次（(i,j) 和 (j,i)），所以每次贡献 2Jij − Kij，两次加起来正好是 4J − 2K　✔

最重要的一条规则（第 3 讲 p44 会直接考）
Jij 对任何电子对都非零，与自旋无关
Kij 只对自旋相同的电子对非零

这条规则来自 p63 的 ∫α*βdσ = 0。记住它，你就能手工写出任何 Slater 行列式的能量表达式——这是本课唯一需要动笔计算的题型。

原文翻译（p84）· Fock 算符的引入
  • 注意 φi 是一个分子轨道，其形式尚待确定。确定 φi 需要按变分原理，对分子轨道系数最小化总能量。这导出下列方程：

F̂ φi(1) = εi φi(1)

其中 εi 是轨道能，F̂ 称为 Fock 算符，可表示为：

F̂ = −∇₁² − ΣA ZA/|r₁−rA| + ΣjN/2 [2Ĵj(1) − K̂j(1)]

原文翻译（p85）· Ĵ 与 K̂ 作为算符

Ĵj(1) f(1) = f(1) ∫ |fj(2)|² / |r₁−r₂| dr₂

K̂j(1) f(1) = fj(1) ∫ fj*(2) f(2) / |r₁−r₂| dr₂

总能量是各个轨道能量之和：E = ΣiNMO γiεi，其中 γi 是轨道 i 的占据数。

公式解析 · Fock 算符（HF 方法的核心）

★ Fock 算符 F̂(1) = ĥ(1)  +  Σj占据 [ 2Ĵj(1) − K̂j(1) ]
符号名称含义
F̂Fock 算符一个有效的单电子哈密顿量。它把"这个电子 + 其他所有电子的平均效应"打包成一个只作用于单个电子的算符。
ĥ(1)core 部分动能 + 核吸引，与其他电子无关
Ĵj库仑算符见下面的解释。是个"乘法算符"——先算出一个势场，再乘上去
K̂j交换算符是个非局域算符——它把 f 换成了 fj，作用结果依赖于 f 在全空间的值
εi轨道能希腊字母 epsilon。Fock 算符的本征值。p47（第 3 讲）的 Koopmans 定理会赋予它物理意义。
γi占据数RHF 里是 2（双占据）或 0（空轨道）

讲解 · Ĵ 和 K̂ 作为算符的区别（p85 的两个式子）

Ĵj：局域的、有经典图像的
Ĵj(1) f(1) = f(1) · [ ∫ |φj(2)|²/r12 dr2 ]

方括号里的东西是一个普通的函数（依赖 r₁）——它就是"轨道 j 的电荷云在 r₁ 处产生的静电势"。

所以 Ĵ 的作用就是"乘以一个静电势"。完全经典，可以画出来。

K̂j：非局域的、没有经典图像的
K̂j(1) f(1) = φj(1) · [ ∫ φj*(2)f(2)/r12 dr2 ]

注意：作用之后出来的是 φj(1)，不是 f(1)！被作用的函数 f 跑到积分里面去了。

这意味着 K̂ 在 r₁ 处的作用效果，取决于 f 在所有 r₂ 处的值——这就是"非局域"。

后果：

  • 交换项算起来贵（不能像库仑项那样用多极展开或快速多极方法加速）
  • DFT 的最大卖点之一就是把这个非局域的 K̂ 换成一个局域的交换泛函——这就是 DFT 比 HF 快、但也因此有"自相互作用误差"的根源
  • 杂化泛函（B3LYP 含 20% HF 交换）就是在"精确但贵的非局域交换"和"便宜但近似的局域交换"之间取折中
HF 方程的"鸡生蛋"困境 —— 这是理解 SCF 的关键

看清楚这个逻辑循环：

要解 F̂φi = εiφi 得到轨道 φi
↓ 但是
F̂ 里含有 Ĵj 和 K̂j，它们由轨道 φj 构造
↓ 所以
要知道轨道，才能构造 F̂；要有 F̂，才能求出轨道

HF 方程不是一个普通的本征值方程，而是一个非线性的、自洽的方程。

解法就是迭代：猜一组轨道 → 建 F̂ → 解出新轨道 → 再建 F̂ → …… 直到轨道不再变化（"自洽"）。这就是 SCF (Self-Consistent Field，自洽场)，p89 的流程图。

p86–88Hartree–Fock–Roothaan 方程：从微分方程到矩阵

原文翻译（p86）

Hartree–Fock 方程很难求解。1955 年 Roothaan 提出用原子轨道的线性组合（LCAO）来表示分子轨道：

φi = ΣsN csiχs

把这个形式的 MO 代入 Hartree–Fock 方程：

ΣsN csi F̂χs = εi ΣsN csiχs

两边乘以 χt* 并积分，得到：

ΣsN csi(Fts − εiSts) = 0，　t = 1,2,3,…,N

原文翻译（p87）

其中：Fts = ⟨χt|F̂|χs⟩　；　Sts = ⟨χt|χs⟩

为使 HFR 方程有非平凡解，久期行列式必须为零：

|Fts − εiSts| = 0

前面几页高亮的方程可以用自洽场 (SCF) 过程迭代求解，使总能量收敛到一个容许的数值。这些方程构成了现代量子化学与计算化学的基础。

原文翻译（p88）

由 HFR 方程，我们需要计算积分 J 和 K，并得到系数 csi（s, i = 1,2,3,…,N）。

（重复给出 F̂、Ĵj、K̂j、φi = Σcsiχs 的表达式）

这些方程仍然相当难解，因为必须计算大量的积分。于是人们设计了更多的近似。

公式解析 · LCAO 展开

★ LCAO：分子轨道 = 原子轨道的线性组合 φi = Σs=1Nbasis csi χs
符号名称含义
φi分子轨道 (MO)要求的东西。小写 phi
χs基函数 / 原子轨道希腊字母 chi（念"卡伊"）。这就是"基组"里的那些函数——你写 6-31G(d) 时选定的就是这些 χ。它们是已知的、固定的。
csiMO 系数整个 HF 计算真正要求的唯一未知数。下标读法：基函数 s 在分子轨道 i 中的贡献。
Nbasis基函数总数决定计算量的那个 N。MO 的个数 = 基函数的个数（占据的 + 空的）
为什么 LCAO 是天才的一步

它把"求一个未知函数"（无穷维的难题）变成了"求一组未知数"（有限维的线性代数）。

化学上它也非常自然：分子里的电子大部分时间还是在某个原子附近，所以用原子轨道来搭分子轨道是合理的。你在无机化学里画的 MO 能级图，就是 LCAO 的定性版本。

公式解析 · Roothaan 方程（矩阵形式）

★ Roothaan–Hall 方程（现代量子化学的中心方程） F C = S C ε
符号名称含义与维度
FFock 矩阵N×N。Fts = ⟨χt|F̂|χs⟩。依赖于 C（这就是非线性的来源）
C系数矩阵N×N。第 i 列就是第 i 个分子轨道的系数向量。要求的东西。
S重叠矩阵N×N。Sts = ⟨χt|χs⟩。它出现的唯一原因是基函数不正交（见 p18 的警告）。对角元恒为 1（基函数归一化）。
ε轨道能对角矩阵N×N，只有对角线非零，元素是各个轨道能 εi
这个方程是怎么来的（p86 的三步，讲清楚）

第一步：把 φi = Σcsiχs 代进 F̂φi = εiφi：

Σscsi·F̂χs = εiΣscsi·χs　（c 是常数，可以提到算符外面）

第二步：左乘 χt* 并对全空间积分（这叫"投影"，就是 p36 那个技巧）：

Σscsi·⟨χt|F̂|χs⟩ = εiΣscsi·⟨χt|χs⟩

下划线的两个积分就是数（矩阵元），分别记作 Fts 和 Sts。

第三步：移项，对每个 t = 1…N 都成立，写成矩阵形式即得 FC = SCε。

整个过程把一个微分方程变成了 N 个联立线性方程。这就是量子化学能在计算机上做的全部秘密。

拓展 · S 矩阵怎么被消掉（程序里真实的做法）

FC = SCε 是"广义本征值问题"，比标准的 Ax = λx 麻烦。实际程序会先做正交化：

对称正交化（Löwdin 正交化）
  1. 对角化 S，求出 S−1/2
  2. 定义 F′ = S−1/2FS−1/2，C′ = S1/2C
  3. 方程变成标准形式：F′C′ = C′ε　✔ 直接调 LAPACK 对角化
  4. 算完再变回去：C = S−1/2C′
这里藏着一个实际会遇到的错误

如果基组里有近乎线性相关的函数（比如加了太多很弥散的 diffuse 函数），S 会有接近 0 的本征值，S−1/2 就会数值爆炸。

症状：Gaussian 会打印 Warning! Small eigenvalue of overlap matrix 或直接报 linear dependence，SCF 崩溃或收敛到胡说八道的结果。

解法：换小一点的基组、去掉多余的 diffuse 函数、或让程序自动丢掉那些病态的组合（Gaussian 的 IOp(3/59=...)、ORCA 的自动处理）。

p89–90SCF 自洽场过程

原文翻译（p89）

在"所有其他电子的平均电场"中求解一个电子的问题相对容易，HF 方法就是按一个循环依次处理每个电子（见右侧示意图）。

流程：GUESS（猜测）→ 求解电子 1 → 求解电子 2 → 求解电子 3 → … → 求解电子 N → 回到开头

算法不断更新每个电子的波函数，直到解不再变化。这个过程被称为自洽场方法。

p90：富勒烯衍生物的一个 Hartree–Fock 轨道（图）。

讲解 · SCF 循环的完整图解

"自洽 (self-consistent)"到底是什么意思

自洽 = 输入和输出一致。

你用密度 D 构造出 F，解 F 又得到新的密度 D′。如果 D′ = D，说明这组轨道"产生的平均场"恰好就是"造出这组轨道的平均场"——首尾自洽，找到了不动点。

数学上这叫不动点迭代 (fixed-point iteration)，和用牛顿法解方程是同一类思想。

拓展 · 怎么判断收敛（看 Gaussian 输出时用得上）

Gaussian 每一轮 SCF 会打印一行：

Cycle   3  Pass 1  IDiag  1:
 E= -76.0107465392  Delta-E=       -0.000234  Rises=F  Damp=F
 RMSDP= 1.23D-05 MaxDP= 8.91D-05
E=当前总能量（Hartree）
Delta-E=能量变化。默认要求 < 10⁻⁶ 或 10⁻⁸（tight）
RMSDP=密度矩阵变化的均方根（Root Mean Square Density Ptot）
MaxDP=密度矩阵元的最大变化
Rises=能量是否上升了（T 是坏信号——变分原理下能量应该单调下降到极小）

收敛后打印：SCF Done: E(RB3LYP) = -76.4089532 A.U. after 9 cycles

典型迭代次数：有机小分子 8–15 轮；过渡金属配合物可能 50–100 轮甚至不收敛（原因见 p75 的拓展：3d/4s 近简并）。第 3 讲 p66–68 有一整套救急技巧。

p91自旋限制 (RHF) 与自旋非限制 (UHF)

原文翻译

自旋限制 (Spin-restricted)：每个占据分子轨道有两个电子。α 自旋密度与 β 自旋密度完全相同。α 自旋轨道的形状与 β 自旋轨道相同。

自旋非限制 (Spin-unrestricted)：优化两套独立的分子轨道——α 自旋轨道和 β 自旋轨道。大体上，在电子基态和平衡几何构型下，RHF 和 UHF 是等价的。然而，UHF 在解离极限附近表现好得多。UHF 波函数存在自旋污染问题。

讲解 · 三种 SCF 的对比（第 3 讲 p51–53 会再讲一遍，这里先建立框架）

方法全称做法适用
RHFRestricted HFα 和 β 共用同一套空间轨道，每个轨道放 2 个电子闭壳层：所有电子成对。绝大多数稳定有机分子
ROHFRestricted Open-shell HF成对的电子共用空间轨道，未成对的单独占据开壳层，且要求自旋纯净（无自旋污染）
UHFUnrestricted HFα 和 β 各有一套独立的空间轨道，分别优化开壳层、自由基、解离过程、过渡金属
UHF 的代价：自旋污染 (spin contamination)

UHF 波函数不是 Ŝ² 算符的本征函数。意思是：你想算一个纯的双重态（S=½），但得到的波函数里混进了四重态（S=3/2）、六重态的成分。

自旋污染的判据（第 3 讲 p53 给出） ⟨Ŝ²⟩UHF ≥ ⟨Ŝ²⟩精确 = S(S+1) = (nunpaired/2)(nunpaired/2 + 1)
体系S理论 ⟨Ŝ²⟩可接受范围
单重态00.00< 0.1
双重态（自由基）1/20.75< 0.79（偏差 < 5%）
三重态12.00< 2.1
四重态3/23.75< 3.9

怎么看：Gaussian 每次 UHF/UDFT 计算结束会打印一行 <S**2>= 0.7601。如果这个数比理论值大 10% 以上，你的结果就不可信了。

污染严重意味着什么：第 3 讲 p53 说得很准——"严重的自旋污染通常意味着单个行列式对基态是一个很差的近似 → 应该考虑 MCSCF 方法。"它是一个"该换方法了"的诊断信号，而不只是一个技术瑕疵。

拓展 · "UHF 在解离极限表现好得多"是什么意思（第 4 讲 p4、p21 的核心）

这是本课最经典的一个例子，一定要理解。以 H₂ 拉断为例：

方法在 R → ∞ 时给出什么对不对
RHF因为强制两个电子共用同一个 σg 轨道，波函数里永远保留 50% 的离子项（H⁻ + H⁺）错：能量比正确值高约 140 kcal/mol
UHFα 电子可以塌到左边的 H 上，β 电子塌到右边 → 得到两个中性 H 原子能量对了
FCI正确混入双激发组态，离子项自动消掉完全正确

但 UHF "对得有点侥幸"（第 3 讲 p52 原话："treats bond breaking correctly although for the wrong reasons"）：

  • 它是靠破坏自旋对称性换来的正确能量
  • 在解离极限，UHF 的 ⟨Ŝ²⟩ 会从 0 涨到 1.0（一半是单重态、一半是三重态）——严重自旋污染
  • 而且 UHF 的势能曲线在某个键长处会出现一个不自然的"扭结"（RHF→UHF 解开始出现的那一点，叫 Coulson–Fischer 点）

这正是第 2 讲 p101 那道作业题的全部内容：扫描 H₂ 的势能面，对比 RHF 和 UHF，解释为什么不同。答案就是这一段。

脚本解析 · 逐行拆开这个 bash 循环

这一行做了什么
input=Gaussian_PES_H2_UB3LYP定义一个 shell 变量存文件名前缀。注意等号两边不能有空格——input = xxx 在 bash 里是错的。
for R in 0.50 0.55 … ; do循环。变量 R 依次取列表里的每个值，执行 do…done 之间的内容。
sed -e "s/DISTANCE/$R/g" $input.gjf > …核心的一行。sed = stream editor（流编辑器）。s/A/B/g = 把所有（g=global）A 替换成 B。所以它读模板文件，把里面的占位符 DISTANCE 全部换成当前的 R 值，写出一个新输入文件。
g16 < xxx.gjf > xxx.log运行 Gaussian 16。< 把输入文件喂给它，> 把输出存成 log。
grep 'SCF Done' "$input"_*.log > results.txt循环结束后，从所有 log 里抓出能量行汇总。* 是通配符，匹配任意字符。
用双引号而不是单引号："s/DISTANCE/$R/g"

bash 里：双引号内的 $R 会被展开成变量的值；单引号内的 $R 保持字面量。

如果这里写成单引号 's/DISTANCE/$R/g'，sed 会把字符串 $R 本身写进文件，而不是 0.50、0.55…——生成的输入文件全是坏的。这是最常见的脚本错误之一。

做 UHF 版本时的关键：只把 rhf 改成 uhf 是不够的。因为 UHF 从对称的初始猜测出发，会一路收敛到与 RHF 完全相同的解（α 和 β 轨道保持相同）。必须加 guess=mix 关键词，它把 HOMO 和 LUMO 混合起来打破 α/β 对称性，UHF 才能找到那个更低的破缺解。

讲解 · 这道题的标准答案（p101 那个"你能解释为什么结果不同吗？"）

答案（分四步说）

① RHF 强制两个电子共用同一个空间轨道 σg。它的波函数展开后（第 4 讲 p19 会精确推导）是：

ΨRHF ∝ [χA(1)χA(2) + χB(1)χB(2)] + [χA(1)χB(2) + χB(1)χA(2)]
　　　　离子项（两个电子在同一个 H 上）50%　　　共价项 50%

② 这个 50:50 的比例是固定的，无论 R 多大——因为 RHF 只有一个行列式，没有可调的混合系数。

③ 在 R → ∞ 时，"离子项"意味着 H⁻ + H⁺，它比 H· + H· 高出 (IE − EA) ≈ 13.6 − 0.75 = 12.8 eV ≈ 295 kcal/mol。乘以 50% 的权重，就是约 147 kcal/mol 的能量高估——正是图上那个巨大的误差。

④ UHF 允许 α 和 β 用不同的空间轨道，于是 α 电子可以完全塌到左边的 H 原子上、β 电子塌到右边，得到两个中性 H 原子 → 能量正确。

要说清楚的关键概念名词（答题时要点到）
  • 静态相关 (static correlation)：这个失败的根源。在解离极限，σg² 和 σu² 两个组态变成简并，单个 Slater 行列式从原理上就不够用了。（第 4 讲 p4 的定义）
  • UHF 的解法是"破缺对称性"：牺牲自旋纯度（⟨Ŝ²⟩ 从 0 涨到 1）来换取正确的能量。所以第 3 讲 p52 说它 "correct for the wrong reasons"。
  • 真正的解法是多组态方法：CASSCF(2,2) 或 Full CI，把 σu² 组态混进来，让离子项在长距离处自动消掉（第 4 讲 p20：R→∞ 时 a₂ = −a₁，离子项系数 a₁+a₂ = 0）。
