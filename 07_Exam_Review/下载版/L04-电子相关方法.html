p2精确波函数的形式

原文翻译

当所有可能的 Slater 行列式都被包含进波函数、且它们各自的权重由变分方法确定时，就得到了精确波函数：

Ψexact = a₀ψHF + ΣioccΣrvirt airψir + Σi<joccΣr<svirt aijrsψijrs + Σi<j<kΣr<s<t aijkrstψijkrst + ⋯

这样的波函数被称为薛定谔方程的精确非相对论解。

通过把激发的 Slater 行列式加入 HF 波函数，电子开始"感受"到彼此并互相回避（增大电子间距离），这就计入了所谓的"电子相关"。

这样的波函数只对非常小的分子（主要是双原子分子）、小基组下才可能。它被称为 Full CI。

实践中，通常对激发电子的数目施加一个限制（相对于基态 HF 行列式），通常是 2。

讲解 · "激发"到底是什么意思（零基础版）

重要澄清：这里的"激发"不是物理上的电子跃迁

Ψijrs 并不表示"分子真的被激发了"。它们只是一组数学上的基函数——用来把真实的基态波函数展开。

类比：用正弦波展开一个方波（傅里叶级数），高频正弦波并不意味着方波"真的在高频振动"，它们只是构造这个形状的零件。

所以：基态的 CI 波函数里混入双激发行列式，描述的仍然是基态，只是描述得更准确了。

p3Hartree–Fock 回顾与相关能的定义

原文翻译
  • 每个电子在所有其余电子和核产生的平均静电场中运动（平均场近似）
  • 每个分子（自旋）轨道描述一个电子的运动（单电子近似）
  • 多电子波函数 ΨHF 写成单电子分子轨道的反对称化乘积（即单个 Slater 行列式），以满足泡利不相容原理
  • Hartree–Fock 能量作为哈密顿量的期望值得到：
    EHF = ∫ΨHF*ĤΨHFdτ = ⟨ΨHF|Ĥ|ΨHF⟩
  • Hartree–Fock 解的能量比精确能量高。
    Eexact = ⟨Ψexact|Ĥ|Ψexact⟩
  • 精确能量与 HF 能量之差称为相关能：
    Ecorr = Eexact − EHF

p4★ 静态相关与动态相关（本讲最重要的一页）

原文翻译

电子相关实际上被定义为：Hartree–Fock 理论没有正确处理的那部分电子间相互作用。

静态相关 (Static correlation) 指的是这样一种情形：单个 Slater 行列式（即单一的分子轨道占据模式）可能不是基态的好近似。这常常发生在基态是简并或变成简并的时候。

例子：H₂ 的解离。一个著名的例子是氢分子的解离，其中限制性 Hartree–Fock 方法产生的是一对离子而不是一对自由基。

（图示：正确（精确解）H···H；错误（RHF 解）H⁻···H⁺）

动态相关 (Dynamic correlation) 是由库仑排斥导致的电子之间关联的运动。作为平均场理论，HF 方法没有正确处理这个效应。

非弹性 X 射线散射的描述如果不包含动态相关效应就无法得到。

顺序必须先处理静态，再处理动态。标准做法：CASSCF（静态）→ CASPT2/NEVPT2（动态）
为什么 RHF 会把 H₂ 解离成一对离子（p4 那张图）

这是全课最经典的例子，p17–p21 会详细推导，这里先给结论：

RHF 强制两个电子共用同一个 σg 轨道。展开后：

ΨRHF ∝ [χA(1)χA(2) + χB(1)χB(2)] + [χA(1)χB(2) + χB(1)χA(2)]
　　　离子项 50%（两个电子在同一个 H 上 ⟹ H⁻ + H⁺）　共价项 50%

这个 50:50 比例是固定的，不随距离变化——因为单个行列式没有可调的混合系数。

而 R→∞ 时，H⁻+H⁺ 比 H·+H· 高出 (IE−EA) ≈ 12.8 eV，乘以 50% 权重 ≈ 147 kcal/mol 的能量高估。

修复方法：混入双激发组态 σu²，让离子项的系数在长距离处趋于零（p20 会精确给出）。

p5变分原理及其局限

原文翻译

应用到量子化学计算中，变分原理指出：在给定的一类函数中，能量期望值最低的那个是量子体系基态的最佳近似。

实践中，变分原理保证更大的基组会给出更好的近似，虽然收益递减规律确实适用。

基组能量 / Hartree
STO-3G−0.49491
STO-4G−0.49848
STO-5G−0.49951
STO-6G−0.49983

由于误差抵消效应，变分原理一般不适用于能量以外的性质，甚至不适用于能量差（如左图所示）。

因此对性质计算而言，更大的基组不一定意味着更准确的答案，但一定意味着更长的计算时间。

讲解 · 那张表在演示什么

这是氢原子（精确解 −0.5 Hartree）用不同数目高斯函数拟合的结果：

基组能量距精确值每加一个高斯的收益
STO-3G−0.49491+0.00509—
STO-4G−0.49848+0.00152改善 0.0036
STO-5G−0.49951+0.00049改善 0.0010
STO-6G−0.49983+0.00017改善 0.0003

两个观察：

  1. 能量单调下降，永远不越过 −0.5 ⟹ 变分原理 ✔
  2. 改善幅度每次约减小到 1/3 ⟹ 收益递减。从 5G 到 6G 只改善 0.0003 Hartree，但计算量增加 20%
"变分原理不适用于性质和能量差" —— 这是最容易被忽视的一句话

为什么能量差不受保护：设有两个结构 A 和 B，你想算 ΔE = EB − EA。

真实：ΔE真 = EB,真 − EA,真
计算：ΔE算 = (EB,真 + δB) − (EA,真 + δA) = ΔE真 + (δB − δA)

变分原理只保证 δA > 0 和 δB > 0，但对它们的差 (δB−δA) 一无所知。

实际后果（非常重要）：

  • 如果 A 和 B 很相似（同分异构体、反应物与产物），误差高度抵消 ⟹ 小基组也能给出好的 ΔE。这就是为什么 B3LYP/6-31G(d) 这么好用。
  • 如果 A 和 B 差别很大（比如"分子" vs "两个分开的碎片"，即 BSSE 的场景 p37），抵消被破坏 ⟹ 必须用大基组或做校正。
  • "平衡的基组"比"大的基组"更重要——不要给分子的一部分用大基组、另一部分用小基组。

p6处理电子相关的两条技术路线

原文翻译

在计算化学中，我们有两条主要途径来处理电子相关效应：

多组态波函数方法：

  • 在原有的基态 Hartree–Fock Slater 行列式之外，再考虑额外的 Slater 行列式，以扩充 Hartree–Fock 波函数
  • 这些额外的 Slater 行列式描述各种激发-去激发过程，从而计入动态电子相关
  • 我们随后将分析额外 SD 对"保证电子分开"的效果

密度泛函理论方法：

  • 这个方法以近似的方式描述交换与相关效应。该方法仍然使用与 Hartree–Fock 类似的单 Slater 行列式形式，但修改了 Fock 算符的版本——它现在包含一个"更软"的势，其中含有近似的电子间相关项（这一项在 HF 中是缺失的）

讲解 · 两条路线的根本区别

波函数方法 (WFT)密度泛函方法 (DFT)
基本变量波函数 Ψ(r₁,…,rN)，3N 个变量电子密度 ρ(r)，只有 3 个变量
怎么补相关加更多 Slater 行列式（显式地）用一个近似的交换-相关泛函 Exc[ρ]（隐式地）

能算多大20–100 原子数百到数千原子
DFT 的核心权衡（本课不细讲，但要知道）

DFT 用 HF 的价格买到了（部分）相关能。这是它统治了实际计算化学的原因。

但代价是：

  • 没有系统改进的路径。B3LYP 算不准，换成 M06-2X 可能更好也可能更差，只能靠经验和 benchmark。
  • 自相互作用误差 (SIE)：近似泛函里，一个电子会跟自己排斥。后果：高估离域、低估反应能垒、带隙偏小。
  • 算不出色散（第 1 讲 p12），必须外加 D3/D4 修正。
  • 对静态相关基本无能为力——DFT 只有一个行列式，遇到 p4 那种情况同样失败。

所以：DFT 不是"更好的方法"，是"性价比不同的方法"。做机理研究用 DFT，做基准和小体系高精度用 CCSD(T)，做多参考体系用 CASPT2。

原文翻译

拓展 · 烯丙基阴离子为什么需要 MCSCF（p9 的例子）

烯丙基阴离子 [CH₂–CH–CH₂]⁻ 有 4 个 π 电子分布在 3 个 p 轨道上（π₁ 成键、π₂ 非键、π₃ 反键）。

HF 给出 π₁²π₂²。但 π₂（非键）和 π₃（反键）能量差不大，所以 π₁²π₃² 这个组态也有可观权重。

更一般的规律：所有共轭 π 体系都有可观的静态相关——因为 π 轨道之间的能隙比 σ 小得多。这就是为什么算多烯、卟啉、富勒烯的激发态特别难。

p10–13组态相互作用 (CI) 与久期方程

原文翻译（p10）

我们可以把 MCSCF 推到极限，把所有激发行列式都包含进计算。这非常昂贵（组合原因），常常需要某种截断。

方法组态随基组大小的标度
CID所有双激发行列式O(n⁵)
CISD所有单激发和双激发行列式O(n⁶)
CISDT所有单、双、三激发行列式O(n⁸)
full CI所有组态O(n!)

对全部轨道的一个子集做 full CI，这个极限被称为 CASSCF（完全活性空间 SCF）。轨道的选择不是一件简单的事。

由于组态数目天文数字般巨大，full CI 只对非常小的（双原子）体系可行。幸运的是，full CI 很少必需，因为 CISD 对大多数实际目的已经足够准确。

原文翻译（p12–13）· CI 久期方程

把 Full CI 展开简记为：Ψ = a₀ΨHF + ΣSaSΨS + ΣDaDΨD + ΣTaTΨT + ⋯

波函数的优化需要使 ⟨Ψ|Ĥ|Ψ⟩ → 最小，约束条件是 ⟨Ψ|Ψ⟩ = 1。使用拉格朗日乘子法。

步骤 1：设置拉格朗日函数 L：

L = ⟨Ψ|Ĥ|Ψ⟩ − λ(⟨Ψ|Ψ⟩ − 1) = ΣiΣjaiaj⟨Ψi|Ĥ|Ψj⟩ − λ(Σiai² − 1)

步骤 2：对所有参数 ai 和 λ 求导：

∂L/∂ai = 2Σjaj⟨Ψi|Ĥ|Ψj⟩ − 2λai = 2ai(Ei − λ) + 2Σj≠iaj⟨Ψi|Ĥ|Ψj⟩ = 0

步骤 3：把所有 ai 的方程写成矩阵形式（CI 久期方程），记 ⟨Ψi|Ĥ|Ψj⟩ = Hij：

（给出 (H − EI)a = 0 的矩阵形式）

可以写成简写形式：(H − EI)a = 0　或　Ha = Ea

这就是常见的本征值问题。这个方程的解原则上给出精确答案。CI 方法的唯一困难是 CI 矩阵的规模随分子和基组增长得非常快。

实践中通常实现截断的 CI 方法：CISD = HF + 单激发和双激发；CISDT = HF + 单、双、三激发

　　　　　　　　　　离子项　　　　　　　　　　　　　　　　共价项

= (χA(1)−χB(1))(χA(2)−χB(2))

= χA(1)χA(2) + χB(1)χB(2) − χA(1)χB(2) − χB(1)χA(2)

ΨFCI = a₀Ψ₀ + a₁Ψ₁，其中 a₀² + a₁² = 1

HF 波函数 Ψ₀ 有 50% 离子和 50% 共价贡献。通过把 Ψ₁ 混入 Ψ₀，共价贡献通常会增加。

推导详解 · 一步步把 p19 算清楚

第一步：为什么 φ₁(1)φ₁(2) 展开后会有离子项

φ₁ = χA + χB（省略归一化常数）。所以：

φ1(1)·φ1(2) = [χA(1)+χB(1)]·[χA(2)+χB(2)]
= χA(1)χA(2) + χA(1)χB(2) + χB(1)χA(2) + χB(1)χB(2)
项物理含义叫什么

covalent

四项系数完全相同（都是 1）⟹ 离子 : 共价 = 50 : 50，而且这个比例被锁死了，因为 Ψ₀ 里没有任何可调参数。

第二步：双激发 Ψ₁ 展开后符号相反

φ₂ = χA − χB，所以：

φ2(1)·φ2(2) = [χA(1)−χB(1)]·[χA(2)−χB(2)]
= +χA(1)χA(2) + χB(1)χB(2) − χA(1)χB(2) − χB(1)χA(2)

关键：离子项同号（都是 +），共价项反号（变成 −）。

为什么：因为交叉项来自 (+χA)×(−χB)，多了一个负号；而 χAχA 项来自 (+χA)×(+χA)，符号不变。

第三步：线性组合 ⟹ 两个可调的系数
ΨFCI = a0Ψ0 + a1Ψ1
= (a0 + a1)·[离子项] + (a0 − a1)·[共价项]

这就是全部秘密：混入双激发之后，离子项和共价项的系数不再被锁死为相等了。

因为 a₁ 通常是负数（双激发是稳定化的），所以：

  • 离子系数 (a₀+a₁) 变小
  • 共价系数 (a₀−a₁) 变大

物理效果：两个电子"同时出现在同一个原子上"的概率降低了 ⟹ 它们更倾向于一人一边 ⟹ 这就是电子在躲避。这种沿键轴方向的躲避叫 左-右相关 (left-right correlation)。

第四步：解离极限（p20 的高潮）

当 R → ∞ 时，变分优化会给出 a₁ = −a₀（即 a₀ = 1/√2，a₁ = −1/√2）。代入：

离子系数 = a0 + a1 = a0 − a0 = 0　　✔ 离子项完全消失
共价系数 = a0 − a1 = 2a0　　　　✔ 纯共价

ΨFCI → χA(1)χB(2) + χB(1)χA(2)　—— 正好是 Heitler–London 的价键波函数（第 1 讲 p11 的拓展）！

解离产物：两个中性的 H 原子 ✔ 完全正确。

p22★ 截断 CI 的致命缺陷：尺寸不一致性

原文翻译

假设我们需要计算两个相距 100 Å 的水分子的能量。可以做两个计算：

  1. 把两个水分子放在同一个计算里一起算（给全部 2 个 O 和 4 个 H 分配基组）⟹ 得到总能量 Etogether
  2. 计算一个水分子，然后把结果乘以 2 ⟹ 得到总能量 Esum

我们期望 Etogether = Esum。然而，这个等式只被 Full CI 方法满足（当两个计算中都包含所有激发时）。

当使用任何截断的 CI 方法（如 CISD）时，我们会发现 Esum < Etogether。

这种行为的原因在于：Etogether 对两个分子的整个基组只包含了单激发和双激发，而 Esum 对每个片段各自包含了单激发和双激发。当我们把一个水分子的能量乘以 2 时，本质上是取了两个水分子 CISD 波函数的乘积。这样两个 CISD 波函数的乘积必然包含单、双、三、四重激发的 SD，比情形 (1) 得到的 CISD 波函数更多。

思想实验：两个相距 100 Å 的水分子

100 Å 相当于 10 纳米——两个分子之间没有任何物理相互作用。所以正确答案必须是 E(2 个 H₂O) = 2 × E(1 个 H₂O)。

p23–27★ 耦合簇 (Coupled Cluster)：黄金标准

原文翻译（p23）

耦合簇理论对某一特定类型的所有激发求和。也就是说，在 CI 理论中被参数化的是每一个行列式，而在 CC 理论中被参数化的是激发这个过程。CC 包含更高的激发，但它们的系数是低阶激发系数的乘积。

CC 理论是尺寸一致的，即对两个体系：ECC(1+2) = ECC(1) + ECC(2)

原文翻译（p24）

耦合簇方法（和 CI 一样）旨在把激发的 Slater 行列式加入基态 HF 波函数。CC 与 CI 的区别在于选择哪些激发 SD 被包含在波函数中。

T = T₁ + T₂ + T₃ + ⋯ + TNelec

  • T₁ —— 生成单激发组态的算符
  • T₂ —— 生成双激发组态的算符

CI 波函数可以写成：ΨCI = (1 + T)Ψ₀ = (1 + T₁ + T₂ + T₃ + ⋯ + TNelec)Ψ₀

相应的耦合簇波函数定义为：

ΨCC = eTΨ₀ ⟹ 对 eT 做 Taylor 展开

= (1 + T₁ + T₂ + ½T₁² + T₃ + T₂T₁ + ⅙T₁³ + ⋯)Ψ₀

与 CI 波函数相比，CC 波函数在每个激发级别上都包含由激发的乘积产生的额外项。薛定谔方程变为：

原文翻译（p25–26）· CC 能量方程

左乘 Ψ₀* 并对全空间积分：

⟨Ψ₀|ĤeT|Ψ₀⟩ = ECC⟨Ψ₀|eT|Ψ₀⟩ = ECC⟨Ψ₀|(1+T₁+T₂+⋯)|Ψ₀⟩ = ECC

因此，为了得到 ECC，我们只需计算一个积分（这里假设指数截断在二阶）：

ECC = ⟨Ψ₀|Ĥ(1 + T₁ + T₂ + ½T₁²)|Ψ₀⟩

= E₀ + Σtia⟨Ψ₀|Ĥ|Ψia⟩ + Σ(tijab + tiatjb − tibtja)⟨Ψ₀|Ĥ|Ψijab⟩

其中 Σtia⟨Ψ₀|Ĥ|Ψia⟩ = 0，由 Brillouin 定理。

p26：要计算上式，我们需要知道振幅 tijab、tiatjb 以及变换到 MO 基的积分 ⟨φiφj|φaφb⟩。

振幅通过求解如下方程得到：

⟨Ψia|ĤeT|Ψ₀⟩ = ECC⟨Ψia|eT|Ψ₀⟩

⟨Ψijab|ĤeT|Ψ₀⟩ = ECC⟨Ψijab|eT|Ψ₀⟩

实践中 CC 方法在某个级别截断：

  • CCSD = 耦合簇 单激发 + 双激发
  • CCSDT = 单、双、三激发 ⟹ 量子化学的黄金标准是 CCSDTQ

耦合簇即使在截断的级别上也是尺寸一致的。

讲解 · 指数拟设为什么能解决尺寸一致性

数学根源：指数函数的性质 eA+B = eA·eB

考虑两个相距无穷远的分子 A 和 B。它们的簇算符可以分开：T = TA + TB（因为没有相互作用）。

ΨCC(A+B) = eTA+TBΨ0 = eTA·eTBΨ0 = ΨCC(A)·ΨCC(B)　✔

波函数自动分解成两个片段波函数的乘积——这正是"两个独立体系"的正确形式。能量因此自动可加：E(A+B) = E(A) + E(B)。

对比 CI：(1 + TA + TB) ≠ (1 + TA)(1 + TB) = 1 + TA + TB + TATB

CI 少了那个 TATB 交叉项——这正好就是 p22 说的"两个分子各激发 2 个电子"的四激发项。CC 因为指数展开，自动包含了它。

Taylor 展开里每一项的含义（p24 的关键）
eT = 1 + (T1) + (T2 + ½T1²) + (T3 + T2T1 + ⅙T1³) + ⋯
激发级别CC 里包含的项说明
单激发T₁"连接的"(connected)——真正的单激发
双激发T₂ + ½T₁²除了真正的双激发，还有"两个独立的单激发同时发生"
四激发… + ½T₂²这就是 CCSD 里"免费送"的四激发——两对电子各自独立地双激发。它修复了尺寸一致性

关键洞察：CCSD 虽然只求解 T₁ 和 T₂ 的振幅，但通过 ½T₂²、⅙T₂³ 这些项，波函数里隐含了四激发、六激发……而且它们的系数不是独立参数，是 t₂ 的乘积。

物理上这非常合理：两对相距很远的电子对，各自独立地关联——它们的联合概率就是各自概率的乘积。这正是指数函数在描述的东西。

CC 的代价：它不是变分的

看 p26 的求解方式：CC 的振幅方程不是通过"最小化能量"得到的，而是通过"把薛定谔方程投影到各个激发行列式上"得到的。

拓展 · CCSD(T)：为什么括号里的 T 是"黄金标准"

CCSD(T) 的读法是 "CCSD with perturbative triples"（带微扰三激发的 CCSD）。

方法标度说明
CCSDO(N⁶)迭代求解 T₁, T₂
CCSD(T)O(N⁷)在 CCSD 之上，用微扰论（非迭代）估算三激发的贡献
CCSDTO(N⁸)完全迭代地求解 T₃，贵得多，精度提升有限

为什么 (T) 这么成功：

  • 只加了一个 N⁷ 的非迭代步骤，比完整 CCSDT (N⁸ 迭代) 便宜一个数量级
  • 精度却几乎和 CCSDT 一样好（p27 的表：CCSDT 误差 0.000493，CCSDTQ 0.000019）
  • 存在一定的误差抵消：(T) 的近似误差恰好部分补偿了 CCSD 缺少的高阶效应

所以：CCSD(T)/CBS 是目前公认的"黄金标准"——对单参考体系，它的精度通常在 1 kcal/mol 以内，被用作检验 DFT 泛函的基准。

但 CCSD(T) 有一个致命场景

当体系有强静态相关时（p4），CCSD(T) 会灾难性地失败——甚至给出发散的结果（因为 (T) 的微扰修正分母上有轨道能差，简并时分母趋零）。

p39 的原文明确警告："In systems with homolytic bond cleavage or degeneracies, MPn, CI and CC methods can fail dramatically."

判断标准：算完看 T₁ 诊断。> 0.02（有机分子）就要警惕。

p28–35微扰论：从"小修正"到 MP2

原文翻译（p28–29）

p28：微扰论是物理学、特别是量子力学中最重要最有用的方法之一，它允许处理复杂体系的复杂哈密顿量。为简单起见，我们只概述这个方法的基本思想。

假设一个更简单的哈密顿量 Ĥ₀，它在某个特定态的波函数和能量是已知的：

Ĥ₀|ψn(0)⟩ = En(0)|ψn(0)⟩

假设新的哈密顿量可以写成：Ĥ = Ĥ₀ + λĤ₁

例如 Ĥ₀ = K̂ + V̂₀。我们假定相互作用力 V̂₀ 远强于微扰力 λĤ₁。

p29：Ĥ₁ 可以是例如外加的电场或磁场。Ĥ₁ 作用在原波函数上会改变态和它的能量。

第 n 个态的新（受微扰）波函数可以写成：

|ψ̃n⟩ = Σk=0∞ λk|ψn(k)⟩，　n = 1,2,3,…

对应的能量是：En = Σk=0∞ λkEn(k)

其中 |ψn(k)⟩ 和 En(k) 是波函数与能量的第 k 阶修正。

公式解析 · 微扰论的基本设定

★ 微扰论的出发点 Ĥ = Ĥ0 + λĤ1
符号名称含义
Ĥ0零阶哈密顿量一个我们已经会解的简单问题
Ĥ1微扰真实哈密顿量与 Ĥ₀ 的差。要求它"小"
λ微扰参数一个记账用的形式参数：λ=0 是未微扰体系，λ=1 是真实体系。它的作用是给各阶修正"贴标签"，让我们能按 λ 的幂次分类
上标 (0),(1),(2)阶数不是幂次！是"第几阶修正"。E(2) 读作"二阶能量修正"
日常类比

你要算"地球绕太阳的轨道 + 木星的引力扰动"。

  • Ĥ₀ = 只有太阳的两体问题 ⟹ 精确可解（椭圆轨道）
  • λĤ₁ = 木星的引力 ⟹ 小，但会让轨道慢慢进动

微扰论的精神：先解简单问题，再一层层加修正。只在"微扰确实很小"时才有效。

原文翻译（p30–33）· 逐阶推导

p30：完整哈密顿量成为 (Ĥ₀ + λĤ₁)ψn = Enψn。把 ψ̃n 和 En 的展开代入，并把 λ 的幂次小于 2 的项显式写出、合并同幂次的项：

Ĥ₀ψn(0) + λ[Ĥ₀ψn(1) + Ĥ₁ψn(0)] + λ²[Ĥ₀ψn(2) + Ĥ₁ψn(1)] + ⋯

= En(0)ψn(0) + λ[En(0)ψn(1) + En(1)ψn(0)] + λ²[En(0)ψn(2) + En(1)ψn(1) + En(2)ψn(0)] + ⋯

p31：令相同幂次的项相等：

λ⁰：Ĥ₀ψn(0) = En(0)ψn(0)

λ¹：Ĥ₀ψn(1) + Ĥ₁ψn(0) = En(0)ψn(1) + En(1)ψn(0)

λ²：Ĥ₀ψn(2) + Ĥ₁ψn(1) = En(0)ψn(2) + En(1)ψn(1) + En(2)ψn(0)

用 ⟨ψm(0)| 左乘第二个方程，并利用 Ĥ₀ 的厄米性，得到：

p32：(Em(0) − En(0))⟨ψm(0)|ψn(1)⟩ = En(1)δmn − ⟨ψm(0)|Ĥ₁|ψn(0)⟩

若 m = n，左边为 0：

En(1) = ⟨ψn(0)|Ĥ₁|ψn(0)⟩　；　En ≈ En(0) + En(1)

若 m ≠ n，把 ψn(1) 在未微扰函数的完备集上展开，得到：

p33：am = ⟨ψm(0)|Ĥ₁|ψn(0)⟩ / (En(0) − Em(0))

完整波函数：ψn = ψn(0) + Σm [⟨ψm(0)|Ĥ₁|ψn(0)⟩ / (En(0) − Em(0))] ψm(0)

原文翻译（p34–35）· 二阶能量

选择对应 λ² 的方程，用 ⟨ψm(0)| 左乘。若 m = n，左边为 0，且 ⟨ψn(0)|ψn(1)⟩ = 0：

En(2) = ⟨ψn(0)|Ĥ₁|ψn(1)⟩

把 ψn(1) 的表达式代入：

En(2) = Σm |⟨ψm(0)|Ĥ₁|ψn(0)⟩|² / (En(0) − Em(0))

En ≈ En(0) + En(1) + En(2)

公式解析 · 一阶和二阶能量修正

★ 一阶能量修正 En(1) = ⟨ψn(0)| Ĥ1 |ψn(0)⟩

解读：用没有被扰动的波函数，去算微扰算符的期望值。直观、便宜、只需要已知的东西。

★ 二阶能量修正（本讲最重要的公式） En(2) = Σm≠n |⟨ψm(0)|Ĥ1|ψn(0)⟩|² ⁄ (En(0) − Em(0))
部分名称含义
分子耦合矩阵元的平方衡量微扰把态 n 和态 m "混合"得有多强。因为取了平方，永远 ≥ 0
分母能量差对基态（n=0），所有 Em > E0，所以分母永远为负
整体二阶修正对基态永远是负的（分子正，分母负）⟹ 基态永远被二阶微扰稳定化
这个公式的三条通用规律（在整个物理化学里都成立）
  1. 能量越接近，混合越强（分母越小，贡献越大）。这就是"能量相近的轨道容易相互作用"这条化学直觉的数学来源——分子轨道理论、微扰分子轨道理论 (PMO)、前线轨道理论全靠它。
  2. 基态总是被推低，激发态总是被推高（能级的"互相排斥"）。这是"避免交叉规则 (avoided crossing)"的来源。
  3. 简并时公式失效：En(0) = Em(0) ⟹ 分母为零 ⟹ 发散。这就是为什么 MP2 对近简并体系（过渡金属、断键）会崩溃——它是 p39 那句警告的数学根源。这时必须用简并微扰论或多参考方法。

讲解 · 三个必须注意的点

① 为什么公式里只有双激发，没有单激发

因为 Brillouin 定理（p25 明说）：⟨ΨHF|Ĥ|Ψia⟩ = 0。

代入 p35 的二阶公式，单激发项的分子恒为零 ⟹ 整项消失。

所以 MP2 = "所有双激发的二阶微扰贡献之和"。而 p16 的数据告诉我们双激发本来就是主力，这解释了 MP2 为什么这么便宜又这么好用。

② EMP1 去哪了？

公式里 EMP0 + EMP1 被合并写成了 E₀。原因：

EMP0 + EMP1 = EHF

零阶 + 一阶恰好就是 Hartree–Fock 能量。所以真正的相关能修正从二阶才开始——这就是"MP2"这个名字的来历，也是为什么没有"MP1 方法"。

为什么会这样：Møller–Plesset 选的零阶哈密顿量是 Ĥ₀ = ΣF̂i（Fock 算符之和）。它的本征值是 Σεi，而这个值把电子间排斥数了两遍。一阶修正 E(1) 恰好把多数的那一遍减掉，还原成正确的 EHF。

③ MP2 不是变分的

MP2 能量可能低于精确能量（"过冲"）。这是它和 CI 的关键区别。

典型表现：MP2 高估相关能，导致它高估弱相互作用（π–π 堆积能常被高估 50%）。SCS-MP2（自旋分量标度 MP2）就是为了修正这个而设计的——把同自旋和反自旋的贡献分别乘上不同的经验因子。

当分子被一起模拟时，每个分子都获得了新的激发可能性，导致 CI 子空间中更大的变分灵活性。

当分子被靠近时，它们互相扩充了对方的基组，从而增加了变分灵活性。即使不存在任何相互作用，能量也会下降。这导致非物理的吸引。

E(proximate) < E(distant)

  1. 算任何非共价相互作用（氢键、π 堆积、主客体结合），BSSE 校正是标配。
  2. 基组越小、方法相关水平越高，BSSE 越大（MP2 的 BSSE 比 HF 大，因为虚轨道也参与了）。
  3. 不要只报告一个数：好的做法是同时报告未校正值和 CP 校正值，真值通常在两者之间（CP 有轻微过校正的倾向）。
BSSE 与尺寸一致性：两个不同的问题，别搞混
BSSE尺寸不一致性
根源基组不完备方法（激发级别截断）
谁有所有用原子中心基组的方法（含 HF、DFT）只有截断 CI（HF、MP2、CC 都没有）
怎么消Counterpoise 校正；或用完备基组换方法（用 CC 而不是 CI）
误差方向高估结合（能量偏低）低估相关（合并体系能量偏高）

p37 把这两件事放在同一页，容易让人混淆——记住：BSSE 是基组问题，尺寸一致性是方法问题。

拓展 · p40 提到的"解析导数"为什么重要

解析导数 = 能量对坐标的梯度有闭式公式，一次计算就能拿到全部 3N 个分量。

数值导数 = 只能靠"挪动每个原子一点点，看能量变多少"来估算，需要 6N 次单点计算（每个坐标正负各一次）。

对一个 20 原子的分子做一次几何优化步
有解析梯度（HF、DFT、MP2）1 次计算
只有数值梯度（MP4、CCSDT）120 次计算

这就是为什么"CCSD(T) 几何优化"在实践中很少做——大家用 DFT 或 MP2 优化结构，再用 CCSD(T) 算单点能。

"For properties other than energy, a higher correlation level method does not necessarily mean a more accurate answer – beware of error compensation situations."

这句话在整个课程中出现了三次（p5、p41、p42），说明它非常重要。

误差抵消的典型例子：

  • HF/小基组的键长意外地准：HF 缺少相关能会让键偏短，而小基组的不完备会让键偏长——两者抵消。用 HF/大基组反而更差！

实用建议：用一个在你的体系类别上被 benchmark 验证过的方法/基组组合，不要自己随意搭配"更好的方法 + 更好的基组"。

p43完备基组极限 (CBS) 外推

原文翻译

能量（但通常不包括其他参数）可以外推到基组极限——实际上就是外推到完备基组。下面给出 Dunning–Feller 外推方案，其中 n 是 (aug-)cc-pVnZ 基组的 zeta 指数：

En = ECBS + αe−βn

α, β 是可以针对具体情形/分子类别拟合的参数

快速的近似方法（但抓住了要点）：HF/6-31G(d,p) 或 HF/cc-pVDZ

慢而准确的方法：MP2/6-311G(2d,2p) 或 MP2/cc-pVTZ

非常慢、非常准确的方法：CCSD(T)/cc-pVQZ 及更高

专门的高精度复合方法：MP2-R12、G1-G3、G2MP2、G3MP2 等

公式解析 · CBS 外推

★ Dunning–Feller 外推（HF 部分） En = ECBS + α e−βn
符号名称含义
nzeta 指数cc-pVDZ → n=2；cc-pVTZ → n=3；cc-pVQZ → n=4；cc-pV5Z → n=5
En用第 n 级基组算的能量实际算出来的数
ECBS完备基组极限要外推得到的东西——理论上 n→∞ 时的能量
α, β拟合参数用三个不同 n 的计算结果拟合出来
怎么用（实际操作）
  1. 用 cc-pVDZ、cc-pVTZ、cc-pVQZ 各算一次单点能，得到 E₂, E₃, E₄
  2. 三个方程三个未知数（ECBS, α, β），解出 ECBS

这样得到的能量比任何单一基组的结果都更接近真值，而且不需要真的去算 cc-pV6Z（那会贵几十倍）。

拓展 · 实践中更常用的分离外推（讲义只给了一个公式，但实际做法不同）

关键洞察：HF 能量和相关能的收敛速度完全不同，应该分开外推。

部分收敛行为常用外推式
HF 能量指数收敛（快）EnHF = ECBSHF + αe−βn（讲义给的这个）
相关能幂律收敛（慢！）Encorr = ECBScorr + A/n³

为什么相关能收敛得慢：相关能的核心是描述"电子对靠得很近时的行为"（电子尖点 cusp）。而以原子为中心的基函数永远无法正确描述 r₁₂ → 0 的行为——因为那需要显式含 r₁₂ 的函数。

解法：显式相关方法 (F12)。在波函数里直接加入依赖 r₁₂ 的项：

Ψ ~ ΨCC × (1 + ½r12 + …)

CCSD(T)-F12 用 cc-pVTZ-F12 基组就能达到常规 CCSD(T)/cc-pV5Z 的精度——省一个数量级的时间。这是近 15 年最重要的进展之一。讲义 p43 提到的 MP2-R12 就是这一类方法的先驱。

拓展 · 复合方法 (composite methods)：G3、CBS-QB3、W1

思路：把一个"理想上要用 CCSD(T)/极大基组"的计算，拆成若干个便宜的计算再拼起来。

E ≈ E[MP2/大基组] + {E[CCSD(T)/小基组] − E[MP2/小基组]} + 零点能 + 经验校正

假设：高阶相关效应（CCSD(T) 相对 MP2 的改进）对基组不敏感，所以可以用小基组算这个"差值"。

方法典型精度（原子化能）
G3 / G4约 1 kcal/mol
CBS-QB3约 1.1 kcal/mol（Gaussian 里最常用）
W1 / W2< 0.5 kcal/mol（非常贵）

Gaussian 里直接写 #p G4 或 #p CBS-QB3，程序自动跑完整个流程。做热化学（生成焓、键解离能）时这是标准工具。
