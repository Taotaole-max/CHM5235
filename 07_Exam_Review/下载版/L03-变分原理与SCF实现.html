拓展 · "内坐标 (internal coordinates)"是什么，为什么它是 Gaussian 的看家本领
坐标类型怎么描述分子特点
笛卡尔坐标每个原子的 (x,y,z)，共 3N 个数简单，但包含 6 个无意义的自由度（整体平移 3 + 转动 3）
内坐标
（Z-matrix）		用键长、键角、二面角描述，共 3N−6 个数化学家的语言；每个自由度都有明确的化学含义；可以单独冻结某一个

为什么这对优化重要：分子的能量对键长非常敏感（硬），对二面角很不敏感（软）。用内坐标，优化算法可以对不同类型的自由度用不同的步长；用笛卡尔坐标，这些自由度混在一起，收敛慢得多。

做扫描时更是必需：你想"固定 C–C 键长为 1.5 Å，优化其余全部"，用内坐标一行搞定；用笛卡尔坐标几乎没法表达。

公式解析 · 电荷与多重度这两个数字（最容易写错的地方）

★ 自旋多重度 多重度 = 2S + 1 = n未成对电子 + 1
未成对电子数S多重度名称例子
001单重态 singlet绝大多数稳定有机分子、H₂O、苯
11/22双重态 doublet自由基、NO、任何奇数电子的分子
213三重态 tripletO₂ 的基态！卡宾、许多激发态
55/26六重态 sextet高自旋 Fe³⁺ (d⁵)
检查方法：总电子数与多重度必须自洽

总电子数 Ne = ΣZA − 电荷

  • Ne 是偶数 → 多重度必须是奇数（1, 3, 5…）
  • Ne 是奇数 → 多重度必须是偶数（2, 4, 6…）

写错的话 Gaussian 会直接报错退出：The combination of multiplicity N and M electrons is impossible.

例：黄素阴离子（讲义的例子）。写的是 -1 1——阴离子（多了一个电子），但多重度是 1（单重态）。这说明原来的中性分子是奇数电子（自由基），加一个电子后变成偶数、全部配对。这是合理的（黄素半醌自由基还原成阴离子）。

拓展 · 为什么要专门指定 grid=ultrafine

背景：DFT 的交换-相关泛函没有解析积分形式，必须在三维数值格点上求和。格点密度是可调的：

格点每原子的点数后果
coarse(35,110) ≈ 3850快，但数值噪声大
fine（G09 默认）(75,302) ≈ 22500一般够用
ultrafine（G16 默认）(99,590) ≈ 58400推荐。频率计算和过渡态搜索必须用
superfine(150,974)用于基准计算

用粗格点的真实后果：格点太粗会引入数值噪声，让势能面出现"人造的小坑"。症状是：几何优化在两个几乎相同的结构之间来回震荡不收敛；或者频率算出几个 −10 cm⁻¹ 左右的小虚频，实际上是数值噪声不是真的过渡态。

这个问题在含大 π 体系、过渡金属、以及使用 M06 系列泛函时尤其明显（M06 家族对格点特别敏感）。遇到"莫名其妙的小虚频"，第一件事就是加密格点重算。

拓展 · -V/T 位力比：一个免费的自检指标

位力定理 (virial theorem) 对库仑体系（分子在平衡几何处）给出：

位力定理⟨V⟩ = −2⟨T⟩　⟹　−V/T = 2.000　；　E = −⟨T⟩ = ½⟨V⟩
⟨T⟩总动能永远为正
⟨V⟩总势能核吸引 + 电子排斥 + 核排斥，净值为负

怎么用它自检：如果输出的 -V/T 明显偏离 2.000（比如 1.98 或 2.05），说明：

  • 几何还没优化到极小点（位力定理只在驻点严格成立），或
  • 基组太差、SCF 没真正收敛

讲义例子里是 2.0012，偏离 0.06%，非常正常（有限基组下总有小偏差）。

分析 log 文件的标准流程（做作业时按这个顺序查） 
grep 'Normal termination' job.log     # 1. 正常结束了吗?
grep 'SCF Done' job.log | tail -1     # 2. 最终能量
grep -A4 'Stationary point found' job.log   # 3. 优化收敛了吗?
grep 'Frequencies' job.log | head -3  # 4. 有虚频吗?(负数=虚频)
grep -A10 'Mulliken charges' job.log  # 5. 原子电荷

拓展 · ORCA 为什么在光谱性质上是第一

它的作者 Frank Neese 是理论光谱学家，ORCA 专门为"算实验能测到的谱学参数"设计：

性质对应实验
g 张量EPR 谱的位置
超精细耦合 AEPR 的超精细分裂（探测未成对电子在核处的密度）
零场分裂 D、E高自旋体系的 EPR，单分子磁体的能垒
交换耦合常数 J磁化率曲线（用 BS-DFT 算，见 p45）
NMR 化学位移与耦合常数NMR 谱

另外 ORCA 的 DLPNO-CCSD(T) 是近年最重要的算法进展之一：把 CCSD(T) 的标度从 O(N⁷) 降到接近线性，让 100+ 原子的黄金标准计算成为可能。这是"算法胜过硬件"（第 1 讲 p21）的最好例证。

"没有对称性因子化"是什么意思

Gaussian 会自动检测分子的点群对称性，把 Fock 矩阵分块（p69 会讲），从而省几倍时间。ORCA 完全不用对称性——它把每个分子都当成 C₁ 处理。

后果：对高对称性的分子（如二茂铁 D5d、苯 D6h），Gaussian 可能快好几倍。但对没有对称性的真实分子（绝大多数），这个缺点不存在。

拓展 · CASSCF 的核心概念：活性空间 (active space)

你以后做作业 3 会用到，先建立概念。CASSCF(n,m) 的意思是：

把 n 个电子放进 m 个轨道里，在这个小空间内做 Full CI（穷尽所有排布方式），同时优化轨道

怎么选活性空间（这是 CASSCF 最难、最需要经验的部分）：

  • 过渡金属：至少把 5 个 3d 轨道 + 相应电子放进去。Fe²⁺ 就是 CAS(6,5)
  • 共轭体系：把所有 π 和 π* 放进去。苯是 CAS(6,6)
  • 断键：把成键 σ 和反键 σ* 一起放进去。H₂ 解离是 CAS(2,2)

规模限制：组态数随 m 阶乘增长，实际极限约 CAS(16,16)（约 10⁸ 个组态）。超过就要用 RASSCF（限制激发级别）或 DMRG。

关键补充：CASSCF 只处理静态相关，它不包含动态相关。所以实践中总是 CASSCF 之后再做 CASPT2 或 NEVPT2（二阶微扰）把动态相关补上——这就是 p7 里 "CASSCF/CASPT2" 总是一起出现的原因。

p25–28变分原理：计算化学最重要的定理

原文翻译（p25–26）

p25：变分原理（计算化学中最重要的定理之一）

p26：对任何算符，当我们使用它自己的基态本征态时——我们得到可能的最低本征值。

Eexact = ⟨ψexact|Ĥ|ψexact⟩ / ⟨ψexact|ψexact⟩

当我们用一个近似函数（即不是它的本征态）来计算该算符的期望值时——结果永远更高。

Etrial = ⟨ψtrial|Ĥ|ψtrial⟩ / ⟨ψtrial|ψtrial⟩

上述定理表明：Etrial ≥ Eexact

证明：把试探函数在哈密顿量的精确本征态上展开（即在哈密顿量的基组中分解 ψtrial）：

ψtrial = Σi ciφi，其中 Ĥφi = εiφi

Etrial = ⟨ψtrial|Ĥ|ψtrial⟩ = ΣiΣj cj*ci⟨φj|Ĥ|φi⟩ = ΣiΣj cj*ciεi⟨φj|φi⟩ = ΣiΣj cj*ciεiδji = Σi ci*ciεi

另一方面：Eexact = ⟨φ₁|Ĥ|φ₁⟩ = ε₁

p27：两者之差：

Etrial − Eexact = Σici*ciεi − ε₁ = Σici*ci(εi − ε₁) ≥ 0

这个不等式来自 ci*ci ≥ 0 和 εi ≥ ε₁。

公式解析 · 变分原理

★ 变分原理（Variational Principle） Etrial = ⟨ψtrial|Ĥ|ψtrial⟩ / ⟨ψtrial|ψtrial⟩  ≥  Eexact
符号名称含义
ψtrial试探波函数你随便猜的一个（合法的）波函数，通常含有一些可调参数
Etrial试探能量用这个猜测算出来的能量期望值
ε1真实基态能量哈密顿量的最低本征值
ci展开系数试探函数在真实本征态 φi 上的投影
δjiKronecker delta正交归一性：j=i 时为 1，否则为 0
这个定理为什么是计算化学的立身之本

它给了你一个绝对的、无需知道正确答案的质量判据：能量越低 = 波函数越好。

这非常了不起。想象一下没有它的世界：你算出 −76.02 Hartree，别人算出 −76.05，你完全不知道谁更接近真相。有了变分原理，答案是：−76.05 更好，一定。

三个直接推论：

  1. 可以用"最小化能量"来确定参数——这就是 HF 求轨道系数的依据（第 2 讲 p84）。
  2. 更大的基组一定给出更低（更好）的能量——因为小基组是大基组的一个子集，大基组能表达的试探函数更多（p5 第 4 讲的表格）。
  3. 不同方法的能量可以直接比较（前提是同一个体系、同一个几何、都是变分方法）。

讲解 · 证明的关键一步在哪里

整个证明就靠最后那个不等式
Etrial − ε1 = Σi |ci|² · (εi − ε1) ≥ 0
  • |ci|² ≥ 0：模长平方，永远非负
  • (εi − ε₁) ≥ 0：因为 ε₁ 是最低的本征值，所有其他 εi 都不小于它

非负 × 非负 = 非负，求和还是非负。∎

等号什么时候成立？只有当所有 i≠1 的 ci = 0，即 ψtrial 恰好就是 φ₁ 本身。

原文翻译（p28）· 变分法的四步流程

很常见的情况是我们没有精确波函数，但能构造一个近似函数。通常近似波函数含有一些可以在计算中调整的参数。

  • 步骤 1：构造试探波函数 ψtrial = Σciφi
  • 步骤 2：用公式计算能量的试探值 Etrial = ⟨ψ|Ĥ|ψ⟩/⟨ψ|ψ⟩
  • 步骤 3：令能量对所有变分系数的一阶导数等于零：∂Etrial/∂ck = 0。解出这个方程组，得到变分参数 ck
  • 步骤 4：用得到的 ck 计算最终能量 Etrial_best

满足步骤 3 条件的那组参数 ck 称为解。它们是 ψtrial 的最佳变分参数，得到的能量是可能的最低值。进一步的改进只能通过：

  1. 增加变分参数的数目（扩大函数基组）
  2. 改变波函数的表示形式（这也包括增加待优化参数的数目）
拓展 · 这四步就是 Hartree–Fock 的骨架
变分法的步骤在 HF 里对应什么
步骤 1试探函数 = 一个 Slater 行列式，可调参数 = MO 系数 csi（第 2 讲 p86）
步骤 2能量表达式 = E = 2ΣHi + Σ(2J−K) + VNN（第 2 讲 p83）
步骤 3∂E/∂csi = 0（加上正交归一约束，用拉格朗日乘子）→ 推出 Fock 方程 F̂φi = εiφi
步骤 4SCF 迭代收敛后，代回去算总能量
a) 扩大基组用更大的基组（p70–76）→ 能量单调下降到 HF 极限
b) 改变波函数形式用多个 Slater 行列式 → CI / MCSCF / CASSCF（p79–80，第 4 讲）

最后这两行是一张地图：HF 之后往哪走，只有两个方向——把基组做大（水平方向），或把波函数形式做复杂（垂直方向）。第 4 讲 p43 会把这两个方向画成一张二维收敛图。

重要限制：变分原理只对能量成立，对其他性质不成立

第 4 讲 p5 会明确说："由于误差抵消效应，变分原理一般不适用于能量以外的性质，甚至不适用于能量差。"

意思是：更大的基组给出更低的绝对能量（这是保证的），但不保证给出更准的偶极矩、键长、反应能垒。因为这些量是差值或导数，误差可能抵消也可能放大。

实际后果：有时候 HF/6-31G(d) 算出的键长比 HF/cc-pVQZ 更接近实验值——不是因为它更好，而是因为基组误差恰好抵消了缺少电子相关的误差。这种"两个错误互相抵消"的现象在计算化学里极其普遍，也是为什么大家会固定用某些"经验上好用"的组合（如 B3LYP/6-31G(d)）。

p29–35变分法实例：氢原子（完整算两遍）

原文翻译（p29–32）· 例题一

p29：H 原子基态是 ψ1s = (1/√π)e−r，E1s = −½ (a.u.)

假设我们不知道这个函数。我们可以假定描述 H 原子的一个好函数是：

ψtrial = √(α³/π) e−αr

参数 α 取什么值能给出最低的能量？

p30 解答：1) 检查 ψtrial 是否归一化：

∫ψ*ψdτ = (α³/π)∫₀πsinθdθ∫₀2πdφ∫r²e−2αrdr = (4πα³/π)·(2/(2α)³)·… = 1

这说明试探波函数是归一化的。

2) 用这个试探函数计算能量：E = ∫ψ*Ĥψdτ

p31：Ĥψtrial 的作用可以单独计算：

Ĥψtrial = [−½(1/r²)(d/dr)(r² d/dr) − 1/r]√(α³/π)e−αr = … = [(α−1)/r − α²/2]√(α³/π)e−αr

代入能量表达式：

E = 4π(α³/π)∫[(α−1)/r − α²/2]r²e−2αrdr = 4α³(α−1)∫re−2αrdr − 2α⁵∫r²e−2αrdr = … = α²/2 − α

p32：3) 计算能量对参数 α 的导数：

dE/dα = α − 1

令 dE/dα = 0，得到 α = 1

ψtrial = (1/√π)e−r = ψ1s

这一次我们很幸运，试探波函数的形式能够变成真实的波函数。

解析 · 例题一的完整逻辑

符号名称含义
α变分参数这个例子里唯一的可调旋钮。物理含义是"轨道的收缩程度"——α 越大，e−αr 衰减越快，轨道越紧。
√(α³/π)归一化常数它依赖 α——每换一个 α，归一化常数也要跟着变，才能保持 ∫|ψ|²=1
dτ球坐标体积元= r²sinθ dr dθ dφ。注意那个 r² 因子——它是径向积分里出现 r² 和 r 的原因。
积分部分怎么算（讲义省略的地方）

角度部分：∫₀πsinθdθ = 2，∫₀2πdφ = 2π，乘积 = 4π。因为被积函数只依赖 r，角度积分就是球面的立体角 4π。

径向部分用标准积分公式：

∫₀∞ rn e−br dr = n! / bn+1
积分nb结果
∫r²e−2αrdr22α2!/(2α)³ = 2/(8α³) = 1/(4α³)
∫re−2αrdr12α1!/(2α)² = 1/(4α²)

验证归一化：(α³/π)·4π·1/(4α³) = 1　✔

验证能量：
第一项：4α³(α−1)·1/(4α²) = α(α−1) = α² − α
第二项：−2α⁵·1/(4α³) = −α²/2
合计：α² − α − α²/2 = α²/2 − α　✔ 与讲义一致

最后一步：求极小

E(α) = α²/2 − α 是一条开口向上的抛物线。

dE/dα = α − 1 = 0 ⟹ α = 1

代回去：Emin = 1/2 − 1 = −0.5 Hartree　✔ 正好等于精确值！

为什么这么完美：因为试探函数的形式 √(α³/π)e−αr 在 α=1 时恰好就是精确解。试探函数"包含"了精确解，所以变分法能找到它。

原文翻译（p32–35）· 例题二（更有教育意义）

p32 末–p33：假设另一种情况，ψtrial 不能变成真实的 ψ1s：

ψtrial = √(α⁵/3π)·r·e−αr

练习：证明 ψtrial 是归一化的。

按之前的步骤：Ĥψtrial = … = [−1/r² + (2α−1)/r − α²/2]√(α⁵/3π)re−αr

p34：计算能量得：

E = 4π(α⁵/3π)∫[−1/r² + (2α−1)/r − α²/2]r⁴e−2αrdr = … = (4/3)(α²/8) − 3α/8

对 α 的一阶导数：dE/dα = 0 = (4/3)(α/4) − 3/8，得 α = 3/2

改进后的波函数是：ψtrial′ = √(243/96π)·r·e−(3/2)r

E = (4/3)(3/2)²/8 − 3(3/2)/8 = −3/8 a.u.

这个能量高于最低本征值（−½ a.u.），但远低于第二本征值（−1/8 a.u.）。这个能量接近 1s 态的真实能量。

这个 ψtrial′ 中真正的 1s 成分权重是多少？

例题二的关键教训
量数值 (a.u.)说明
精确的 E1s−0.500目标

这个例子比第一个更有价值：它展示了变分法在"试探函数形式不包含精确解"时的表现——能量仍然是上界，但不再是精确值。

为什么这个试探函数不好：ψ ∝ re−αr 在 r=0 处等于零，而真实的 1s 在核处有最大值（还有个尖点 cusp）。试探函数在最重要的区域（核附近）完全错了，所以能量差得多。

这正好对应基组选择的实践：一个基组好不好，关键看它能不能描述"电子密度实际上大的那些区域"。这就是为什么高斯基组要用收缩（多个高斯拼一个 STO，p72–73）——单个高斯在核处是平的（导数为 0），描述不了尖点。

ψtrial′ = c1sψ1s + c2sψ2s + c3sψ3s + c2pxψ2px + c2pyψ2py + c2pzψ2pz + ⋯

除了含 c1s 的那一项，其余各项都会消失，因为哈密顿量的本征态彼此正交。因此：

c1s = ∫ψ1s*ψtrial′dτ

p46Fock 算符与正则轨道：轨道并不唯一

原文翻译

Fock 算符（它定义了一个电子的有效动能以及对所有核的吸引）：

Fi = hi + Σj≠iN(Jj − Kj)

HF 轨道能就是 Fi 算符的本征值：Fiφi = εiφi

当 HF 轨道优化计算完成后，φi 是正则分子轨道 (canonical molecular orbitals)。在正则分子轨道基下写出的 Fock 算符是对角的。

对同一个 HF 波函数，存在许多可能的轨道集合，它们给出相同的总能量。

任何由收敛的分子轨道经过某个幺正变换得到的轨道集合——都会给出完全相同的 HF 总能量。

例：天然轨道 (natural orbitals) 是通过对角化单电子密度矩阵得到的。

公式解析 · "幺正变换下总能量不变"

★ 轨道的幺正变换不改变物理 φ′i = Σj Uji φj　（U 是幺正矩阵：U†U = 1）
⟹ ΨHF 只差一个相位， E 不变， ρ(r) 不变
符号名称含义
U幺正矩阵unitary matrix。相当于"在轨道空间里做一次旋转"——保持长度和夹角不变
U†共轭转置转置再取复共轭。实矩阵时就是转置 UT
ρ(r)电子密度可观测量。它在幺正变换下不变
为什么会这样（行列式的性质）

Slater 行列式在列的线性组合下，只会乘以变换矩阵的行列式 det(U)。而幺正矩阵的 |det(U)| = 1，所以 Ψ 只差一个模长为 1 的相位因子 → |Ψ|² 完全不变 → 所有物理量不变。

这一页的含义比它看起来重要得多

"轨道"不是物理实在，它是一个可以任意重新组合的数学工具。只有占据轨道张成的整个空间（以及由它得到的电子密度）才有物理意义。

这解释了两个常见困惑：

  • "为什么甲烷的光电子谱有两个峰，但我画的四个 sp³ 杂化轨道能量相同？"
    因为 sp³ 是定域轨道，而 PES 测的是正则轨道（a₁ 和 t₂，能量不同）。两套轨道描述同一个电子密度，都对，但只有正则轨道的能量对应电离能（见 p47 Koopmans 定理）。
  • "不同软件算出的轨道图不一样"
    只要总能量和密度一样，就没有矛盾。

公式解析 · Koopmans 定理

★ Koopmans 定理 IE ≈ −εHOMO　；　EA ≈ −εLUMO

这个定理的核心假设，也是它的核心问题

看 p47 第一行："Consider that the orbitals remain exactly the same as in the original calculation."

这个假设叫"冻结轨道近似 (frozen orbital approximation)"——假装拿走一个电子后，剩下的电子完全不动。

现实是：拿走一个电子后，剩下的电子会向核收缩（因为屏蔽减少了），这个过程叫轨道弛豫 (orbital relaxation)，会降低离子的能量，使真实的 IE 小于 −εHOMO。

讲解 · Koopmans 定理为什么在 HF 里"意外地准"

忽略相关能的变化

这是计算化学里最著名的"误差抵消"案例之一——它对应第 4 讲 p5 说的"error compensation effects"。

对 DFT 千万不要直接套用 Koopmans 定理

Kohn–Sham 轨道能不是 HF 意义上的轨道能。常规 GGA/杂化泛函（B3LYP、PBE）的：

  • εHOMO 会严重高估（即 |εHOMO| 比真实 IE 小 3–5 eV），根源是自相互作用误差 (SIE) 和错误的长程渐近行为
  • HOMO–LUMO 能隙会严重低估（半导体带隙常被低估 50%）

正确做法：用 ΔSCF 方法——分别算中性和离子的能量，取差值。

IE = E(阳离子, 各自优化) − E(中性, 各自优化)

这样轨道弛豫被自动包含了，精度高得多。但代价是要算两次。

p49–50B 原子：HF 从根本上不适用的一个例子

原文翻译（p49–50）

p49：假设我们要计算自由 B 原子的基态。你有两个选择：

  1. 不假思索地开始计算（输入相当平凡）
  2. 做一点小练习，试着理解波函数的本质是什么。Hartree–Fock 波函数合适吗？请论证。

p50：B 的基态电子组态是 1s²2s²2p¹。

由于 2p 壳层是简并的，最后一个壳层的电子可以放在这些轨道中的任何一个。而且，波函数是对现实的一种概率性表示——必须把所有可能性平等地包含进来。

结果是，这个体系有三个可能的 Slater 行列式。波函数是这三个行列式的线性组合：

ψ = (1/√3)·[φ1s²φ2s²φ2px¹ + φ1s²φ2s²φ2py¹ + φ1s²φ2s²φ2pz¹]

鉴于 HF 方法只优化一个 Slater 行列式的分子轨道——它对这个问题是不合适的。为了定性正确地描述这个解，对自由 B 原子必须使用多组态自洽场方法 (CASSCF)。

这是一个典型的"静态电子相关"问题。

讲解 · 为什么必须用三个行列式

问题的根源：简并 + 对称性

B 原子是球对称的（孤立原子）。三个 2p 轨道（px, py, pz）能量完全相同、方向完全等价。

如果你强行只用一个行列式，比如把电子放进 2pz，那么你得到的波函数在 z 方向和 x、y 方向就不一样了——你人为地破坏了球对称性。

得到的电子密度会是个哑铃形，而真实的 B 原子密度必须是球形的。

静态相关 vs 动态相关（第 4 讲 p4 的核心区分）
静态相关 (static)动态相关 (dynamic)
本质单个 Slater 行列式从原理上就不够（有几个组态权重相当）单个行列式定性上对，但缺少电子瞬时躲避的细节
典型场景简并/近简并：B 原子、断键、过渡金属 d 轨道、双自由基、激发态所有体系都有；主要来自电子对的短程排斥
能量大小可以很大（几十 kcal/mol）每对电子约 25 kcal/mol，但总量大
怎么补CASSCF / MCSCF（少量组态，但必须选对）MP2 / CCSD(T)（海量组态，但权重都很小）
诊断信号天然轨道占据数偏离 0/2；⟨S²⟩ 污染严重；T₁ 诊断 > 0.02；SCF 难收敛—（总是存在）

最重要的一条：静态相关必须先处理。如果参考波函数（HF）本身就是错的，那么在它基础上做 MP2/CCSD 会给出灾难性的结果——第 4 讲 p39 明说 "In systems with homolytic bond cleavage or degeneracies, MPn, CI and CC methods can fail dramatically."

p51–53限制与非限制 SCF、自旋污染

原文翻译（p51–52）

p51：Hartree–Fock 理论中使用的哈密顿量没有显式提到自旋，因此它对自旋有一个对称性——自旋翻转不改变能量。如果我们强制这个对称性（要求自旋向上和向下的轨道共用空间部分），得到的 Hartree–Fock（更一般地说 SCF）版本就叫限制的 (restricted)。

在开壳层体系中，倾向于用非限制的 (unrestricted) 版本，其中两个空间部分被允许不同。

p52：限制 SCF 通常更快（需要计算的积分更少），但无法重现某些断键过程。非限制 SCF 正确地处理断键（虽然是出于错误的理由），但可能遭受自旋污染——得到的波函数往往不是总自旋算符的本征态。

原文翻译（p53）

非限制 SCF 方法产生的波函数不是总自旋算符的本征函数。这会导致计算的磁性质发生畸变，最好避免。

处理自旋污染的三种常见方法：

  • "湮灭 (annihilation)" 方法：在 SCF 过程结束后投影掉具有错误总自旋的项
  • "投影 (projection)" 方法：在 SCF 循环内部投影掉具有错误总自旋的项
  • "自旋约束 (spin constraint)" 方法：把偏离目标总自旋的量作为拉格朗日项引入约束能量优化问题

大多数软件包在 SCF 结束时会打印总自旋的期望值。大的自旋污染（尤其是在 Hartree–Fock 计算中）通常表明单个行列式对基态是非常差的近似——应当考虑 MCSCF 方法。

⟨Ŝ²⟩UHF ≥ ⟨Ŝ²⟩exact = S(S+1) = (nunpair/2)·(nunpair/2 + 1)

讲解 · 为什么 UHF 会自旋污染（数学根源）

根源：UHF 行列式不是 Ŝ² 的本征函数

回想第 2 讲 p68：4 个自旋函数中，α₁β₂ 和 α₂β₁ 单独都不是 Ŝ² 的本征函数，必须组合成 (α₁β₂ ± α₂β₁)/√2 才行。

而一个 UHF 行列式只包含 α₁β₂ 这一种排布，天然是"单重态和三重态的混合"。

RHF 为什么没这个问题：因为 α 和 β 共用空间轨道，行列式恰好等于那个正确的组合。

★ 密度矩阵 Dγδ = Σj占据轨道 cγj cδj
符号名称含义

为什么要引入密度矩阵（三个理由）
  1. 它是真正的物理量：电子密度 ρ(r) = ΣαβDαβχα(r)χβ(r)。轨道可以幺正变换（p46），但 D 不变——它是幺正变换的不变量。
  2. 它让公式变简洁：F = h + G·D，E = tr(Dh) + …，全部是矩阵运算，直接对应代码。
  3. 它是 SCF 的收敛判据：p60 的流程图里判断收敛，看的就是 D 变不变（RMSDP、MaxDP）。

Mulliken 布居分析就是从 DS 来的：原子 A 上的电子数 = Σα∈A(DS)αα。这就是 p81 练习里要看的"Mulliken charges"。

Mulliken 电荷的著名缺陷

它把两个原子之间的重叠电荷平均分配给两个原子——但当两个原子电负性差别很大时，这显然不合理。

后果：Mulliken 电荷对基组极其敏感。换个基组，同一个分子的 Mulliken 电荷可能从 +0.3 变成 −0.1。加了弥散函数之后尤其糟糕。

更好的选择：NBO 电荷（较稳定）、Hirshfeld / CM5 电荷（基于密度划分）、ESP 拟合电荷（CHelpG、RESP，最适合做力场参数）。

但记住：原子电荷不是可观测量——它依赖于你怎么划分空间。只能用来比较趋势，不要当成实验值。

  • 体系有近简并，电子在两个组态之间跳
  • 数值格点太粗（p4 的 grid 问题）

p64RI 近似（密度拟合 / Cholesky 分解）

原文翻译

恒等分解 (Resolution of Identity, RI) 是一个把任意完备基组与该空间上的恒等算符联系起来的等式：

1̂ = ΣPN |φP⟩⟨φP|

用这个算符，2-ERI 可以写成：

⟨χαχγ|g|χβχδ⟩ = ΣP,QNaux ⟨χαχγ|g|P⟩ (P|Q)−1 ⟨Q|g|χβχδ⟩

节省来自以下几点：

  1. ⟨χαχγ|g|P⟩ 和 ⟨Q|g|χβχδ⟩ 是三指标矩阵。P, Q 称为拟合基组，是有限的，且比两个原始基函数乘积（即 Nbasis²）小得多
  2. 矩阵 (P|Q) 可以存在活动内存 (RAM) 中
  3. HF 原本的标度是 N⁴。用 RI 后标度降到 N³ 甚至更低，取决于计算机的内存
  4. 2-ERI 的 Cholesky 分解是 RI 方法的一种特殊形式

讲解 · RI 的核心思想（把四指标变三指标）

符号名称含义
P, Q辅助基组
(auxiliary basis)		专门用来展开"电荷密度"的一套额外基函数。通常 Naux ≈ 3–4 × Nbasis——听起来更多，但它只有一个指标
(P|Q)−1度规矩阵的逆辅助基函数之间的库仑相互作用矩阵的逆。只有 Naux×Naux，很小，能放内存
1̂ = Σ|φP⟩⟨φP|恒等分解数学上：在一组完备正交基下，"插入一个恒等算符"不改变任何东西。这就是名字 "resolution of identity" 的来源。
物理直觉：把"两个函数的乘积"当成一团电荷来拟合

双电子积分本质上是"电荷分布 1"和"电荷分布 2"之间的静电排斥。其中"电荷分布 1"就是 χα(r)χγ(r) 这个乘积。

RI 的想法：不必精确表示这个乘积，用一组辅助函数把它拟合出来就行。因为最终要算的是积分（一个数），拟合的小误差影响很小。

3) 能级移动 (Level shifting)：这个方法在于人为地增大 HOMO–LUMO 能隙，这会立刻使下一次迭代中占据轨道与空轨道之间的混合变小。

在 SCF 完全收敛时 ⟹ 占据轨道与空轨道之间的混合 = 零。

通过能级移动，收敛变得有保证，但它也可能收敛到局部极小。

原文翻译（p68）· 技巧 4

4) 迭代子空间直接反演 (DIIS)：对第 n+1 次迭代，我们把 Fock 矩阵构造成之前所有 n 个 Fock 矩阵的线性组合：

Fn+1′ = Σin ciFi

系数 ci 通过最小化下列"误差"函数得到：

f(c) = Trace(FDS − SDF)²

约束条件是 Σin ci = 1。F、D、S 分别是 Fock 矩阵、密度矩阵和重叠矩阵。

4) Newton–Raphson (NR)、共轭梯度 (CG) 等方法 ⟹ 它们利用轨道梯度（一阶导数）和轨道 Hessian（二阶导数）来预测最好的 Fock 矩阵。在极小点附近收敛良好。Hessian 计算昂贵。如果 DIIS 失败，可以使用 NR 或 CG 方法。

公式解析 · 四个技巧各自在做什么

技巧 2：阻尼 (Damping) —— 最容易理解
阻尼D用于下一轮 = ω·D旧 + (1−ω)·D新
ω阻尼因子0 到 1 之间。ω=0 表示完全用新的（无阻尼）；ω=0.9 表示 90% 保留旧的

物理图像：SCF 常见的失败模式是振荡——密度在两个值之间来回跳，永远不收敛（p66 那张图画的就是这个）。阻尼相当于"每次只走一小步"，把振荡压下去。

代价：收敛变慢（需要更多轮）。所以通常只在前几轮用阻尼，后面关掉。

技巧 3：能级移动 (Level shift)

做法：人为地在所有空轨道的对角元上加一个正的常数（如 +0.3 Hartree），把它们抬高。

为什么管用：微扰论告诉我们，占据轨道和空轨道的混合程度 ∝ 1/(ε空 − ε占)。gap 越大，混合越小，迭代越"温和"。

关键性质：收敛之后，占据-空混合应该恰好为零，所以 level shift 不影响最终结果（只影响路径）。

但 p67 那句警告很重要

"convergence becomes guaranteed, but it may also converge to local minima."

level shift 强行阻止了轨道重排，所以可能把你锁死在一个不是全局最低的解上。典型症状：过渡金属配合物收敛到了错误的 d 电子组态。

对策：收敛后用 stable=opt（Gaussian）检查 SCF 解的稳定性。

技巧 4：DIIS —— 现代 SCF 的默认主力
DIIS 的误差向量 ei = FiDiS − SDiFi　；　最小化 ‖Σciei‖²，约束 Σci = 1
符号名称含义
FDS − SDF误差矩阵这个量在完全收敛时严格等于零。所以它的大小直接衡量"离收敛还有多远"
ci组合系数可以是负数——这就是它比简单平均强的地方，能做外推
Σci = 1归一化约束保证组合出的 Fock 矩阵仍然是"合法"的
为什么 FDS − SDF = 0 是收敛判据

回想 Roothaan 方程 FC = SCε。收敛时，F 和 D 有共同的本征向量，两个矩阵对易（在 S 度规下）。

而 FDS − SDF 正是这个"广义对易子"。它等于零 ⟺ 自洽达成。

这就是 DIIS 的天才之处：它有一个不需要知道正确答案就能计算的误差度量，于是可以像做曲线拟合一样，从历史迭代中外推出最优的下一步。

效果：DIIS 通常把迭代次数从 50+ 降到 10–15。它由 Pulay 在 1980 年提出（第 1 讲 p8 的人名表里那个 Pulay），是量子化学里最重要的算法之一，现在所有软件都默认开启。

实战：SCF 不收敛时的排查顺序
  1. 先检查结构：原子重叠了吗？键长是不是荒谬（0.5 Å 或 5 Å）？这是最常见的原因，而不是算法问题。用 GaussView 看一眼。
  2. 检查电荷和多重度：写错了会导致物理上不合理的体系。
  3. 换初始猜测：guess=huckel，或从小基组 guess=read。
  4. 用二次收敛 SCF：Gaussian 的 scf=xqc（先跑 DIIS，失败自动切二次收敛）或 scf=qc（直接用，慢但稳）。
  5. 加阻尼/能级移动：ORCA 的 %scf damp fac 0.7 end、shift shift 0.3 end。
  6. 加大迭代上限：scf=(maxcycle=512)。
  7. 如果都不行：这可能不是数值问题，而是体系本身是多参考的（p49–50）——考虑 CASSCF。

p69对称性的利用

原文翻译

如果分子有对称性（例如平面正方形、反演中心、八面体、三角形等），我们可以利用这个对称性来加速计算。

  1. 用相应的点群对称操作生成对称性匹配的原子轨道线性组合 (SALCs)，作为分子轨道的初始猜测
  2. Fock 矩阵 Fαβ、核哈密顿矩阵 hαβ、双电子积分、密度矩阵 Dαβ 都会变成块对角的

（给出块对角矩阵示意：Irrep 1/2/3/4 各占一块，块外全是 0）

  • 只存非零部分 ⟹ 显著节省空间和内存
  • 块对角矩阵的乘法也快得多
  • 收敛也得到改善

讲解 · 为什么对称性能省钱

核心事实：不同对称性的轨道之间，矩阵元严格为零
⟨φA₁|F̂|φB₂⟩ = 0　（因为 F̂ 是全对称的）

这是群论的一个基本定理：只有当被积函数含有全对称成分时，积分才可能非零。

后果：把基函数按不可约表示（irrep）分组后，Fock 矩阵变成块对角的——只有同一 irrep 内部的块非零。

省了多少

假设有 N 个基函数，分成 k 个大小相等的 irrep 块，每块 N/k 个。

操作不用对称性用对称性
存储N²k·(N/k)² = N²/k
对角化N³k·(N/k)³ = N³/k²

对 D6h 的苯（12 个 irrep），对角化理论上能快 100 倍以上。

对称性的三个坑（实践中很重要）
  1. 它可能把你锁在错误的对称性上。优化时如果分子想要发生 Jahn–Teller 畸变（降低对称性来降低能量），强制保持高对称性会让你收敛到一个鞍点而不是极小点。症状：频率算出虚频，且虚频对应的振动模式会破坏对称性。
    对策：加 nosymm 重新优化，或沿虚频方向微扰后重算。
  2. 激发态、过渡态计算常常要关掉它。
  3. Gaussian 会自动"调整"你的坐标到标准取向（Standard orientation），这有时会让人困惑——输出里的坐标和你输入的不一样。用 nosymm 可以保持原始取向。
拓展 · SALC 是什么（和你无机化学学的对上）

SALC = Symmetry-Adapted Linear Combination（对称性匹配线性组合）。你在无机化学画 MO 图时，把配体轨道组合成"符合中心原子对称性"的那些组合——就是 SALC。

例：八面体 ML₆ 的 6 个配体 σ 轨道，组合成 a1g + eg + t1u 三组 SALC，分别与金属的 s、dz²/dx²−y²、p 轨道成键。

而 t2g（dxy, dxz, dyz）找不到对称性匹配的配体 σ SALC ⟹ 保持非键 ⟹ 这就是 Δo 分裂的来源。这是配位场理论的量子力学基础。

公式解析 · STO 与 GTO 的根本区别

★ 两种基函数 STO（Slater 型）：  χ ∝ e−ζr　　　GTO（高斯型）：  χ ∝ e−αr2
符号名称含义
ζSlater 指数希腊字母 zeta。控制 STO 的衰减快慢

为什么全世界都用 GTO，尽管它物理上是错的

唯一的理由：高斯乘积定理。

e−α|r−A|² × e−β|r−B|² = K · e−(α+β)|r−P|²

两个不同中心的高斯函数，乘积仍是一个高斯函数（中心在 P，是 A 和 B 的加权平均）。

后果：一个四中心积分 ⟨χAχB|g|χCχD⟩ 立刻塌缩成一个双中心积分，而且有闭式解析公式。

STO 没有这个性质——它的四中心积分必须数值算，慢几个数量级。这就是为什么 ADF（唯一用 STO 的主流软件，p10）只做 DFT 而不做 HF/post-HF：DFT 不需要那个非局域的交换积分（第 2 讲 p85），所以 STO 的困难被绕过了。

讲解 · 收缩 (contraction)：用几个 GTO 拼一个 STO

STO-3G 的名字就是在说这件事

STO-3G = "用 3 个 Gaussian 拟合一个 STO"。

χ1sSTO-3G = a1·e−α1r² + a2·e−α2r² + a3·e−α3r²

其中一个 α 很大（窄尖，管核附近），一个中等，一个很小（宽扁，管长程）。三个加起来的形状就很接近 e−ζr 了。

关键点：这 3 个高斯的系数 ai 和指数 αi 是预先拟合好、固定不变的。SCF 只优化"这一整个收缩函数"前面的 MO 系数 c。

原始高斯 (primitive) 数量 ≫ 收缩基函数 (contracted) 数量
积分算在 primitive 上（贵），矩阵维度是 contracted（省）

这就是"收缩"的意义：用一点点精度损失，换取矩阵维度的大幅降低。

讲解 · 极化函数和弥散函数各解决什么问题

极化函数：让轨道能"变形"

规则：给 l 的轨道加 l+1 的函数。

  • H（只有 s）→ 加 p 函数（(…,p) 或第二个 *）
  • C, N, O（有 p）→ 加 d 函数（(d) 或 *）
  • 过渡金属（有 d）→ 加 f 函数

什么时候必须有：几乎总是。没有极化函数的基组（如 6-31G、STO-3G）算出的键角、二面角都不可靠。尤其是含 P、S 的分子（超价化合物）对 d 函数极其敏感。

弥散函数：描述"跑得很远"的电子

就是指数 α 非常小的高斯函数（很宽很扁），让基组能描述离核很远的电子密度。

什么时候必须加原因
阴离子（任何带负电的体系）多出来的电子束缚很松，电子云延展很远。不加弥散函数，算出的 EA 可以错 1 eV 以上
孤对电子、路易斯碱孤对比成键电子延展得远
激发态、Rydberg 态激发电子跑到很远的轨道上
弱相互作用（氢键、范德华）相互作用发生在电子云的"尾巴"处
算 EA、极化率、超极化率这些性质都由外围电子决定
但弥散函数有代价
  • SCF 变难收敛：弥散函数容易造成近线性相关（第 2 讲 p87 的拓展）
  • BSSE 变严重（下面讲）
  • Mulliken 电荷变得毫无意义

所以：需要时才加，不要无脑加。

p73 提到的 BSSE：一个必须理解的系统误差

BSSE = Basis Set Superposition Error（基组重叠误差）。第 4 讲 p37–38 会详细讲，这里先建立概念。

怎么产生的

算 A···B 复合物的结合能：ΔE = E(AB) − E(A) − E(B)

问题在于：算 E(AB) 时，A 分子可以"借用"B 分子的基函数来改善自己的描述（因为基函数是原子中心的，靠近了就能用）。而算孤立的 E(A) 时没有这些额外函数。

结果：E(AB) 被人为地降低了 ⟹ ΔE 被高估（结合得太强）。这是一个纯粹的数学假象，不是物理相互作用。

解法：Counterpoise (CP) 校正（第 4 讲 p38）
ΔECP = E(AB)AB基 − E(A)AB基 − E(B)AB基

关键：算单体时，把另一个分子的基函数留着，但把它的原子核和电子拿走（叫"ghost atoms"，幽灵原子）。这样两边用的基组就一样了，误差抵消。

Gaussian 里：counterpoise=2。

BSSE 有多大：小基组（6-31G(d)）算氢键，BSSE 可以占结合能的 30–50%！基组越大 BSSE 越小，完备基组极限下 BSSE = 0。

讲解 · 这几个问题的答题思路

问题 5："所有频率都是实数吗？为什么这很重要？"

答：振动频率来自 Hessian 矩阵（能量的二阶导数矩阵）的本征值。

ν ∝ √(k/μ)，其中 k 是力常数 = Hessian 的本征值
Hessian 本征值频率意味着什么
全部 > 0全实（正）真正的极小点（稳定结构）✔
恰好 1 个 < 01 个虚频
（打印成负数）		一阶鞍点 = 过渡态。虚频对应的振动模式就是反应坐标
2 个以上 < 0多个虚频高阶鞍点，没有化学意义，必须重新优化

为什么重要：如果不检查频率，你可能报告了一个根本不是稳定结构的"分子"。另外，只有在真正的驻点上，热力学量（零点能、焓、熵、吉布斯自由能）才有意义。

补充：非线性分子应该有 3N−6 个振动频率，线性分子 3N−5 个（另外 6 个/5 个是平动和转动，频率接近 0）。

问题 7：Mulliken 电荷 —— 邻甲酚的预期答案

邻甲酚 = 苯环 + OH + CH₃（邻位）。

  • 最负：酚羟基的 O（电负性最强，且有两对孤对电子）
  • 最正：羟基上的 H（被 O 强烈拉走电子密度）

但要写上注意事项（这会显示你真的理解了）：Mulliken 电荷对基组高度敏感，不是可观测量，只能用来比较同一体系内不同原子的相对趋势。（见 p58 的拓展）

问题 8：为什么两次计算的频率会不同

两处差异叠加：

  1. 泛函不同（PBE vs RevTPSS）：PBE 是 GGA（广义梯度近似，只用密度和它的梯度）；RevTPSS 是 meta-GGA（额外用了动能密度 τ）。不同泛函给出的力常数不同。一般规律：GGA 泛函倾向于低估频率，杂化泛函（B3LYP）倾向于高估。
  2. U vs R：对邻甲酚这个闭壳层分子，UDFT 和 RDFT 在基态平衡结构处应该给出几乎完全相同的结果（第 2 讲 p91："在电子基态和平衡几何构型下，RHF 和 UHF 是等价的"）。如果差别很大，说明 UDFT 找到了一个破缺对称的解——那要检查 ⟨S²⟩ 是不是不为零。

所以预期答案：频率差异主要来自泛函，典型差别在 10–50 cm⁻¹ 量级；U/R 的差别应该可以忽略。

问题 9："哪一个更可靠？"——这是个陷阱题
不能用变分原理来回答这个问题

初学者的直觉答案是"能量低的那个更好"。这是错的，理由有两条：

  1. DFT 不是严格变分的：不同泛函的总能量不能直接比较（它们对应不同的近似哈密顿量，就像比较"用英尺量的长度"和"用米量的长度"的数值大小）。
  2. 即使对 HF，变分原理也只保证能量，不保证结构和频率（p28 的警告，第 4 讲 p5 会重申）。

正确的答题思路：

  1. 与实验对比：这是唯一的最终裁判。查 X 射线/微波谱得到的键长、IR 光谱的频率。
  2. 与更高水平的计算对比：用 CCSD(T)/大基组 算一个基准结构。
  3. 看方法的已知表现：文献里有大量 benchmark。对有机分子的几何结构，meta-GGA（RevTPSS）通常优于 GGA（PBE）；杂化泛函（B3LYP、PBE0）通常又优于 meta-GGA。
  4. 结构差异怎么量化：RMSD（均方根偏差）——把两个结构叠合后算对应原子的平均位移；或者直接列出关键的键长、键角对比表。
