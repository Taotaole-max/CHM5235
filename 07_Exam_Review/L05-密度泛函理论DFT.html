讲义封面写的是 "Electron Correlation Methods"，但这一讲的真正主题是 密度泛函理论 (DFT)。它是第 4 讲 p6 说的两条路线里的第二条：

第 4 讲：波函数方法 (CI / CC / MP2)第 5 讲：DFT
基本变量波函数 Ψ，3N 个变量电子密度 ρ(r)，永远 3 个变量
怎么补相关能加更多 Slater 行列式在 Fock 算符里换上一个近似的"交换-相关势" Vxc
代价O(N⁵) 到 O(N!)约 O(N³–N⁴)，和 HF 差不多

这一讲的逻辑链（记住这 5 步，整讲就串起来了）：

  1. p4–p9：定义电子密度 ρ(r)——它只有 3 个变量
  2. p11–p17：HK 第一定理：基态密度唯一决定一切（所以原则上只要 ρ 就够了）
  3. p19–p20：HK 第二定理：能量泛函在真实密度处取最小（所以可以用变分法找 ρ）
  4. p22–p23：Kohn–Sham：把问题变成和 HF 长得几乎一样的单电子方程，唯一的未知是 Vxc
  5. p24–p37：Vxc 不知道，只能近似 → 各种泛函（LDA → GGA → meta-GGA → 杂化 → 双杂化），以及它们的毛病

后面 p39–p43 是一个完整应用：用 DFT 算磁交换耦合常数 J（第 3 讲 p45 预告过的"破缺对称"方法），p44–45 是激发态方法 TD-DFT。

p2各种密度与分布

原文翻译

密度指某个性质在空间中的连续分布。常见的密度有：概率密度 p(x,y,z) = |ψ(x,y,z)|²；电子密度 ρ(r) = N∫|Ψ(r,r₂,…,rN)|²d³r₂⋯d³rN；自旋密度 σ(r) = ρ↑(r) − ρ↓(r)；电荷密度 ρC(r) = Ne∫|Ψ|²d³r₂⋯d³rN。

（三张图：映射了静电势的电子等密度面；修饰硅表面的电荷密度图；氧化铈中氧空位周围的自旋密度。）

讲解

这一页和第 4 讲 p44 完全相同，详细的公式解析和每个符号的标注见第 4 讲 p44。放在这里是为了引出本讲的主角——电子密度 ρ(r)。

记住第 4 讲那一页的核心结论就够了：波函数有 3N 个变量且不可观测；电子密度只有 3 个变量，而且能被 X 射线衍射直接测到。DFT 就是要"只用密度"来做量子化学。

考点
  • 电子密度的定义式里为什么乘 N、为什么要对其余 N−1 个电子积分（见第 4 讲 p44）
  • 自旋密度 = α 密度 − β 密度；它对应 EPR 实验

p4电子密度分布与密度矩阵

原文翻译

总电子密度可以作为每个单独电子的概率分布之和得到：

ρ(r) = Σi=1N |χi(r)|²　，　χi(r) = Σμ=1K cμiφμ(r)

其中 N 是体系中的电子数，K 是基组中的函数数目。因此总密度可以表示为：

ρ(r) = Σμ,ν=1K Σi=1N cμi*cνi φμ*(r)φν(r)

对全空间积分给出体系的总电子数：

N = ∫ρ(r)d³r = Σμ,νΣi cμi*cνi ∫φμ*(r)φν(r)d³r

这个表达式里通常定义两个简写：

Pμν = Σi=1N cμi*cνi　"密度矩阵"；　Sμν = ∫φμ*(r)φν(r)d³r　"重叠矩阵"；　N = Σμ,ν PμνSμν

注意：这一页的字母分工和第 3 讲是反的

第 3 讲里 φ 是分子轨道、χ 是基函数；这一页反过来——χi 是分子（自旋）轨道，φμ 是基函数。密度矩阵在第 3 讲叫 D，这里叫 P（Gaussian 输出里也叫 P）。同一样东西换了名字，别被吓到。看下标最保险：希腊字母 μ,ν 永远数基函数，拉丁字母 i 永远数轨道/电子。

公式解析 · 从轨道到密度，一步一步

第一步：密度 = 每个占据轨道的概率密度之和 ρ(r) = Σi=1N |χi(r)|²
第二步：把每个轨道用基函数展开（LCAO）后代进去 ρ(r) = Σμ,ν Pμν φμ*(r) φν(r)　，　Pμν = Σi占据 cμi*cνi
第三步：积分 → 电子总数 N = Σμ,ν Pμν Sμν = tr(PS)
符号名称含义
ρ(r)电子密度空间点 r 处单位体积里的电子数
χi分子（自旋）轨道第 i 个占据轨道。本页用 χ 表示轨道
φμ基函数第 μ 个原子轨道基函数（高斯函数），已知且固定
cμiMO 系数基函数 μ 在轨道 i 中的权重，SCF 解出来的东西
N电子数这里的求和对占据的自旋轨道进行，所以上限就是电子数
K基函数总数就是 Gaussian 输出里的 NBasis
Pμν密度矩阵把所有占据轨道的系数打包成一个 K×K 矩阵——有了它，不用再管单个轨道，密度就完全确定了
Sμν重叠矩阵两个基函数的重叠积分。对角元 = 1（基函数归一化）
* 复共轭实函数时可以忽略
tr(PS)矩阵的迹trace = 对角元之和。ΣμνPμνSμν 就等于 tr(PS)（因为 S 对称）
第二步那个双重求和是怎么来的（初学者最容易卡的地方）

|χi|² = χi*·χi。把两个因子各自展开：

χi*χi = (Σμ cμi*φμ*) · (Σν cνiφν) = ΣμΣν cμi*cνi φμ*φν

两个和相乘，就得到"每一项 × 每一项"——所以变成双重求和，下标要用两个不同的字母 μ 和 ν。然后再对所有占据轨道 i 求和，把只含 i 的部分 Σicμi*cνi 单独拎出来，起个名字叫 Pμν。密度矩阵就是这么来的。

小例子：H₂ 最小基组

2 个基函数（1sA、1sB），1 个双占据轨道 σg = c(1sA + 1sB)，c = 1/√(2(1+S))。闭壳层时 Pμν = 2Σ空间轨道cμicνi，所以：

P = 2c² [ 1 1 ; 1 1 ]　，　S = [ 1 S ; S 1 ]

N = ΣPμνSμν = 2c²(1 + S + S + 1) = 2c²·2(1+S) = 2·[1/(2(1+S))]·2(1+S) = 2　✔ 正好两个电子。

考点
  • 写出 Pμν 和 Sμν 的定义，证明 N = ΣPμνSμν
  • 为什么密度表达式里需要重叠矩阵？——因为基函数不正交（第 2 讲 p18、第 3 讲 p39）

p5把密度划分给原子和化学键：Mulliken 布居

原文翻译

现在我们可以求出某一对轨道（基函数）对总的可观测电子密度贡献了多少：

Nμν = Σi=1N cμi*cνi ∫φμ*(r)φν(r)d³r = PμνSμν　（前一部分 = 轨道布居，后一部分 = 轨道重叠）

这种按轨道对划分密度的做法在电荷分析和成键结构分析中很有用。在以原子为中心的基组中有两种情形：

  1. φμ 和 φν 在同一个原子上。Nμν 中的全部密度可以分给这个原子，解释为对它电荷的贡献。
  2. φμ 和 φν 在不同原子上。Nμν 中的密度由两个原子共享，可以解释为对化学键以及电荷的贡献。

这个形式可以推广到自旋和电荷的划分：

Pμνα = Σi cμiα*cνiα　，　Pμνβ = Σi cμiβ*cνiβ

公式解析 · 布居矩阵

★ 布居矩阵（population matrix） Nμν = Pμν · Sμν　（注意：逐元素相乘，不是矩阵乘法）
符号名称含义
Nμν布居矩阵元"基函数 μ 与 ν 这一对"分到的电子数。所有元素加起来 = N
Nμμ净布居对角元：纯粹属于基函数 μ 的电子（因为 Sμμ=1，就等于 Pμμ）
Nμν（μ≠ν）重叠布居非对角元：两个基函数"共有"的电子
Pα, Pβα/β 密度矩阵只用 α（或 β）电子的系数构造。P = Pα + Pβ（总密度），Pα − Pβ 就是自旋密度矩阵

讲解 · Mulliken 原子电荷是怎么从这张表算出来的

Mulliken 原子电荷 qA = ZA − Σμ∈A (PS)μμ
qA原子 A 的 Mulliken 电荷正 = 缺电子，负 = 富电子
ZA核电荷用 ECP 时是价电子数
(PS)μμ矩阵乘积的对角元= ΣνPμνSνμ：基函数 μ 的净布居 + 它和所有其他函数的重叠布居的一半（另一半在对面）
μ∈A"属于 A 的基函数"只对以原子 A 为中心的基函数求和
拓展 · 这一页直接对应作业里的三个输出
Gaussian / ORCA 输出从这一页的哪个量来
Mulliken charges上面的 qA 公式
Mulliken spin densities（开壳层）把 P 换成 Pα − Pβ 再做同样的分配 → 每个原子上有多少未成对电子。本讲 p48 的 Cu₂Cl₆²⁻ 作业就要看这个
Mayer 键级用 A–B 跨原子块的元素构造。单键约 1，双键约 2

老问题再提一次（第 3 讲 p58 讲过）："平分重叠布居"是一个人为约定，所以 Mulliken 电荷对基组很敏感，加弥散函数后可能完全失去意义。只能比较同一计算里不同原子的相对大小。

考点
  • Nμν = PμνSμν 的两种情形：同一原子 → 电荷；不同原子 → 化学键
  • 自旋密度 = Pα − Pβ
  • Mulliken 电荷为什么依赖基组

p6电子相关能（回顾）

原文翻译

Ψ = a₀ψHF + ΣSaSψS + ΣDaDψD + ΣTaTψT + ⋯

HF 能量：EHF = ⟨ψHF|Ĥ|ψHF⟩　；　精确能量：Eexact = ⟨Ψ|Ĥ|Ψ⟩

这是第 4 讲 p2–p3 的浓缩（详细解析见第 4 讲 p3）。S、D、T 分别是单、双、三激发行列式的下标。放在这里的目的，是提醒你DFT 要解决的仍然是这个问题：把 HF 丢掉的那 1–5% 找回来。

p7外势：什么东西决定了"这是哪个分子"

原文翻译

在 Born–Oppenheimer 哈密顿量中，分子或固体的种类由电子-原子核相互作用决定：

V̂ext = −(1/4πε₀) Σi=1Nelec ΣA=1Nnuc e²ZA/|RA − ri|　（SI 单位）　= −ΣiΣA ZA/|RA − ri|　（原子单位）

（这常被称为"外势"。）

公式解析 · 外势

★ 外势 external potential（原子单位） V̂ext = − Σi=1Nelec ΣA=1Nnuc ZA / |RA − ri|
符号名称含义
V̂ext外势所有电子感受到的原子核吸引。"外"是相对于电子而言——它不是电子之间的作用，是"外面"的核施加的
i电子编号1 到 Nelec
A原子核编号1 到 Nnuc
ZA核电荷数C=6，O=8
RA核的位置BO 近似下固定不动（大写 R 表示核）
ri电子的位置小写 r 表示电子
e, ε₀电子电荷、真空介电常数原子单位下都消失（第 2 讲 p44 拓展）

讲解 · 为什么说外势"定义了分子"

把分子哈密顿量（BO 近似后）拆开看：

Ĥ = T̂ + V̂ee + V̂ext
项对不同分子是否相同？
动能 T̂ = −½Σ∇i²完全一样——所有电子的动能算符都是同一个形式
电子排斥 V̂ee = Σ1/rij完全一样——电子之间的排斥不管在哪个分子里都是 1/r
外势 V̂ext唯一不同的地方——核在哪、带多少电荷

所以：给定电子数 N，只要知道 Vext，就知道了整个哈密顿量，也就知道了一切。苯和吡啶的区别，全在于 Vext 里有一个 Z=6 换成了 Z=7。

这一点是下面 HK 定理的起点：HK 定理要证明的，就是"知道密度 ⟺ 知道外势"。

考点
  • 外势的定义；为什么 T̂ 和 V̂ee 是"普适的"而 V̂ext 是"体系特有的"

p8–9电子密度算符

原文翻译（p8）

单个电子的电子密度算符：ρ̂(r) = δ(r′ − r)

单个电子的电子密度：ρ(r) = ⟨Ψ|ρ̂(r)|Ψ⟩ = ∫Ψ*(r′)Ψ(r′)δ(r′ − r)dr′ = Ψ*(r)Ψ(r) = |Ψ(r)|²

解释：在位置 r 找到电子的概率。

原文翻译（p9）

N 个电子的电子密度算符：ρ̂(r) = Σi=1N δ(ri − r)

N 电子的电子密度：

ρ(r) = ⟨Ψ|ρ̂(r)|Ψ⟩ = Σi=1N ∫Ψ*(r₁,r₂,…,ri≡r,…,rN)Ψ(r₁,…,ri≡r,…,rN)dr₁dr₂…dri…drN = Σi=1N|φ(ri)|²

解释：在位置 r 找到任何一个电子的概率，不管其他 N−1 个电子在哪里。

ρ(r) ≡ ρ(x,y,z) 是一个 3 变量的实函数，无论 N 多大。

公式解析 · Dirac δ 函数（这两页的关键工具）

Dirac δ 函数的定义性质 ∫ f(r′) δ(r′ − r) dr′ = f(r)
符号名称含义
δ(r′ − r)Dirac δ 函数一个"无限窄、无限高、面积为 1"的尖峰，只在 r′ = r 处非零。它的作用是"挑出"被积函数在某一点的值
r′积分变量带撇号的是"跑遍全空间"的哑变量
r探测点你想知道密度的那个位置（固定的）
ρ̂(r)密度算符"去 r 点数一数有没有电子"这个操作
ri ≡ r把第 i 个电子钉在 r只有这个电子的坐标不积分，其余全积掉
用一个比喻理解 δ 函数的"挑选"作用

想象你有一张全城人口分布图 f(r′)，你想知道某个路口 r 的人口。δ 函数就像一个只在那个路口开着的小窗口：把整张图乘上这个窗口再求和，其他地方全被乘成 0，只剩窗口里的那个值。

所以 ∫Ψ*(r′)Ψ(r′)δ(r′−r)dr′ = Ψ*(r)Ψ(r)："算密度算符的期望值"就等于"在那一点取 |Ψ|²"——这就是第 2 讲 p32 的 Born 解释，只不过换成了算符语言。

p9 的 N 电子情形：为什么是求和

密度算符 Σiδ(ri − r) 的意思是："电子 1 在 r 吗？+ 电子 2 在 r 吗？+ … + 电子 N 在 r 吗？"

每一项都给出"那个特定电子在 r 的概率"。因为电子全同，这 N 项的值完全相等，所以总和 = N × （任意一个电子在 r 的概率）。这就是第 4 讲 p44 公式里那个因子 N 的来源。

最后等于 Σi|φi|² 这一步只在单个 Slater 行列式下成立（用到了轨道正交归一）——这正是 p4 那个式子。

p9 最后一句话是 DFT 的全部动机

"ρ(r) 是 3 变量的实函数，无论 N 多大。"

体系波函数的变量数 3N密度的变量数
H₂（2 电子）63
苯（42 电子）1263
一个小蛋白（~10⁴ 电子）~30 000还是 3

如果能只用密度做量子化学，问题的复杂度就和体系大小脱钩了。但凭什么说 3 个变量的函数就包含了 3N 个变量的函数的全部信息？——这就是 HK 第一定理要回答的问题。

考点
  • 密度算符的定义 ρ̂(r) = Σiδ(ri − r) 及其物理解释
  • "ρ 只有 3 个变量，与 N 无关"——这是 DFT 相对波函数方法的根本优势

p10数学准备：单射、满射、双射

原文翻译

（五张示意图，每张左边一列 A、右边一列 B，箭头表示对应关系）

  • 不是函数：一个 A 对应多个 B
  • 一般函数：一个 B 可以有多个 A
  • 单射 (Injective)（非满射）：一个 B 不能有多个 A
  • 满射 (Surjective)（非单射）：每个 B 都有某个 A
  • 双射 (Bijective)（既单又满）：A 到 B 完美对应

讲解 · 三个词，用"学生与座位"来记

设 A = 一群学生，B = 教室里的座位，箭头 = "谁坐哪"。

类型数学定义座位比喻
函数每个 A 恰好对应一个 B每个学生都坐且只坐一个位子（不能一人占两座）
单射
injective		不同的 A → 不同的 B
（f(a₁) = f(a₂) ⟹ a₁ = a₂）		没有两个人挤同一个座位（可能有空座）
满射
surjective		每个 B 都至少被一个 A 对应没有空座位（可能有人挤一起）
双射
bijective		既单射又满射一人一座，不多不少 → 可以反过来：看座位就知道是谁
为什么 DFT 要讲这个

只有双射才能"反推"。如果"波函数 → 密度"是双射，那么知道密度就能唯一反推出波函数，于是密度里就包含了波函数的全部信息。

如果只是一般函数（两个不同波函数可以给出同一个密度），那么光看密度就分不清是哪个波函数——信息丢了，DFT 就不可能成立。p11–p16 就是在证明：它确实是双射。

讲解 · 把这张图读懂

为什么 C 是单射"不意外"

两个不同的外势（比如核的位置不同），解出的基态波函数当然不同——这是物理直觉，数学上也容易证明（两个不同的 V 不可能有相同的基态本征函数，除非它们只差一个常数）。

为什么 D 是单射"非常意外"

D 做的事是：从一个 3N 维的函数 Ψ，积掉 3(N−1) 个变量，只留下 3 维的 ρ。

直觉上这是一个极度"有损"的压缩——就像把一部电影压成一张平均亮度图，你怎么可能从平均亮度图还原出电影？

一般的波函数确实做不到（很多不同的 Ψ 可以有相同的 ρ）。HK 定理的惊人之处在于：只要限定为某个外势下的基态波函数，这种压缩就是无损的。

关键限定词是"基态"——激发态不适用。这也是为什么普通 DFT 只能算基态，激发态要用 TD-DFT（p44）。

p15★ HK 第一定理的证明（反证法，可能直接考）

原文翻译

我们要证明：如果 Ψ ≠ Ψ′，那么 ρ ≠ ρ′。

做法：假设 Ψ ≠ Ψ′ 但 ρ = ρ′，推出矛盾。

Ψ 是哈密顿量 H 的基态，基态能量为 EGS；Ψ′ 是哈密顿量 H′ 的基态，基态能量为 EGS′。V 和 V′ 是两种情况的外势。

电子数相同（否则是平凡的），因此：H = T + V，H′ = T + V′ ⟹ H = H′ − V′ + V

由变分原理：

EGS = ⟨Ψ|H|Ψ⟩ < ⟨Ψ′|H|Ψ′⟩ = ⟨Ψ′|H′ − V′ + V|Ψ′⟩ = ⟨Ψ′|H′|Ψ′⟩ + ⟨Ψ′|V − V′|Ψ′⟩ ⟹

EGS < EGS′ + ∫ρ′(r)[V(r) − V′(r)]dr

从 Ψ′ 出发重复这个论证：EGS′ < EGS − ∫ρ(r)[V(r) − V′(r)]dr

把两式相加，并假设 ρ = ρ′ ⟹ EGS + EGS′ < EGS′ + EGS　矛盾。

证明逐步拆解（每一步的依据都写出来）

符号名称含义
V, V′两个不同的外势假设它们不只差一个常数（差常数的外势给出同一个 Ψ，是平凡情形）
Ψ, Ψ′对应的基态波函数假设不相同
EGS, EGS′对应的基态能量GS = Ground State
T动能 + 电子排斥讲义把 T̂ + V̂ee 合写成 T——两个体系完全相同（p7：它们是普适的）
<（严格小于）严格变分不等式因为 Ψ′ 不是 H 的基态，用它算出的能量严格高于 H 的真实基态能量（假设基态不简并）
第 1 步：写出两个哈密顿量的关系

两个体系电子数相同，所以 T（动能 + 电子排斥）完全一样，只有外势不同：

H = T + V　，　H′ = T + V′　⟹　H = H′ + (V − V′)
第 2 步：用变分原理（第 3 讲 p26）

把 Ψ′ 当成 H 的"试探函数"——它不是 H 的基态，所以：

EGS = ⟨Ψ|H|Ψ⟩ < ⟨Ψ′|H|Ψ′⟩ = ⟨Ψ′|H′|Ψ′⟩ + ⟨Ψ′|V − V′|Ψ′⟩

第一项就是 EGS′（Ψ′ 是 H′ 的基态）。

第 3 步：势能的期望值只依赖密度（这一步是整个证明的精髓）

V 是一个"乘法型"的单电子算符：V = Σiv(ri)。它的期望值：

⟨Ψ′| Σi v(ri) |Ψ′⟩ = ∫ ρ′(r) v(r) dr

对任何单电子乘法算符，期望值都只需要密度就能算——不需要完整的波函数。（这和 p9 的密度定义是同一件事：积掉其余电子后只剩 ρ。）于是：

① EGS < EGS′ + ∫ ρ′(r) [V(r) − V′(r)] dr
第 4 步：把角色对调，再做一次

这次把 Ψ 当成 H′ 的试探函数，完全对称地得到：

② EGS′ < EGS + ∫ ρ(r) [V′(r) − V(r)] dr = EGS − ∫ ρ(r) [V − V′] dr
第 5 步：相加，引出矛盾

假设 ρ = ρ′（我们要推翻的假设），那么 ① 和 ② 里的两个积分大小相等、符号相反，相加后抵消：

EGS + EGS′ < EGS′ + EGS　⟹　0 < 0　✘ 荒谬

一个数严格小于它自己，这不可能。所以假设错了——两个不同的外势不可能给出同一个基态密度。∎

证明的逻辑结构（考试写证明时的骨架）
  1. 反设：V ≠ V′（Ψ ≠ Ψ′）但 ρ = ρ′
  2. 变分原理 + "势能期望值只依赖密度" → 不等式 ①
  3. 对称地 → 不等式 ②
  4. 相加 → E + E′ < E + E′，矛盾
  5. 结论：ρ 唯一确定 Vext（至多差一个常数），从而确定 H、Ψ 和一切性质

用到的两个前提：① 变分原理；② 基态非简并（否则"<"要变成"≤"，证明需要修补——Levy 在 1979 年给出了推广）。

拓展 · 这个证明短得惊人，但它是一个"存在性"证明

它证明了"ρ 决定一切"，但完全没有告诉你怎么从 ρ 算出能量——那个"从密度到能量的规则"（泛函）存在，但它长什么样没人知道。

这就是 DFT 的根本处境：理论上是精确的，实践上必须近似。Kohn 因此在 1998 年获诺贝尔奖，而找到那个精确泛函至今仍是未解决的问题（p24 "One unique expression must exist, but it is unknown"）。

p18什么是泛函？

原文翻译

函数把数映射成（复）数：f: ℝ → ℂ: x ↦ f(x)

泛函把函数映射成（复）数：F: ℌ → ℂ: f ↦ F[f]

例：F[f] = ∫−∞+∞ f(x)e−x²dx

泛函导数：导数对泛函的推广。

F1[ρ] = ∫ρ(r)ν(r)dr　⟹　δF1[ρ]/δρ = ν(r)

公式解析 · 函数 vs 泛函

函数 f(x)泛函 F[f]
输入一个数 x一整个函数 f(·)
输出一个数一个数
记号圆括号 (x)方括号 [f]
例子f(x) = x²：给 3 得 9F[f] = ∫₀¹f(x)dx：给 f=x² 得 1/3，给 f=sin 得 1−cos1
日常类比"温度 → 穿几件衣服""一整天的温度曲线 → 这一天的平均体感"
符号名称含义
ℝ, ℂ实数集、复数集函数的定义域和值域
ℌ希尔伯特空间"所有合法波函数（或密度）组成的集合"——泛函的定义域是一个函数的集合
ν(r)某个给定的函数例子里扮演外势的角色（希腊字母 nu，别和速度 v 混）
δF/δρ泛函导数见下
泛函导数：把 ρ 在某一点"戳一下"，看 F 变多少

普通导数问："x 变一点点，f 变多少？"

泛函导数问："函数 ρ 在点 r 附近变一点点，F 变多少？"——答案随 r 变化，所以泛函导数本身是一个关于 r 的函数。

δF = ∫ (δF/δρ)(r) · δρ(r) dr

讲义的例子：F₁[ρ] = ∫ρνdr。给 ρ 一个小改变 δρ：

δF₁ = ∫(ρ+δρ)νdr − ∫ρνdr = ∫ν(r)·δρ(r)dr　⟹　δF₁/δρ = ν(r)　✔

这个例子不是随便举的：外势能量 ∫ρVextdr 对密度的泛函导数就是外势本身。p22 的 Vxc = δExc/δρ 就是用同样的方式从能量泛函得到势。

DFT 做的是同一件事，只是把自变量从 3N 维的 ψ 换成了 3 维的 ρ。

原文翻译

"一个 N 电子体系的精确基态密度是

ρ(r) = Σi=1N φi*(r)φi(r)

其中单粒子波函数 φi 是 Kohn–Sham 方程能量最低的 N 个解：

ĤKSφi = εiφi

讲解 · Kohn–Sham 的天才想法

问题：HK 泛函 FHK[ρ] = T[ρ] + Vee[ρ] 完全未知

最大的困难在动能——动能占总能量的一半左右（位力定理，第 3 讲 p5），而且用密度直接表示动能极其困难（早期的 Thomas–Fermi 模型尝试过，连化学键都给不出）。

Kohn–Sham 的解法（1965）：引入一个"替身体系"

因为替身体系的电子没有相互作用，它的波函数精确地就是一个 Slater 行列式，动能 T0 可以用轨道精确地算出来（−½∇²）。这一步把动能的绝大部分（约 99%）精确地处理掉了。

于是总能量被重新拆分：

E[ρ] = T0[ρ] + J[ρ] + ∫ρVext + Exc[ρ]
项能否精确计算约占总能量
T0（无相互作用动能）✔ 用轨道算大
J（经典库仑排斥）✔ 用密度算大
∫ρVext（核吸引）✔ 用密度算最大（负）
Exc（交换-相关）✘ 必须近似约 10%（交换为主）

KS 的成功之处：把"未知的部分"从整个 FHK（约 50% 的能量）压缩到只剩 Exc（约 10%），而且这 10% 相对容易近似。

"精确变换"这四个字的意思

讲义最后一句：KS 方程是原问题的精确变换。

如果 Vxc 是精确的，KS-DFT 就给出精确的基态能量和密度——没有任何近似。所有误差都来自 Vxc 的近似。

对比 HF：即使完备基组，HF 也有固有误差（丢了相关能）。DFT 原则上可以精确，HF 原则上不能。这是两者理论地位的根本区别。

拓展 · KS 方程也要做 SCF

看 KS 哈密顿量：VH 和 Vxc 都依赖于 ρ，而 ρ 又由轨道 φi 算出——和 HF 一模一样的"鸡生蛋"困境（第 2 讲 p85）。所以解法也一样：

猜 ρ → 建 ĤKS → 对角化得 φi → 算新 ρ → 重复直到自洽。

第 3 讲讲的一切 SCF 技术（DIIS、level shift、基组、RI 近似）在 DFT 里原封不动地适用。这就是为什么 Gaussian 里 #p hf 和 #p b3lyp 只差一个关键词。

DFT 多出来的一件事：Vxc 一般没有解析积分，要在数值格点上积分——这就是第 3 讲 p4 的 integral=(grid=ultrafine)，也是本讲 p3 提纲里"数值积分"指的东西。

考点
  • 写出 KS 方程，逐项说明含义；指出唯一未知的是 Vxc
  • KS 的核心思想：用无相互作用替身体系重现真实密度
  • 为什么说 KS 方程是"精确变换"；误差从哪里来

p23Hartree–Fock 与 DFT 的哈密顿量并排对比

原文翻译

  • 受原子核的库仑势作用
  • 与其他电子有库仑相互作用

  • 有动能的准粒子
  • 受原子核的库仑势作用
  • 与所有其他准粒子的平均、静态分布相互作用
  • 受一个神秘的"交换-相关"势的影响

原文翻译

拓展 · "均匀电子气"为什么是一个合理的起点

均匀电子气 (uniform electron gas, jellium) 是唯一一个 XC 能被精确算出的多电子体系：一堆电子在均匀的正电荷背景里。它的交换能有解析式（p29 那个 ρ4/3），相关能由 Ceperley–Alder 的量子蒙特卡罗计算（1980）精确给出并拟合成公式（VWN、PW92）。

LDA 的假设就是：分子里每一个小体积元，都当成"密度为该点 ρ 的均匀电子气"来处理。对金属（电子本来就很均匀）效果好；对分子（密度在核附近剧烈变化）就不太好——所以要加梯度修正。

考点

  • "局域"的含义：εxc 只依赖点 r 附近的信息

p27DFT 小结

原文翻译

DFT 的基本引理：在某个外势中、有相互作用电子组成的束缚体系，其基态密度唯一地决定这个外势。

基态密度 → 外势 → 哈密顿算符（动能项我们知道） → 体系的所有性质（通过标准量子力学）

因此应该可以只用电子密度（只有三维！）来重新表述量子化学——一个重大的简化。

Hohenberg–Kohn 变分原理：存在一个定义明确（虽然没有显式已知）的电子密度泛函，它在基态密度处取得全局最小值。

minρ E[ρ] = ⟨Ψ₀|T̂ + V̂ + Û|Ψ₀⟩　（Ψ₀ = 基态波函数；T̂ 动能项；V̂ 核吸引；Û 电子排斥）

E[ρ] = T[ρ] + U[ρ] + ∫V(r)ρ(r)d³r　（能量泛函 = 动能泛函 + 电子间排斥能泛函 + 核吸引能泛函（已知））

讲解 · 这一页把 p7–p20 压缩成了两句话

讲义说法对应哪个定理本讲在哪
"基态密度唯一决定外势"HK 第一定理p11–p17
"泛函在基态密度处取全局最小"HK 第二定理p19–p20
符号名称含义
T[ρ]动能泛函未知 → KS 用 T0 近似掉大部分
U[ρ]电子排斥泛函讲义 p20 叫 Vee，这里叫 U——同一个东西
V(r)外势= Vext，已知
d³r体积元= dxdydz
考点
  • "DFT 的基本引理"原文及其推理链（密度 → 外势 → 哈密顿量 → 一切性质）

公式解析 · LDA 交换（唯一需要记住形式的一个）

★ LDA 交换能（Dirac / Slater 交换） EXLDA[ρ] = −(3/4)·(3/π)1/3 ∫ ρ(r)4/3 dr
符号名称含义
ρ4/3密度的 4/3 次方这个指数可以由量纲分析直接得到（见下）
−(3/4)(3/π)1/3常数≈ −0.7386。由均匀电子气精确推出
负号—交换能永远是负的（稳定化，Fermi 空穴）
为什么是 4/3 次方（一个漂亮的量纲论证）

均匀电子气里，电子的平均间距 rs ∝ ρ−1/3（密度越大，间距越小）。交换能是库仑型的，每个电子的交换能 ∝ 1/rs ∝ ρ1/3。

总交换能 = ∫（电子数密度）×（每个电子的交换能）= ∫ρ · ρ1/3 = ∫ρ4/3　✔

所以 εxLDA ∝ −ρ1/3。

公式解析 · B88 交换（看结构，不用背）

εxB88 = εxLDA + ΔεxB88　，　ΔεxB88 = −βρ1/3 · x² / (1 + 6βx·sinh⁻¹x)　，　x = |∇ρ| / ρ4/3
符号名称含义
x约化密度梯度无量纲的"不均匀程度"。均匀电子气 x=0，修正项消失，退回 LDA
β经验参数= 0.0042，拟合惰性气体原子的交换能得到——这就是 GGA 的"经验性"
sinh⁻¹反双曲正弦保证在远离分子处（ρ→0，x→∞）有正确的渐近行为

LYP 相关（右框）：由 Colle–Salvetti 的氦原子相关能公式改写而来，参数 a, b, c, d 拟合氦原子数据。LYP 的特点是它是从一个"单电子对"模型推来的，所以对单个电子正确地给出零相关能——没有相关部分的自相互作用。公式很长，考试不会要求背。

"B3LYP 是魔法泛函"：它的 3 个参数是 1993 年针对一个小数据集拟合的，却在此后 30 年里对大量从未见过的体系表现意外地好——没有人能从理论上完全解释为什么。这正是"缺乏系统改进性"的写照：你不知道它为什么对，所以也不知道它什么时候会错。

"空穴函数 (hole function)"：交换-相关空穴描述"在某处有一个电子时，它周围其他电子被排开形成的空洞"（第 2 讲 p70 的 Fermi 空穴 + 库仑空穴）。Exc 本质上就是电子与自己的 XC 空穴之间的相互作用能。更好地建模这个空穴，是构造新泛函的主要理论途径。

考点

色散力来自两个分子电子云的瞬时涨落相互关联：A 的电子云某一瞬间偏向一边形成瞬时偶极，诱导 B 产生反向偶极，两者吸引。能量 ∝ −C6/R⁶。

p33★ 自相互作用误差 (Self-Interaction Error)

原文翻译

自相互作用问题

在 HF 中：Hartree 能 = Σi,j∫ρi(r)ρj(r′)/|r−r′| drdr′；交换能 = −Σi,j∫ψi*(r)ψi(r′)ψj*(r)ψj(r′)/|r−r′| drdr′

非物理的自相互作用被抵消：Σi∫ρi(r)ρi(r′)/|r−r′| drdr′

在 DFT (Kohn–Sham) 中：Hartree 能 = Σi,j∫ρiρj/|r−r′|，被（未知的）精确 XC 泛函中的某一项精确抵消。

实际使用的 DFT 版本存在一个虚假的、非物理的自相互作用贡献，因此需要"自相互作用校正方法"(SIC)。当电子排列紧密、因而相关很强时尤其重要。

公式解析 · 自相互作用从哪里来

Hartree（经典库仑）能 —— 求和包含 i = j 的项 EH = ½ Σi,j ∫∫ ρi(r) ρj(r′) / |r − r′| drdr′　⊃　½ Σi ∫∫ ρi(r)ρi(r′)/|r−r′|
符号名称含义
ρi(r)第 i 个轨道的密度= |ψi(r)|²
Σi,j对所有轨道对求和包括 i = j！即"轨道 i 的电荷云和它自己的电荷云相互排斥"
i = j 项自相互作用一个电子和自己排斥——物理上不存在
½—讲义省略了这个 ½，不影响论证

讲解 · HF 自动消掉了它，近似 DFT 消不干净

在 HF 里：Jii = Kii，完美抵消

回忆第 3 讲 p43：同一个轨道的库仑积分和交换积分定义完全一样，Jii = Kii。HF 能量里是 Σ(Jij − Kij)，所以 i=j 的项：

Jii − Kii = 0　✔ 自相互作用被精确扣除
在近似 DFT 里：EH 是精确的，但 Exc 是近似的

KS 的 Hartree 能 EH 包含自相互作用 Jii。理论上精确的 Exc 里有一项恰好等于 −Jii 把它抵消。

但 LDA/GGA 是局域近似，它给出的"自交换"不等于 −Jii，抵消不干净，剩下一个正的残差——电子多排斥了自己一点。

最干净的检验：氢原子（只有 1 个电子，不应有任何电子-电子相互作用）：

方法H 原子能量 (Hartree)说明

SIE 解释了 DFT 的一连串典型错误（考试好题）
现象SIE 怎么导致它
反应能垒偏低（p25 表 V）过渡态的电子更离域 → SIE 让离域态被人为稳定 → 过渡态能量偏低

为什么杂化泛函好一点：掺了 20% HF 交换 → 抵消了 20% 的自相互作用。范围分离泛函在长程用 100% HF 交换，效果更好。

考点
  • 解释什么是自相互作用误差；为什么 HF 没有而近似 DFT 有（Jii = Kii）
  • SIE 导致的后果：过度离域、能垒偏低、带隙偏小

p34范围分离（长程校正）泛函

原文翻译

范围分离（长程校正）泛函旨在解决 DFT 的一些系统性误差：

  • 自相互作用误差（对某个电子，交换抵消项不能精确抵消库仑项，导致误差。在 HF 理论中，交换与库仑精确匹配。）
  • （TD-DFT 算的）电荷转移态的激发能太低
  • 电子过度离域问题

做法是把库仑算符拆成两部分：短程和长程：

1/|r₁−r₂| = 1/r₁₂ = [1 − erf(ωr₁₂)]/r₁₂ + erf(ωr₁₂)/r₁₂，　erf(x) = (2/√π)∫₀xe−t²dt

对短程用 DFT 交换-相关，对长程用精确的 HF 交换。

例子：LC-BLYP、CAM-B3LYP 等。

公式解析 · 库仑算符的范围分离

★ 把 1/r₁₂ 拆成两段 1/r12 = [1 − erf(ωr12)] / r12 + erf(ωr12) / r12
　　短程 SR：用 DFT 交换　　　　　　长程 LR：用 HF 交换
符号名称含义
erf(x)误差函数error function：一条 S 形曲线，x=0 时为 0，x→∞ 时趋于 1。它充当一个"平滑开关"
ω范围分离参数单位 Bohr⁻¹。1/ω 大致是"短程与长程的分界距离"。LC-ωPBE 约 0.4，CAM-B3LYP 0.33
r12电子间距—
t积分哑变量只出现在 erf 的定义里

讲解 · 为什么"短程 DFT + 长程 HF"是对的组合

距离谁更合适理由
短程DFT 交换DFT 交换与 DFT 相关在短程误差互相抵消（p25 讲过），效果好
长程HF 交换精确的交换势在远处应该按 −1/r 衰减（一个电子离开分子时，感受到剩下的 N−1 个电子 + Z 个质子，净电荷 +1）。GGA 的交换势是指数衰减的，太快了；HF 交换恰好给出正确的 −1/r
拓展 · 什么时候必须用范围分离泛函
场景原因
TD-DFT 算电荷转移激发B3LYP 可能把电荷转移激发能低估 1–2 eV，甚至预测出不存在的低能"幽灵态"。CAM-B3LYP、ωB97X-D 基本解决这个问题
给体-受体体系（有机光伏、染料）同上
阴离子、Rydberg 激发需要正确的长程势（本讲 p38 建议 4 也提到阴离子要用 range-corrected 泛函）
极化率、超极化率GGA 严重高估长链分子的极化率

Gaussian 关键词：CAM-B3LYP、wB97XD、LC-wPBE。

考点
  • 范围分离泛函的构造：用 erf 把 1/r12 分成短程 + 长程；短程 DFT、长程 HF
  • 它解决的三个问题：SIE、电荷转移激发能过低、过度离域

p35色散校正泛函

原文翻译

色散校正泛函旨在计入各种色散力，如范德华力。标准 DFT 或 HF 方法不包含这些弱相互作用，但它们对大体系越来越重要（它是累积的）。

Grimme 提出以经验项的形式加入色散校正，类似于力场方法中的范德华项。

Grimme：ΔEdisp = −Σn=6(8,10) sn ΣABatoms (CnAB/RABn)·fdamp(RAB)

Becke–Johnson (BJ)：C6AB = αAαB⟨μ²⟩A⟨μ²⟩B / (αA⟨μ²⟩B + αB⟨μ²⟩A)

实现依赖于为任意一对原子制表（或计算）参数 CnAB，以及与泛函有关的参数 sn。

通过选择合适的模型把色散加入计算。Grimme 方法记作 D / D2 / D3 / D4（如 ωB97D）。

另一种做法是让 ΔEdisp 依赖真实密度并数值计算（van Voorhis–Vydrov）。这更慢，但表现与 D3 相近。

公式解析 · Grimme 色散校正

★ DFT-D 色散能 ΔEdisp = − Σn=6,8 sn ΣA<B ( CnAB / RABn ) · fdamp(RAB)
符号名称含义
ΔEdisp色散校正能直接加到 DFT 总能量上，不改变电子密度
RAB原子 A、B 的距离只需要几何坐标——所以几乎不花计算时间
C6AB色散系数London 色散的强度，−C6/R⁶ 是色散力的经典形式。D3 中它还依赖原子的配位数（sp³ 碳和 sp² 碳不同）
n = 6, 8, (10)展开阶数R⁻⁶ 是偶极-偶极，R⁻⁸ 是偶极-四极……D2 只有 n=6，D3 有 6 和 8
sn标度因子依赖于所用泛函——B3LYP-D3 和 PBE-D3 的 s8 不同，因为每个泛函自己"已经包含"的中程相关不同
fdamp阻尼函数短距离时趋于 0，长距离时趋于 1。见下
αA原子极化率BJ 公式中：原子的电子云有多"软"
⟨μ²⟩A偶极矩平方期望BJ 公式中：交换空穴偶极矩（衡量瞬时偶极的大小）
为什么必须有阻尼函数 fdamp

① R→0 时 1/R⁶ → ∞，会让原子"塌缩"到一起；② 短程的相关 DFT 泛函已经算过了，再加一遍会重复计算。

阻尼函数在短程把校正"关掉"，只在中长程起作用。"D3(BJ)" 中的 BJ 就是指 Becke–Johnson 形式的阻尼（在 R→0 时趋于一个有限常数而不是 0），比原来的"零阻尼"表现更好。

拓展 · 色散"是累积的"——为什么大体系一定要加

单个原子对的色散只有零点几 kcal/mol，但它对所有原子对求和，数目 ∝ N²。

体系色散对结合能的贡献
苯二聚体（π–π 堆积）约 −3 kcal/mol，几乎是全部结合能（不加 D3 算出来是排斥的）
蛋白-配体结合可达 −20 ~ −50 kcal/mol
石墨层间约 −50 meV/原子，全部来自色散

实用规则（p38 建议 5）：现代计算里，除非有特殊理由，默认总是加 D3(BJ)。它几乎不增加时间。Gaussian：empiricaldispersion=gd3bj；ORCA：! D3BJ。第 3 讲 p5 的 Gaussian 输出里那行 "Adding Grimme-D3(BJ) dispersion" 就是它。

考点
  • 为什么标准 DFT 缺色散；Grimme D3 的形式（−C6/R⁶ × 阻尼）
  • 阻尼函数的作用；为什么色散对大体系更重要

p38使用 DFT 的七条建议

原文翻译
  1. 思考被研究体系的波函数，评估 DFT 是否适用（即你是否预期能级近简并？）。大多数闭壳层有机分子适合 DFT。所有开壳层单自由基也适合（非限制 DFT）。双自由基和多自由基——不太适合。过渡金属化合物——不太适合，除非它们明显是闭壳层。
  2. 镧系元素只适合用 4f-in-core 赝势。
  3. 尽可能多地获取实验数据，以便把计算与实验比较。测量是在溶剂中还是气相中完成的？
  4. 选择基组。从小基组开始，然后把结果投影到更大的基组上（很多程序自动做这件事）。阴离子需要额外的弥散函数和范围校正泛函。通常 VTZP 基组给出合理结果，更大的基组不带来额外精度。
  5. 对小体系可以忽略色散。对大体系，色散很重要。

原文翻译（p39）

（图：两个自旋 S₁、S₂ 平行 = 铁磁相互作用；反平行 = 反铁磁相互作用。S₁ = S₂ = ½。）

真实波函数：

三重态 S=1：ΨS=1,M=+1 = α(1)α(2)；ΨS=1,M=0 = (1/√2)[α(1)β(2) + β(1)α(2)]；ΨS=1,M=−1 = β(1)β(2)　——磁性的

单重态 S=0：ΨS=0,M=0 = (1/√2)[α(1)β(2) − β(1)α(2)]　——非磁性的

原文翻译（p40）

磁相互作用由 Heisenberg–Dirac–Van Vleck 哈密顿量唯象地描述：Ĥexch = −2J Ŝ₁·Ŝ₂

其中 J 是描述磁相互作用强度的参数。

它可以用总自旋改写：ST：S₁+S₂, S₁+S₂−1, …, |S₁−S₂|

ST² = (S₁+S₂)² = S₁² + S₂² + 2Ŝ₁·Ŝ₂；　2Ŝ₁·Ŝ₂ = ST² − S₁² − S₂²

Ĥexch = −J[ST² − S₁² − S₂²]

现在这个哈密顿量可以在 S=1 和 S=0 的本征态基下展开。铁磁相互作用 J > 0；反铁磁相互作用 J < 0。

原文翻译（p41）

三重态：E(ST=1) = −J[ST(ST+1) − S₁(S₁+1) − S₂(S₂+1)] = −J[2 − ½×3/2 − ½×3/2] = −½J

单重态：E(ST=0) = −J[0 − ½×3/2 − ½×3/2] = +(3/2)J

验证：−½J×(2×1+1) + (3/2)J×(2×0+1) = −(3/2)J + (3/2)J = 0

现在把 S=0 设为基态（即取为 0），三重态的能量为：E(ST=0) = 0；E(ST=1) = ΔEST = −½J − (+3/2J) = −2J

若 J > 0 ⟹ E(ST=1) < E(ST=0) ⟹ 铁磁耦合。

单重态与三重态之间的能隙直接与磁相互作用参数相联系。

如果 E(ST=1) 和 E(ST=0) 能由计算方法估算，就可以直接得到 J。对 CI 或多参考方法这里没有问题，只是相关计算很繁琐。

加外磁场后，能量变化 ∝ M·B（Zeeman 效应）。三重态有 M = +1, 0, −1，所以分裂成三条线，对磁场有响应；单重态只有 M = 0，对磁场没响应。

p42–43★ 用 DFT 算 J：破缺对称 (BS-DFT) 方法

原文翻译（p42）

能用 DFT 计算磁相互作用参数吗？

三重态 S=1：ΨS=1,M=+1 = α(1)α(2)　⟹ 一个 Slater 行列式，适合 DFT

单重态 S=0：ΨS=0,M=0 = (1/√2)[α(1)β(2) − β(1)α(2)]　⟹ 两个 Slater 行列式，不适合 DFT

因此，直接用 DFT 可能不适合计算单重态。

为克服这个问题，提出了破缺对称 (BS) 方法。在 BS-DFT 中，不计算单重态波函数，而是计算一个行列式 α(1)β(2) 的能量。参数 J 由两个组态的能量差导出：

EHS − EBS = [⟨1|h|1⟩ + ⟨2|h|2⟩ + ⟨12|12⟩ − ⟨12|21⟩]HS − [⟨1|h|1⟩ + ⟨2|h|2⟩ + ⟨12|12⟩]BS

= −⟨12|21⟩ = −⟨α(1)β(2)|1/r₁₂|α(2)β(1)⟩ = −2J

J = (EHS − EBS)/2 = ⟨12|21⟩/2 = ⟨α(1)β(2)|1/r₁₂|α(2)β(1)⟩/2

原文翻译（p43）

对更一般的情形 S1,2 ≥ ½，上面的公式不太正确，因为磁耦合依赖于相互作用自旋的数值，因此必须考虑总自旋的较大值。

Yamaguchi 等人 [Chem. Phys. Lett. 432 (2006) 343–347] 提出了如下表达式：

J = (EBS − EHS) / (⟨S²⟩BS − ⟨S²⟩HS) = (EHS − EBS) / (⟨S²⟩HS − ⟨S²⟩BS)

其中 ⟨S²⟩BS 和 ⟨S²⟩HS 是 S² 算符在各自波函数上的期望值，EBS 和 EHS 是破缺对称和高自旋组态的总能量。

Noodleman 等人给出了 J 的另一种公式。

ORCA 软件提供了一个易用的 BS-DFT 磁耦合实现，实现了多种公式。使用 ORCA 做这件事的研究：Phys. Chem. Chem. Phys., 2014, 16, 14568。

GAUSSIAN 也可以计算磁耦合，教程见 gaussian.com/afc/。

拓展 · 一个更深的问题：这个简单模型只能给出铁磁

p42 的推导得到 J = K₁₂/2，而交换积分 K₁₂ 永远为正 → J 永远 > 0 → 永远是铁磁。可实际上大多数双核 Cu(II) 配合物是反铁磁的，这是为什么？

因为推导里假设了"两个行列式用同样的轨道"（冻结轨道）。真实的反铁磁性来自超交换 (superexchange)：两个磁性轨道通过桥联配体（Cl⁻）的轨道发生重叠，电子可以"跳过去"，而只有自旋相反时才允许跳（泡利），跳跃带来的动能降低让单重态更稳定。这一项 ∝ −t²/U（t = 跳跃积分，U = 同位排斥），叫动力学交换。

真实的 BS-DFT 计算为什么能抓到它：在 UKS 计算里，BS 态的 α 和 β 轨道是各自优化的，会向对方中心发生离域——这种轨道弛豫就包含了超交换效应。

结构-磁性关系（p48 附加任务的背景）：Goodenough–Kanamori 规则——M–X–M 桥联角接近 90° 时，两条超交换路径的轨道正交，倾向铁磁；角度增大时重叠增大，倾向反铁磁。对双 μ-Cl 桥联 Cu₂ 体系，交叉点大致在 Cu–Cl–Cu ≈ 90–95°附近。所以作业里"算 J 随 Cu–Cl–Cu 角的变化"应该能看到符号翻转。

p44–45传播子方法与 TD-DFT：算激发态

原文翻译（p44）

如果分子受到一个线性振荡电场 E = r cosωt 的作用，频率依赖的极化率可以很好地近似为：

⟨α⟩ω = Σi=0Nstates |⟨ψ0|r|ψi⟩|² / [ω − (Ei − E0)]

传播子方法（基于 Green 函数或运动方程 EOM）旨在不显式计算 ψi 就求出频率依赖极化率。

随机相位近似 (RPA) 方法计入单、双电子激发对 CI 矩阵元的影响，而不显式构造 CI 波函数。RPA 可以作用于 HF 波函数或 CASSCF。RPA 计入的动态电子相关质量中等。

含时 DFT (TD-DFT) 是 RPA 对 DFT 波函数的等价物，它通过把"电子从某个占据轨道激发到虚轨道"看作对原体系的外部微扰，来优化激发态。

当然，用 TD-DFT 计算激发态时并没有真正的"时间依赖"。这个名字来源于 TD-DFT 方程最初是从求解含时薛定谔方程出发的，之后做了所谓的绝热近似，这等价于"丢失时间记忆"，即不再依赖时间。

原文翻译（p45）

TD-DFT 在以下条件下表现良好：

  1. 基态波函数能被单个 Slater 行列式很好地描述
  2. 自旋污染低
  3. 只需要低能的电子激发态
  4. 使用了合适的基组和密度积分格点
  5. 使用了合适的色散校正方法

并非所有软件包都为 TD-DFT 提供溶剂效应、相对论校正、色散校正的所有组合。也会有一些 bug；因此建议对结果进行批判性分析并配合适当的测试。

能量与分子电离能相当的高激发态描述得很差。

公式解析 · 频率依赖极化率（求和-态公式）

★ 极化率的"态求和"表达式 α(ω) = Σi |⟨ψ0|r|ψi⟩|² ⁄ [ω − (Ei − E0)]
符号名称含义
α(ω)动态极化率分子在频率为 ω 的光照下"被极化"的难易程度
ω外场（光）的频率原子单位下即光子能量
⟨ψ0|r|ψi⟩跃迁偶极矩基态到激发态 i 的跃迁偶极矩（第 2 讲 p16 拓展）。它的平方决定吸收强度（振子强度）
Ei − E0激发能第 i 个激发态的能量 = UV-Vis 吸收峰的位置
Σi对所有激发态求和讲义上限写 Nstates
这个公式的关键：分母为零处就是激发能

当光的频率 ω 恰好等于某个激发能 Ei − E0 时，分母 → 0，α(ω) → ∞——这叫极点 (pole)，物理上就是共振吸收。

所以：只要能算出"分子对振荡电场的响应函数 α(ω)"，找到它的极点位置就得到了所有激发能，找到极点处的留数就得到了跃迁强度——完全不需要显式算出激发态波函数 ψi。这就是"传播子方法 / 线性响应理论"的核心思想，TD-DFT 就是其中一员。

讲解 · 三个名词

名词一句话
RPA（随机相位近似）在 HF（或 CASSCF）基础上做线性响应，求激发能。也叫 TD-HF。包含"激发"和"去激发"两种过程
TD-DFT"RPA 的 DFT 版"：用 KS 轨道和 XC 核做同样的线性响应。实际计算中最常用的激发态方法
绝热近似真正的含时 XC 势应该依赖密度的整个历史（记忆效应）；绝热近似假设它只依赖当前时刻的密度，于是可以直接用基态的 XC 泛函。这是 TD-DFT 算不好双激发态的根源
拓展 · TD-DFT 在实践中的三个常见陷阱（对应 p45 的条件）
问题原因与对策

考点

讲解 · p48 任务的做法思路

体系分析

[Cu₂Cl₆]²⁻：两个 Cu(II)，每个 d⁹，各有 1 个未成对电子（S₁ = S₂ = ½）。两个 Cu 由两个桥联 Cl 相连（Cu₂Cl₂ 菱形核心），外侧各有两个端基 Cl。总电荷 −2（2×Cu²⁺ + 6×Cl⁻ = +4 − 6）。

第一步：高自旋态（S=1）
! UKS B3LYP def2-TZVP def2/J TightSCF LargePrint
* xyz -2 3        <- 电荷 -2, 多重度 3 (两个自旋平行)
...

要检查的：

  • Mulliken 自旋布居（p5 的 Pα − Pβ）：两个 Cu 上应该各有约 +0.5–0.6，其余分布在 Cl 上（自旋离域到配体——这正是超交换的通道）
  • ⟨S²⟩：理论值 2.00，实际应在 2.00–2.01（高自旋态几乎无污染）
第二步：破缺对称态

ORCA 最简单的写法：

! UKS B3LYP def2-TZVP def2/J TightSCF LargePrint
%scf
  BrokenSym 1,1     <- 一个中心 1 个未成对电子向上, 另一个 1 个向下
end
* xyz -2 3          <- 先按高自旋收敛, 程序再自动翻转
...

或者用讲义说的 "SpinFlip" 显式指定翻转哪个原子：%scf FlipSpin 1 FinalMs 0.0 end（FlipSpin 后面是要翻转的原子编号，ORCA 从 0 开始数）。

要检查的：

  • 自旋布居：一个 Cu 约 +0.5，另一个约 −0.5——如果两个都接近 0，说明塌回了闭壳层解，翻转失败
  • ⟨S²⟩BS：应在 1.0 附近（弱重叠）或更小（强重叠）——p43 Yamaguchi 公式要用
第三步：算 J

用 Yamaguchi（按上面订正后的符号）：J = (EBS − EHS)/(⟨S²⟩HS − ⟨S²⟩BS)。能量从 Hartree 换成 cm⁻¹：1 Hartree = 219 474.6 cm⁻¹。

典型 J 只有几到几百 cm⁻¹，即 10⁻⁵–10⁻³ Hartree——比总能量小 7–8 个数量级。所以两次计算必须用完全相同的几何、基组、格点、收敛阈值，否则数值噪声就会盖过 J。这也是 TightSCF 在这里必不可少的原因。

泛函对 J 的影响很大

BS-DFT 算出的 J 强烈依赖泛函中 HF 交换的比例：纯 GGA（SIE 大、过度离域）严重高估反铁磁耦合；HF 交换越多，|J| 越小。B3LYP 和 TPSSh 是常用的折中。报告 J 时必须注明泛函。

考点
  • ORCA 输入各关键词的含义（UKS、def2/J、%maxcore 是每核内存）
  • BS-DFT 计算的流程：HS 计算 → 翻转一个中心的自旋 → BS 计算 → 用能量差和 ⟨S²⟩ 算 J
