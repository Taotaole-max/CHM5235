§1.2 计算化学是什么 · 名人与里程碑what is computational chemistry

原句Computational Chemistry is a (relatively new) research area which aims at finding answers to chemical problems by using computers & fundamental laws of interaction between particles.计算化学：用计算机 + 粒子间相互作用的基本定律来回答化学问题。[L1 p7]{{ix:Computational chemistry|计算化学}}

一个化学反应 A + B →(催化剂) 产物 + C + D… 的未知数 [L1 p7]：最合适的试剂、催化剂；反应条件（温度、压力、溶剂）；从反应混合物中分离新化合物；新化合物的物理性质（分子和晶体结构、势能面、熔点、EPR、UV-Vis、IR、NMR、Raman 谱）；反应机理（新认识）；反应动力学（为工业放大服务）。

判断陷阱
  • "Hartree 在 1930 年提出了 HF 理论。" Hartree 1927 年提出 SCF；Fock 1930 年加上反对称（交换）才成为 Hartree–Fock。
  • "Kohn 因为发明 Gaussian 程序获奖。" Gaussian 是 Pople；Kohn 是 DFT。两人同为 1998 年。
  • "2013 年 Nobel 奖授予 DFT。" 2013 年是多尺度模型（QM/MM 的思想），Karplus、Levitt、Warshel。
  • Roothaan 的年份：L1 p11 写 1950，L2 p86 写 1955。讲义前后不一致，题目引用哪页就按哪页。

§1.3 未来方向promising paths

  1. AI / 机器学习 + 计算化学：以比普通 DFT 快一万倍以上的速度得到 DFT 质量的结果 → 更充分地扫描相空间；快速预测新材料、新现象、反应性和性质；加速新分子和新材料的发现。
  2. 准确描述弱相互作用：van der Waals、色散、长程相关（对应 {{p:s5.9}} 的 DFT-D）。
  3. 准确预测分子晶体的晶体结构和声子谱。
  4. 非平衡量子动力学：同时对电子和核解 Schrödinger 方程，即 non-Born–Oppenheimer（对应 {{p:s2.16}}）。{{ix:Non-Born–Oppenheimer|非 BO 动力学}}
  5. 面向量子处理器的计算方法及各种混合方法。
补充方法层级（便宜 → 昂贵）：力场 / 分子力学（经典势能函数，没有电子；AMBER、OPLS、UFF、MM2）→ 半经验（AM1、MNDO、PM6：略去大部分双电子积分并用参数弥补，{{p:s3.14}}）→ DFT → HF 及后 HF（MP2、CC、CI）。越往后越"第一性原理"，也越贵。

§1.4 计算机与集群的结构anatomy of a computer / cluster

一台计算机 [L1 p14]：主板集成 CPU（多个计算核心 + 很快的本地缓存）、RAM（快）、硬盘（慢）、显卡（自带 GPU 和显存）、外设。

计算机集群（如 NSCC）{{ix:Cluster|计算机集群}}共享内存超算（如 IBM Blue Gene/Q）{{ix:Shared-memory supercomputer|共享内存超级计算机}}
结构独立节点 + 头节点 + 交换机专有大型主板，集成大量处理器和内存
通信异构互联：同节点内核间快，节点间慢高效整合，超大内存
价格便宜：只比各节点价格之和略高，可大规模部署比同等核数的集群贵得多
容错一个节点坏了可单独关掉，不必停整个集群—
系统通常 LinuxUNIX + 自家优化工具
特长大量相对独立的任务别处做不了的：超大矩阵对角化

§1.5 延迟与带宽 · 存储层级latency vs bandwidth

原句Latency: is the time it takes for the data requested by the CPU to start arriving. Bandwidth: is the speed (rate) of the arriving data.延迟 = 请求后多久开始到达（等第一个字节）；带宽 = 到达的速率（之后每秒多少）。两者是不同的量。[L1 p19]{{ix:Latency|延迟}}{{ix:Bandwidth|带宽}}
位置 [L1 p19]延迟带宽
CPU 寄存器1 clock—
L1 缓存1 clock150 GB/s
L2 缓存3 clocks50 GB/s
L3/L4 缓存10 clocks50 GB/s
本机 RAM100 clocks10 GB/s
NUMA RAM150 clocks10 GB/s
其他节点的 RAM10k clocks1 GB/s
闪存10k clocks1 GB/s
磁盘10k clocks0.1 GB/s
为什么重要
  • 小的数据集和程序算得快，因为能放进更高一级（更快）的缓存。
  • 随机访问主内存会让程序很慢：每次都要付一次延迟。
  • 访问其他节点的内存，延迟是本机 RAM 的 100 倍，带宽只有 1/10。
  • NUMA（Non-Uniform Memory Access）：多 CPU 插槽的节点里，访问"另一个 CPU 旁边"的内存稍慢（150 vs 100 clocks）。

§1.6 性能指标 · 双精度 · 能耗GIPS, GFLOPS, double precision

指标含义 [L1 p20]注意
GIPS{{ix:GIPS|每秒十亿条指令}}每秒执行十亿条机器指令与架构强相关，不同架构之间不好比
GFLOPS{{ix:GFLOPS|每秒十亿次浮点运算}}每秒十亿次浮点运算（单精度或双精度乘法）科学计算几乎总是用双精度
为什么用双精度（补充）单精度约 7 位有效数字，双精度约 16 位。分子总能量是几十到几千 Hartree，而化学上关心的能量差是 $10^{-3}$ Ha（约 1 kcal/mol）甚至 $10^{-6}$ Ha（约 0.2 cm⁻¹，磁耦合的量级）。用单精度时两个大数相减，有效数字全被吃掉。{{ix:Double precision|双精度}}

能耗：单台计算机无所谓（平均约 0.2 kWh），大型集群就成问题。ARM 处理器（手机、平板、Apple M1）比 Intel 省电得多；当时排名第一的超算、日本的 Fugaku 用 ARM 架构的 A64FX。

§1.7 Moore 定律Moore's law

原句The number of transistors on integrated circuits doubles approximately every two years.集成电路上的晶体管数约每两年翻一番（不是主频！）。不断增长的算力推动计算化学处理更复杂的体系、用更高级的理论。[L1 p21]{{ix:Moore's law|摩尔定律}}
和标度一起看（补充）算力翻一番，但 CCSD(T) 耗时 $\propto N^7$：能算的体系只大 $2^{1/7}\approx1.10$ 倍。计算化学的进步很大程度上来自算法（RI、定域相关、线性标度），不只是硬件（{{p:sB.5}}）。

图中 2005 年以后单线程性能和主频都停滞（功耗墙），增长主要靠核数 → 并行变得必要。

铜缆或光纤均可；码率越高，受噪声和阻抗损耗限制，电缆最大长度越短。互联延迟通常在 100 ns 量级 [L1 p22]。
难点 [L1 p23]：问题分到 N 个节点后，某些时刻只有部分节点需要交换数据。怎样只在需要的节点之间高效交换，是很难的问题，顶级方案大多受商业专利保护。
原句Note the microsecond latencies – 1 microsecond is equivalent to about 2k clocks on a Nehalem CPU. … For this reason, memory intensive calculations with a lot of data dependencies are often difficult to run on cluster architectures. Running them on a single node could be much faster than in parallel on several nodes.集群节点间延迟是微秒级（1 μs ≈ 2000 个时钟周期），带宽也远低于 RAM 和缓存。所以数据依赖多、内存密集的计算在集群上难跑，单节点可能比多节点并行快得多。[L1 p24]
补充Amdahl 定律：程序中串行部分占比 $s$，用 $P$ 个处理器的加速比 $\le 1/[s+(1-s)/P]$，上限 $1/s$。再加上通信开销，核数多到一定程度反而变慢。这就是讲义说 Gaussian CISD 不宜超过 4 核、DFT 不宜超过 32 核的原因（{{p:s3.1}}）。{{ix:Amdahl's law|阿姆达尔定律}}

§1.10 基本矩阵运算的标度scaling of BLAS & LAPACK operations

原句Matrix factorisations (SVD, LU, diagonalisation, Householder, etc.) are very expensive, difficult to parallelize, and do not benefit from sparse storage.矩阵分解（奇异值分解、LU、对角化、Householder）非常贵、难并行、稀疏存储也不省。[L1 p26]{{ix:Diagonalization|对角化}}
运算（$n\times n$）CPU 耗时内存稀疏存储并行
矩阵 × 矩阵$O(n^3)$$O(nnz)$更低容易
矩阵 × 向量$O(n^2)$$O(nnz)$更低容易
exp(矩阵) × 向量$O(n^2)$$O(nnz)$更低容易
矩阵求幂$O(n^3)$$O(nnz)$更低容易
大多数矩阵分解$O(n^3)$$O(n^3)$不变困难

$nnz$：非零元个数（number of non-zeros）。

和后面的联系SCF 每一轮都要对角化 Fock 矩阵（{{p:s3.13}}），这一步 $O(K^3)$ 且难并行；共享内存超算的特长正是超大矩阵对角化（{{p:s1.4}}）；CI 本质上是超大矩阵的本征值问题（{{p:s4.5}}）；对称性把矩阵分块，正是为了减轻对角化负担（{{p:s3.17}}）。

§1.11 操作系统Linux

自 2018 年起，Top 500 超算全部运行 Linux [L1 p27]。它源自 Unix，开源免费，命令行可以直接和硬件打交道。各软件包的特长和短板见 {{p:s3.1}}。

L1 判断陷阱
  • "用的节点越多，计算一定越快。" 节点间延迟 μs 级（约 2000 时钟周期），数据依赖多的内存密集型计算单节点可能快得多 [L1 p24]。
  • "延迟和带宽是同一指标的两种说法。" 延迟是"多久开始到"，带宽是"到达的速率"。
  • "矩阵对角化和矩阵乘法一样容易并行。" 分解类运算难并行，而且稀疏存储也不省内存 [L1 p26]。
  • "矩阵乘法的内存需求是 $O(n^3)$。" $O(nnz)$；只有矩阵分解的内存是 $O(n^3)$（讲义表）。
  • "科学计算一般用单精度以节省时间。" 几乎总是双精度 [L1 p20]。
  • "集群价格远高于各节点价格之和。" 只略高；是共享内存超算比同等集群贵得多 [L1 p16, p18]。
  • "集群中一个节点故障，整个集群都要停机。" 集群容错，坏节点可单独关掉。
  • "共享内存超算和集群一样运行 Linux。" 讲义：Blue Gene/Q 用 UNIX + 自家优化工具；集群"通常" Linux。（但 Top500 自 2018 全是 Linux —— 看题目问哪一页。）
  • "Moore 定律说 CPU 主频每两年翻一番。" 说的是晶体管数。
  • "计算应该在 home 目录里跑。" 放 scratch；home 是网络文件系统，大量 I/O 拖慢集群 [L1 p25]。
  • "互联带宽越高，电缆可以越长。" 相反，码率越高最大长度越短 [L1 p22]。
  • "GIPS 与架构强相关，不同架构之间不好直接比较。" [L1 p20]
  • "小程序和小数据集跑得快，因为能放进更快的缓存。" [L1 p19]
