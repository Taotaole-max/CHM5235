§3.5 HF 回顾：H₂ 最小基与分子积分review of SCF-HF; molecular integrals

HF 的三个前提 [L3 p38]：① BO 近似（核静止）；② 每个电子在其余电子和核的平均静电场中运动；③ 波函数是一个 Slater 行列式。简写 $|\varphi_1\bar\varphi_1\dots|$，上划线表示 β 自旋轨道。

H₂ 最小基 [L3 p39–43] $$\varphi_g=\frac{1s_1+1s_2}{\sqrt{2(1+S_{12})}},\quad \varphi_u=\frac{1s_1-1s_2}{\sqrt{2(1-S_{12})}},\quad S_{12}=\int1s_1^*1s_2\,d\tau>0$$ $$\psi_{H_2}=\frac{1}{\sqrt2}\begin{vmatrix}\varphi_g(1)\alpha(1)&\varphi_g(1)\beta(1)\\\varphi_g(2)\alpha(2)&\varphi_g(2)\beta(2)\end{vmatrix}=|\varphi_g\bar\varphi_g|$$ $$E=2\langle\varphi_g|\hat h|\varphi_g\rangle+\langle\varphi_g\varphi_g|\hat g|\varphi_g\varphi_g\rangle+V_{NN}=2h_{gg}+J_{gg}+V_{NN}$$

不同原子上的基函数不正交（$S_{12}>0$），但组合出的 MO 正交。$\varphi_u$ 没有电子（虚轨道）。双电子项里交换积分对自旋积分后为 0（两个电子自旋相反），所以只剩库仑项。

§3.6 单个 Slater 行列式的能量（按自旋轨道数）energy of a Slater determinant

通式 [L3 p44]{{ix:Slater–Condon rules|斯莱特-康登规则}} $$E=\sum_{i}^{N_{elec}}h_{ii}+\sum_{i}^{N_{elec}}\sum_{j>i}^{N_{elec}}\left(J_{ij}-K_{ij}\right)+V_{nn}$$

$J_{ij}$ 对所有电子对都不为零（不管自旋）；$K_{ij}$ 只对同自旋电子对不为零。i、j 是电子（自旋轨道），两个电子在同一空间轨道 i 上时贡献 $J_{ii}$。

数法：① 每个电子贡献所在轨道的 $h$；② 每对电子贡献一个 $J$（同轨道两电子 → $J_{ii}$）；③ 每对同自旋电子再减一个 $K$。

§3.7 Fock 算符、正则轨道与幺正变换不变性Fock operator, canonical orbitals

Fock 算符（按自旋轨道写）[L3 p46] $$\hat F_i=\hat h_i+\sum_{j=1}^{N_{elec}}\left(\hat J_j-\hat K_j\right),\qquad \hat F_i\varphi_i=\varepsilon_i\varphi_i$$

"Fock operator … defines the effective kinetic energy of an electron and the attraction to all nuclei"（加上与其他电子的平均排斥）。HF 轨道能就是 $\hat F$ 的本征值。

原句When HF orbital optimization calculation is finished, φi are canonical molecular orbitals. Fock operator written in the basis of canonical molecular orbitals is diagonal. There are many orbital sets possible for the HF wave function, giving the same total energy. Any orbital set obtained by some unitary transformation of the converged molecular orbitals – will also give the same identical total HF energy.收敛得到的是正则轨道（Fock 矩阵对角）。对占据轨道做任意幺正变换，行列式（至多差一个相因子）和总能量都不变 ⇒ 轨道不唯一。例：自然轨道对角化单电子密度矩阵。[L3 p46, p61]{{ix:Canonical orbitals|正则轨道}}{{ix:Natural orbitals|自然轨道}}{{ix:Unitary transformation|幺正变换}}

正则轨道收敛后使 $F_{\alpha\beta}$ 对角的轨道轨道能 $\varepsilon_i$

§3.8 Koopmans 定理Koopmans' theorem

原句Let's use the obtained set of molecular orbitals for a system with N electrons to compute the energy of a system with (N+1) and (N−1) electrons. Consider that the orbitals remain exactly the same as in the original calculation.用 N 电子体系的轨道不变地去算 N±1 电子体系的能量。[L3 p47]{{ix:Koopmans' theorem|库普曼斯定理}}
$$E_N-E_{N-1}=\varepsilon_i\ \ (\text{移走 i 上的电子}),\qquad E_{N+1}-E_N=\varepsilon_a\ \ (\text{加到空轨道 a})$$ $$\text{IP}\approx-\varepsilon_{HOMO},\qquad \text{EA}\approx-\varepsilon_{LUMO}$$

推导 [L3 p48]：两个组态能量之差恰好是 $h_{33}+J_{13}-K_{13}+J_{23}-K_{23}=\langle\varphi_3|\hat F|\varphi_3\rangle=\varepsilon_3$（正则轨道下 F 对角）。

条件 / 失效
  • 前提：冻结轨道（不让 N±1 体系的轨道弛豫）+ 正则 HF 轨道 + 单行列式（无相关）。
  • （补充）IP：忽略轨道弛豫使 IP 偏大、忽略相关使 IP 偏小，两者部分抵消 → Koopmans IP 常不错。EA：两个误差同向，−εLUMO 往往很差（HF 的 LUMO 常为正能量）。
  • 只对 HF 成立；DFT 的 Kohn–Sham 轨道能没有这个意义（只有精确泛函下 −εHOMO = IP，{{p:s5.7}}）。

§3.9 B 原子：什么时候一个行列式不够（静态相关）wave function for B atom

原句Since the 2p shell is degenerate, the electron in the last shell may be placed in any of these orbitals … the wave function … must include all possibilities on equal footing. As result, there are three Slater Determinants possible … Given that HF method optimizes molecular orbitals of ONLY ONE Slater Determinant – it is NOT adequate for this problem … (CASSCF) must be employed … This case is a typical case of "static electron correlation" problem.B：1s²2s²2p¹，2p 三重简并 → 三个等价行列式 $\psi=\frac{1}{\sqrt3}\left(|1s^22s^22p_x|+|1s^22s^22p_y|+|1s^22s^22p_z|\right)$。HF 只能优化一个行列式 → 不合适，要用 CASSCF。这是典型的静态电子相关问题。[L3 p49–50]{{ix:Static correlation|静态相关}}
判别规律只要有简并或近简并的部分占据轨道（开壳层原子、键解离、双自由基、过渡金属 d 壳层、共轭体系），就可能需要多个行列式。

§3.10 RHF、ROHF、UHF 与自旋污染restricted / unrestricted SCF, spin contamination

原句The Hamiltonian used in Hartree-Fock theory does not explicitly mention spin … a spin-flip does not change the energy. If we enforce that symmetry (demanding that the up and the down spin orbitals share the space part), the version … is called restricted. In open-shell systems, the unrestricted version is preferred… Restricted SCF is often faster (fewer integrals to evaluate), but fails to reproduce certain bond breaking processes. Unrestricted SCF treats bond breaking correctly (although for the wrong reasons), but can suffer from spin contamination.[L3 p51–52]{{ix:Restricted open-shell HF (ROHF)|限制性开壳层 HF}}

原句Unrestricted SCF methods produce wavefunctions that are not eigenfunctions of the total spin operator.
