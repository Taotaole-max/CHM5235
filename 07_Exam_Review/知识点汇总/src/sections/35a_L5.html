L5密度泛函理论（DFT）、磁耦合与 TD-DFTDensity functional theory · functionals · BS-DFT magnetic coupling · TD-DFT

L5 换一条路补相关：不再扩展波函数，而是用 3 维的电子密度 ρ(r) 作基本变量。主线：电子密度与 Mulliken 型布居 → HK 第一定理（ρ 唯一决定一切）→ HK 第二定理（密度的变分原理）→ Kohn–Sham 方程（精确变换，未知的只有 $V_{xc}$）→ 泛函阶梯（LDA → GGA → meta-GGA → 杂化 → 双杂化，另有长程校正和色散校正）→ DFT 的系统误差（色散、自相互作用、过度离域）→ 磁耦合（Heisenberg 模型、BS-DFT、Yamaguchi）→ TD-DFT。

§5.1 电子密度的展开与布居分析electron density distribution

[L5 p4–5] $$\rho(\vec r)=\sum_{i=1}^{N}|\chi_i(\vec r)|^2,\quad \chi_i=\sum_{\mu=1}^{K}c_{\mu i}\varphi_\mu\ \Rightarrow\ \rho(\vec r)=\sum_{\mu,\nu}^{K}\sum_i^N c_{\mu i}^*c_{\nu i}\,\varphi_\mu^*(\vec r)\varphi_\nu(\vec r)$$ $$N=\int\rho\,d^3r=\sum_{\mu\nu}P_{\mu\nu}S_{\mu\nu},\qquad P_{\mu\nu}=\sum_{i=1}^{N}c_{\mu i}^*c_{\nu i}\ \text{（密度矩阵）},\quad S_{\mu\nu}=\int\varphi_\mu^*\varphi_\nu\,d^3r\ \text{（重叠矩阵）}$$ $$N_{\mu\nu}=P_{\mu\nu}S_{\mu\nu}\ \text{（轨道对的布居）},\qquad P^\alpha_{\mu\nu}=\sum_i c^{\alpha*}_{\mu i}c^\alpha_{\nu i},\ \ P^\beta_{\mu\nu}=\sum_i c^{\beta*}_{\mu i}c^\beta_{\nu i}$$
N电子数（求和到占据自旋轨道）K基函数数
两种情况 [L5 p5]① $\varphi_\mu,\varphi_\nu$ 在同一原子上：$N_{\mu\nu}$ 全部归这个原子（贡献它的电荷）；② 在不同原子上：$N_{\mu\nu}$ 由两原子共享，既贡献化学键也贡献电荷（Mulliken 平分，{{p:s6.1}}）。同样可以按 α、β 分开做自旋布居。
密度算符 [L5 p8–9] $$\hat\rho(\vec r)=\sum_{i=1}^{N}\delta(\vec r_i-\vec r),\qquad \rho(\vec r)=\langle\Psi|\hat\rho(\vec r)|\Psi\rangle=\sum_i|\varphi_i(\vec r)|^2$$

单电子：$\rho=|\Psi(\vec r)|^2$ = 在 $\vec r$ 找到电子的概率。N 电子：在 $\vec r$ 找到任意一个电子的概率，不管其余 N−1 个在哪。无论 N 多大，ρ 都只是 3 个变量的实函数（波函数是 3N 个变量）。

原句Within the Born-Oppenheimer Hamiltonian, the type of molecule or solid is defined by the electron-nucleus interaction (this is often called the 'external potential').BO 下决定"是什么分子/固体"的只有核–电子吸引 $V_{ext}=-\sum_i\sum_A Z_A/|\vec R_A-\vec r_i|$（外势）；动能和电子排斥对所有体系形式都一样。[L5 p7]{{ix:External potential|外势}}

§5.2 Hohenberg–Kohn 第一定理first HK theorem

原句"There is a one-to-one correspondence between the ground state density of a many-electron system and the external potential." Consequence: any observable ground state property of the many-electron system can be written as a unique functional of the density: property = ⟨Ψ|Ô|Ψ⟩ = O[ρ].基态密度与外势一一对应 ⇒ 任何基态可观测性质都是密度的唯一泛函。C 单射"不奇怪"，D 单射"非常令人惊讶"——这就是 HK 第一定理（1964）。[L5 p14, p17]{{ix:Hohenberg–Kohn theorems|霍恩伯格-科恩定理}}
反证法证明思路 [L5 p15]设 $\Psi\ne\Psi'$（外势 V、V′ 不同，电子数相同）却给出同一个 ρ。$\hat H=\hat H'-V'+V$，由变分原理： $$E_0<\langle\Psi'|\hat H|\Psi'\rangle=E_0'+\int\rho'(V-V')\,d\vec r,\qquad E_0'变分原理和非简并基态。）

泛函：函数把数映射成数，$x\mapsto f(x)$；泛函把函数映射成数，$f\mapsto F[f]$，例如 $F[f]=\int f(x)e^{-x^2}dx$。泛函导数：$F_1[\rho]=\int\rho(\vec r)\nu(\vec r)d\vec r\Rightarrow\delta F_1/\delta\rho=\nu(\vec r)$ [L5 p18]。{{ix:Functional|泛函}}

§5.3 Hohenberg–Kohn 第二定理：密度的变分原理second HK theorem

原句"The unique functional that returns the ground state total energy when applied to the ground state density, returns a higher energy for any other density."把基态密度代入能量泛函得到基态能量；代入任何其他密度得到更高能量。[L5 p19]
$$E_{V_{ext}}[\rho]=F_{HK}[\rho]+\int\rho(\vec r)V_{ext}(\vec r)\,d\vec r,\qquad E_0=\min_\rho E[\rho]$$

$F_{HK}$：（未知的）Hohenberg–Kohn 泛函，给出动能 + 电子–电子部分，对所有体系通用。Note 2：可以通过最小化能量泛函找到基态密度 [L5 p20]。

条件 / 局限
  • HK 定理只讲基态（激发态要 TD-DFT，{{p:s5.16}}）；证明假设非简并基态。
  • 定理保证泛函存在，但没给出它的形式。用近似泛函时，DFT 能量不再是精确能量的上界（补充）。
  • "Ground state total energy" = 把所有核和电子分开到无穷远需要加的能量（0 K）；实验上可由比热、熔化与汽化潜热、再把原子变成等离子体所需能量得到 [L5 p21]。

§5.4 Kohn–Sham 方程Kohn–Sham theorem

原句The Kohn-Sham equations are an exact transformation of the original problem (coupled differential equations) in single-particle equations (uncoupled). "The exact ground state density of a N-electron system is ρ(r) = Σ φi*(r)φi(r), where the single-particle wave functions φi are the N lowest-energy solutions of the Kohn-Sham equations."KS 方程把耦合的多电子问题精确地变换为不耦合的单粒子方程；精确基态密度 = N 个最低 KS 轨道的 $|\phi_i|^2$ 之和。[L5 p22]{{ix:Kohn–Sham equations|科恩-沈方程}}
KS 方程 [L5 p22] $$\hat H_{KS}\phi_i=\varepsilon_i\phi_i,\qquad \hat H_{KS}=-\frac{\hbar^2}{2m_e}\nabla_i^2+\hat V_{ext}+\underbrace{\frac{e^2}{4\pi\varepsilon_0}\int\frac{\rho(\vec r')}{|\vec r-\vec r'|}d\vec r'}_{\hat V_H\ (\text{Hartree})}+\hat V_{xc},\qquad \hat V_{xc}=\frac{\delta V_{xc}[\rho]}{\delta\rho}$$

KS 的"单粒子"是无相互作用的准粒子，其密度等于真实体系密度；动能用轨道精确算（这是 KS 相比纯密度泛函的关键改进，补充）。所有未知都塞进 $V_{xc}$。

§5.5 交换相关泛函：LDA、GGA、meta-GGAapproximate XC functionals

原句One unique expression for Vxc[ρ] must exist, but it is unknown. … Meta-GGAs also include second and higher derivatives of the density. This effectively amounts to building more and more accurate Taylor type approximations to the true XC functional.唯一的精确 $V_{xc}[\rho]$ 存在但未知；LDA → GGA → meta-GGA 相当于对真实泛函做越来越高阶的"Taylor 型"近似。[L5 p24]
[L5 p24, p29]{{ix:Local density approximation (LDA)|局域密度近似}}{{ix:Generalized gradient approximation (GGA)|广义梯度近似}}{{ix:Meta-GGA|meta-GGA 泛函}} $$\text{LDA：}\ V_{xc}^{LDA}[\rho]=\int\rho(\vec r)\,\varepsilon_{xc}(\rho(\vec r))\,d\vec r,\qquad E_x^{LDA}=-\frac34\left(\frac3\pi\right)^{1/3}\int\rho^{4/3}(\vec r)\,d\vec r$$ $$\text{LSDA：}\ \varepsilon_{xc}(\rho_\uparrow,\rho_\downarrow);\qquad \text{GGA：}\ \varepsilon_{xc}(\rho_\uparrow,\rho_\downarrow,\nabla\rho_\uparrow,\nabla\rho_\downarrow);\qquad \text{meta-GGA：再加}\ \nabla^2\rho\ \text{或动能密度}\ \tau$$

GGA 例：Becke 88 交换 $\varepsilon_x^{B88}=\varepsilon_x^{LDA}-\beta\rho^{1/3}\dfrac{x^2}{1+6\beta x\sinh^{-1}x}$，$x=|\nabla\rho|/\rho^{4/3}$；LYP 相关（Lee–Yang–Parr）。meta-GGA：TPSS、VSXC、HCTH 等。

LDA 的物理图像（补充）把每一点当作密度为 ρ(r) 的均匀电子气。适合密度变化缓慢的体系（金属）；分子中会过度结合（键能偏大、键长偏短）。GGA 加入密度梯度，描述不均匀性。
