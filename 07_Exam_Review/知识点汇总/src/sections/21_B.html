§B.2 基函数数 Kcounting basis functions

规则
  • K = 每个原子上各壳层函数数之和。一个 s 壳层 = 1 个函数，p = 3，d = 5（球谐）或 6（笛卡尔），f = 7 或 10，g = 9。笛卡尔函数数 = $(l+1)(l+2)/2$。
  • 最小基组（STO-3G）：每个被占据的原子轨道 1 个函数，而且整个价层亚层都要给（B 只有 1 个 2p 电子，也给 3 个 2p；Li、Be 也给 2p）。
  • 劈裂价层：内层 1 个，价层每个 AO 拆成 2 个（3-21G、6-31G）或 3 个（6-311G）。第三周期的 6-311G 例外：Cl 为 [6s5p]（21 个）。
  • (d) 或 *：重原子（非 H）加一组 d；(d,p) 或 **：再给 H 加一组 p（+3）。(2df,2pd)：重原子加 2 组 d + 1 组 f，H 加 2 组 p + 1 组 d。
  • +：重原子加一组弥散 s + p（+4）；++：再给 H 加一个弥散 s（+1）。
  • cc-pVnZ：n = D、T、Q、5（即 2、3、4、5）为 zeta 数；重原子最高角动量 l = n（DZ → d，TZ → f，QZ → g），H 低一级。aug-：每种角动量各加一个弥散函数。

§B.3 分子轨道数：占据与虚轨道occupied / virtual orbitals

规则 $$\text{MO 数}=K\ (\text{每种自旋}),\qquad \text{闭壳层：占据}=\frac N2,\ \ \text{虚}=K-\frac N2;\qquad \text{开壳层：}\ \alpha\ \text{占}\ N_\alpha,\ \beta\ \text{占}\ N_\beta$$

自旋轨道数 2K。HOMO 是第 N/2 个，LUMO 是第 N/2 + 1 个（闭壳层）。为什么 MO 数 = K：Roothaan 方程中 F、S 是 K × K 矩阵，解出 K 个本征值和本征矢；K 个线性无关函数只能组合出 K 个线性无关轨道（{{p:s3.11}}）。

判断陷阱
  • "换更大的基组，占据轨道会变多。" 占据数只由电子数决定；变的是虚轨道数。
  • "UHF 的轨道总数是 K。" α、β 各一套 K 个空间轨道，共 2K 个。
  • "虚轨道越多，HF 能量降得越多。" HF 能量只取决于占据轨道；更大基组让占据轨道本身更好才降能量。虚轨道数主要影响相关方法。
  • "HF 的虚轨道能 = 加一个电子的能量，很准。" Koopmans EA 通常很差（{{p:s3.8}}）。

§B.4 行列式数与 CSF 数Slater determinants, CSFs, CAS

[L4 p14]：n 个空间轨道（2n 个自旋轨道）、N 个电子、总自旋 S{{ix:Complete active space CAS(N,n)|完全活性空间}} $$N_{SD}=\binom{2n}{N},\qquad N_{SD}(M_S)=\binom{n}{N_\alpha}\binom{n}{N_\beta},\qquad N_{CSF}(S)=\frac{2S+1}{n+1}\binom{n+1}{\frac N2-S}\binom{n+1}{\frac N2+S+1}$$

核对：$\sum_S(2S+1)N_{CSF}(S)=N_{SD}$（每个自旋 S 的 CSF 有 2S + 1 个 $M_S$ 分量）。CAS(N, n)：N 个电子放在 n 个活性轨道中，活性空间内做 FCI（{{p:s3.22}}）；非活性轨道始终双占，虚轨道始终空。

激发行列式的数目（按自旋轨道：N 个占据，$2K-N$ 个虚） $$N_S=N(2K-N),\qquad N_D=\binom N2\binom{2K-N}{2},\qquad N_{FCI}=\binom{2K}{N}$$

例：H₂O / cc-pVDZ（N = 10，2K = 48，虚自旋轨道 38）：单激发 380 个，双激发 45 × 703 = 31 635 个，FCI $\binom{48}{10}=6.5\times10^9$ 个。这就是 FCI 只能做极小体系、CISD 截断到双激发的原因（{{p:s4.5}}）。
