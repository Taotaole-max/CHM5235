§5.13 磁耦合：Heisenberg–Dirac–van Vleck 模型magnetic couplings

由 $\hat S_T^2=(\hat S_1+\hat S_2)^2=\hat S_1^2+\hat S_2^2+2\hat S_1\cdot\hat S_2$；$S_T=S_1+S_2,\dots,|S_1-S_2|$。

§5.15 Broken-symmetry DFT 与 Yamaguchi 公式BS-DFT, Yamaguchi formula

行列式能量（{{p:s3.6}}） $$E_{HS}=\langle1|h|1\rangle+\langle2|h|2\rangle+\langle12|12\rangle-\langle12|21\rangle,\qquad E_{BS}=\langle1|h|1\rangle+\langle2|h|2\rangle+\langle12|12\rangle$$ $$E_{HS}-E_{BS}=-\langle12|21\rangle=-K_{12}\quad(\text{高自旋更低，差一个交换积分})$$
讲义 p42 / p43 的符号笔误（按 p40 约定 $\hat H=-2J\hat S_1\cdot\hat S_2$，J > 0 铁磁）

p42 先写 $E_{HS}-E_{BS}=-2J$（把 BS 当作单重态，与 p41 一致），紧接着却写 $J=(E_{HS}-E_{BS})/2$——代入得 J = −J，自相矛盾。最右边的 $\langle12|21\rangle/2$ 是对的。正确：

$$J=\frac{E_{BS}-E_{HS}}{2}=\frac{K_{12}}{2}\qquad(\text{BS 视作纯单重态})$$

p43 Yamaguchi 公式分子、分母顺序也反了。正确（标准形式）：{{ix:Yamaguchi formula|山口公式}}

$$J=\frac{E_{BS}-E_{HS}}{\langle S^2\rangle_{HS}-\langle S^2\rangle_{BS}}$$

自检（考场用，不用死记）：铁磁体系 HS 更稳定 ⇒ $E_{BS}>E_{HS}$；又总有 $\langle S^2\rangle_{HS}>\langle S^2\rangle_{BS}$ ⇒ 分子分母都正 ⇒ J > 0 ✓。讲义原式在同样情形给出 J < 0，与 p40 约定矛盾。若判断题直接照抄讲义公式，按讲义；若问物理/符号是否自洽，按订正。

假设 [L5 p42–43]＋补充$\langle S^2\rangle_{BS}$Yamaguchi 分母结果
BS ≈ 纯单重态（磁轨道强重叠）02 − 0 = 2$J=(E_{BS}-E_{HS})/2$ ← p42 的结果（Ruiz/Bencini）
BS ≈ ½ 单重态 + ½ 三重态（弱重叠）12 − 1 = 1$J=E_{BS}-E_{HS}$ ← Noodleman（一般 $S_1,S_2$：分母 $4S_1S_2$）{{ix:Noodleman formula|Noodleman 公式}}
一般情形实际计算值$\langle S^2\rangle_{HS}-\langle S^2\rangle_{BS}$Yamaguchi：在两极限间自动插值，用 ⟨S²⟩ 校正自旋污染
为什么弱重叠时差 2 倍BS 行列式 $|\alpha\beta|=\frac{1}{\sqrt2}\left[\text{单重态}+\text{三重态}(M_S=0)\right]$，所以 $E_{BS}\approx\frac12(E_S+E_T)$，$E_{BS}-E_{HS}=\frac12(E_S-E_T)=\frac12\cdot2J=J$。BS 态本身就是自旋污染的混合态（$\langle S^2\rangle\approx1$，而纯单重态应为 0）。
条件 / 注意
  • "For more general cases when $S_{1,2}\ge\frac12$ the above formula is not quite correct … must consider the larger value of the total spin" → 用 Yamaguchi [L5 p43]。
  • 要确认自旋真的翻到了目标原子（看 Mulliken 自旋布居），并检查 BS 态的 ⟨S²⟩（HW2 Ex5 的 Cu₂Cl₆²⁻，{{p:sH.2}}）。
  • J 对泛函（HF 交换比例）很敏感；能量单位换算 1 Ha = 219 474.6 cm⁻¹。
  • ORCA 实现了多种公式（易用）；Gaussian 也可以。

§5.16 激发态：传播子方法、RPA 与 TD-DFTpropagator methods, TD-DFT

频率依赖的极化率 [L5 p44] $$\alpha(\omega)=\sum_{n\ne0}\frac{|\langle\psi_0|\mathbf r|\psi_n\rangle|^2}{\omega-(E_n-E_0)}\quad(\text{讲义简写；分母为零处即激发能：极点})$$

分子体系受线性振荡电场 $\mathbf E=\mathbf r\cos\omega t$ 作用。极化率在 $\omega=E_n-E_0$ 处发散 → 从响应函数的极点得到激发能，从留数得到跃迁强度（补充）。

方法 [L5 p44]要点
传播子方法（Green 函数、运动方程 EOM）{{ix:Propagator methods|传播子方法}}求频率依赖的极化率，不显式构造激发态波函数 $\psi_n$
RPA（无规相近似）{{ix:Random phase approximation (RPA)|无规相近似}}计入单、双激发对 CI 矩阵元的影响，但不显式建 CI 波函数；可用于 HF 或 CASSCF；动态相关质量中等
TD-DFT{{ix:TD-DFT|含时密度泛函}}DFT 版的 RPA：把"一个电子从占据轨道激发到虚轨道"当作对原体系的外加微扰来优化激发态
原句Of course, there is no actual "time-dependency" in the excited state calculations using TD-DFT. The term originates from the fact that TD-DFT equations started from solving the time-dependent Schrodinger equation, with subsequent making the so-called adiabatic approximation, which is equivalent to "losing time memory", i.e. no time-dependency.TD-DFT 算激发态并没有真的"含时"；名字来自从含时方程出发，再做绝热近似（"失去时间记忆"）。[L5 p44]{{ix:Adiabatic approximation|绝热近似}}
TD-DFT 好用的条件 [L5 p45]
  1. 基态能用单个 Slater 行列式很好描述；
  2. 自旋污染小；
  3. 只需要低激发态；
  4. 合适的基组和密度积分网格；
  5. 合适的色散校正。

"High excited states which are comparable to molecular ionization potentials are poorly described."（接近电离能的高激发态、Rydberg 态描述差）。并非所有软件都支持溶剂 + 相对论 + 色散的所有组合，也可能有 bug → 批判地分析结果。补充：电荷转移激发能偏低 → 用长程校正泛函（{{p:s5.8}}）；双激发特征的态 TD-DFT（绝热近似）描述不了。

L5 判断陷阱
  • "HK 定理给出了精确的交换相关泛函形式。" 只证明存在性；形式未知。
  • "KS 方程是对多电子问题的近似变换。" 讲义：精确变换（exact transformation）；近似只在 $V_{xc}$。
  • "HK 定理同样保证激发态密度唯一决定外势。" HK 讲基态。
  • "用近似泛函算的 DFT 能量一定是精确能量的上界。" HK 变分原理针对精确泛函；近似泛函可以低于精确能量。
  • "DFT 是 ab initio 方法，没有经验参数。" 讲义：杂化泛函的系数拟合实验数据 → "disqualifies DFT from the ab initio category"。
  • "DFT 可以像 CI 一样系统地改进。" 波函数方法可以（加大 CI 展开），DFT 不清楚。
  • "B3LYP 能正确描述稀有气体二聚体的结合。" 标准 DFT 缺色散，预测 He₂、Ne₂ 不稳定；要加 D3。
  • "HF 能描述色散。" HF 与标准 DFT 都不能 [L5 p35]。
  • "DFT 低估电荷转移复合物的结合能。" 高估（乙烯–F₂ 高估 20 kcal/mol）。
  • "DFT 的氢键重原子距离偏长。" 通常太短。
  • "HF 有自相互作用误差。" HF 中 J 与 K 的 i = j 项精确抵消；近似 DFT 才有。
  • "长程校正泛函在长程用 DFT 交换、短程用 HF 交换。" 反过来：短程 DFT、长程精确 HF 交换。
  • "TD-DFT 能可靠描述接近电离能的高激发态。" 描述差；只适合低激发态。
  • "TD-DFT 计算中波函数真的随时间演化。" 绝热近似后没有时间依赖。
  • "开壳层单重态是一个 Slater 行列式，可以直接用 DFT 算。" 需要两个行列式 → BS 方法。
  • "BS 态是纯单重态。" 它是 $M_S=0$ 的单行列式，含三重态成分（自旋污染，⟨S²⟩≈1）。
  • "$\hat H=-2J\hat S_1\cdot\hat S_2$ 中 J < 0 表示铁磁。" J > 0 铁磁，J < 0 反铁磁。
  • "两个 S = ½ 自旋的单重–三重能隙是 J。" $E_T-E_S=-2J$。
  • "镧系化合物可以直接用常规 DFT 处理 4f 电子。" 讲义：只适合 4f-in-core 赝势。
  • "双自由基、多自由基最适合 DFT。" 近简并 → 不太适合；单自由基可以。
  • "ρ(r) 无论电子数多少都只是三个变量的函数。"
  • "双杂化泛函用到虚轨道，计算标度 N⁵。"
