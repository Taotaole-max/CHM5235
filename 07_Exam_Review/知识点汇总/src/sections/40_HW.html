HW作业里的现象与结论What HW1 (Gaussian) and HW2 (ORCA) actually showed

只写现象、原因和对应的讲义知识点，不写输入关键词。数值来自你自己的报告，考试出"情景题"时可以直接当例子用。

§H.1 HW1（Gaussian）HCl, H–F PES, CH₂FCl, H₂, CH₂FOH

题目现象（数据）原因 / 对应知识点
Ex1 HCl
RHF，6 个基组		基函数数 = 轨道数：STO-3G 10、6-31G 15、cc-pVDZ 23、6-311+G(d) 33、cc-pVTZ 48、cc-pVQZ 89。STO-3G：9 个占据 + 1 个虚轨道。Re 1.313 → 1.266 Å（实验 1.275）；频率 3373 → 3139 cm⁻¹，都高于实验 2991。6-311+G(d) 的能量（−460.0872）高于 cc-pVDZ（−460.0895）。MO 数 = K（{{p:sB.3}}）；HF 频率系统偏高约 5%（缺相关，键太"硬"）；基组越大越接近 HF 极限，但 HF 极限 ≠ 实验（相关能）。不同系列的基组不是嵌套的，能量不必单调——变分原理只保证同一函数空间扩大时能量不升（{{p:s3.3}}）。
Ex1 HCl
轨道与电荷		MO 1–5 是 Cl 内层（1s −104.8 Ha；2p 三个近简并）；MO 6 以 Cl 3s 为主；MO 7 是 H–Cl σ 键；HOMO（MO 8、9）是两个简并的 Cl 3p 孤对；HOMO–LUMO 能隙 15.5 eV。Mulliken：Cl −0.17、H +0.17。HF 能隙远大于光学能隙（虚轨道能不是激发能）；π 型孤对由 $\hat L_z$ 对称性简并（{{p:s2.6}}）。
Ex2 H–F 势能面
UHF/UB3LYP/UCCSD/UCCSD(T)		guess=mix 对异核 H–F 没能破缺自旋对称：从 0.5 到 10 Å 全程 ⟨S²⟩ = 0（UHF 塌回 RHF 解）。在 R = 5 Å 做稳定性分析后能量降低 0.293 Ha（769 kJ/mol），⟨S²⟩ 0 → 1.003。拉长区 UCCSD 振幅方程不收敛（4.57 Å 以后）。De：UB3LYP 574 最接近实验 569 kJ/mol。SCF 收敛 ≠ 最低解（{{p:s3.16}}）；RHF 型解解离错误（离子项，{{p:s2.20}}）；UHF 破缺对称得到正确极限但 ⟨S²⟩ → 1（两个自由基的 50:50 单重/三重混合，{{p:sB.1}}）；键断裂 = 静态相关 → 单参考 CC 失效（{{p:s4.11}}）。
讲义任务 H₂
RHF vs UHF		平衡附近两条曲线重合；在 Coulson–Fischer 点之后 UHF 低于 RHF，趋于 2E(H) = −1 Ha；RHF 解离极限过高。{{p:s2.20}}、{{p:s4.7}}：RHF 固定 50% 离子项；FCI 中 $a_1\to-a_0$。
Ex3 CH₂FClBDE（UB3LYP/cc-pVDZ，含 ZPE）：C–H 390 kJ/mol、C–F 435 kJ/mol。三种方法总能量：HF/STO-3G −591.17、B3LYP/cc-pVDZ −599.36、CCSD/cc-pVTZ −598.67 Ha。静电势面：H 端正（蓝），F、Cl 端负。BDE = 碎片（自由基用非限制方法）− 母体，要加 ZPE；不同方法 + 不同基组的总能量不能直接比（B3LYP 低于 CCSD 不说明更准，DFT 不受变分上界约束，{{p:s5.3}}）；MEP 见 {{p:s6.7}}。
Ex5 H₂ 理论题最小基 6 个行列式；基态 $E_0=2h_{gg}+J_{gg}+V_{nn}$；单激发三重态 $h_{gg}+h_{uu}+J_{gu}-K_{gu}$，单重态 $+K_{gu}$。{{p:s3.6}}、{{p:s4.7}}、{{p:sB.4}}
Ex6 CH₂FOH
TD-DFT(TDA) vs CIS		S1：TDA/B3LYP 8.10 eV（153 nm），CIS 9.81 eV；CIS 五个态都高 1.7–3.0 eV。无共轭 → 吸收在真空紫外。CIS 不含相关（基于 HF，虚轨道太高）；TD-DFT 含近似相关（{{p:s5.16}}）；激发能 ∝ 1/L²（共轭越长越红）。

§H.2 HW2（ORCA）2-chlorophenol, solvent, RI, TD-DFT, BS-DFT, MD

题目现象（数据）原因 / 对应知识点
Ex1 2-氯苯酚
PBE vs B3LYP，气相 vs 水		HOMO–LUMO 能隙：PBE 4.19 eV、B3LYP 5.76 eV（气相）；水中只变 0.02 eV。频率：B3LYP 平均高 2.8%，O–H 伸缩 3567 vs 3722 cm⁻¹。偶极矩 0.75（PBE 气）→ 1.09 D（B3LYP 水）。熵几乎与方法无关（81.2–81.9 cal/mol/K）。O–H 朝向 Cl 的构象低 3.3 kcal/mol（分子内 O–H···Cl）。杂化泛函的 HF 交换减小 SIE、拉开能隙；GGA 能隙偏小（{{p:s5.6}}、{{p:s5.8}}）。连续介质使分子极化 → 偶极矩、O–H 电荷分离增大（{{p:s6.17}}）。平动/转动熵只取决于质量和几何。
Ex1 原子电荷Mulliken：Cl −0.13 ~ −0.14、O −0.32 ~ −0.42；Löwdin：Cl +0.37 ~ +0.39、O +0.08 ~ +0.11——符号翻转；C1、C2 也反号。电荷不是可观测量；两种方案划分重叠密度的方式不同，只能在同一方案内比较趋势（{{p:s6.1}}、{{p:s6.3}}）。
Ex1 静电势最负：O 孤对（远离 Cl 一侧）和环的 π 面；最正：羟基 H。点电荷模型画不出 π 面上方的负电势。MEP 来自真实电子分布；原子中心电荷不能表示 π 电子云（{{p:s6.7}}）。
Ex2 溶剂理论CPCM(Water)：ε = 80.4，空腔为 1.2 × vdW 半径的原子球；表面电荷 $\mathbf{Aq}=-f(\varepsilon)\mathbf V$，$f=(\varepsilon-1)/(\varepsilon+x)$（CPCM x = 0，COSMO x = 0.5）；静电溶剂化能 −4.7 ~ −4.8 kcal/mol；普通 CPCM 不含空腔/色散项；氢键要显式水。{{p:s6.16}}、{{p:s6.17}}；自洽反应场：电荷与密度每轮一起更新；自由能里的 ½ = 极化溶剂所做的功。
Ex3 RI 理论2-氯苯酚 def2-TZVP：K = 284，四中心积分约 $8.1\times10^8$ 个（≈ 6.5 GB）；RI（def2/J，Naux = 449）只需约 $1.8\times10^7$ 个三中心积分（≈ 145 MB，少 45 倍），可放内存。{{p:s3.15}}、{{p:sB.5}}：$K^4/8$ → $K^2N_{aux}/2$；拟合误差系统性，能量差中大部分抵消。
Ex4 TD-DFTS1 = HOMO→LUMO（π→π*）：PBE 4.66 eV、B3LYP 4.99 eV；B3LYP 所有态比 PBE 高 0.3–0.5 eV；水中 S1 只移 −0.01 eV，但振子强度 0.040 → 0.058；部分态顺序互换。泛函选择的影响远大于溶剂（{{p:s5.16}}）；杂化泛函激发能更高（能隙更大）。
Ex5 Cu(II)₂ 桨轮
BS-DFT		⟨S²⟩HS ≈ 2.00、⟨S²⟩BS ≈ 1.00；Cu 自旋布居 +0.63 / −0.63（BS 确实翻转）。$E_{HS}-E_{BS}$ 只有 20–130 cm⁻¹（比总能量小 7 个数量级）。J（Yamaguchi，$\hat H=-2J\hat S_A\cdot\hat S_B$）：SVP 下非相对论 +38（铁磁）→ DKH −22 / ZORA −53（反铁磁）；TZVP 下三者都反铁磁（−78，DKH = ZORA = −127 cm⁻¹）。相对论使总能量降 30–46 Ha，但在 J 中几乎全部抵消。泛函：TPSSh(10% HF) +173、B3LYP(20%) +38、PBE0(25%) −31 cm⁻¹。弱重叠极限 ⟨S²⟩ 差 ≈ 1 ⇒ Yamaguchi ≈ Noodleman，Bencini 式小一半（{{p:s5.15}}）；小基组造成符号假象；标量相对论主要稳定内层、对 J 的净效应约 60%（{{p:s6.12}}）；HF 交换比例是 BS-DFT 最大的不确定性：本例中 HF 交换越多，J 越负（越偏反铁磁）。
Ex6 水团簇 MD
PBE vs GFN2-xTB，400 K		xTB（128 个水、2.5 ps）：四面体序参量 0.90 → 0.39，4.4 Å 第二近邻峰消失 → 冰簇熔化，氢键数几乎不变；分子从表面蒸发（需要球形壁）。DFT（20 个水、100 fs）：几乎看不到熔化。温度涨落：大团簇 ±22 K，60 原子 DFT 团簇 ±50 K。每原子每步：DFT 比 xTB 贵约 136 倍。氢键重排需 ~ps，100 fs 只够采样振动；小体系温度相对涨落 ∝ $1/\sqrt N$；成本决定能模拟的尺度和时长（半经验 = 忽略大部分积分，{{p:s3.14}}）。
