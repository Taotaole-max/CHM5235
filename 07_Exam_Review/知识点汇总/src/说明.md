# 知识点汇总的源文件

成品：上一级的 `CM5235_开卷知识点汇总_L1-L6.pdf`（黑白双面打印设计）。

| 文件 | 用途 |
|---|---|
| `sections/*.html` | 正文，按文件名顺序拼接：00 封面目录、10 公式速查、20–21 计数手册、31–36 L1–L6、40 作业结论、90 英文索引 |
| `style.css` | 版式（只用灰度和边框样式区分各种框） |
| `crops.py` | 从 `01_Lecture_Notes/slides/` 的讲义 PDF 按区域截图 → `img/L*_p*.png` |
| `make_figs.py` | 自绘示意图 → `img/fig_*.png` |
| `build.mjs` | 拼接 + KaTeX 渲染公式 + Chromium 打印成 `out/raw.pdf` |
| `post.py` | 读页码回填目录/索引/页码引用；盖页眉、页码、外侧书签 |
| `make.sh` | 一键构建 |

构建：`npm install katex @fontsource/noto-serif-sc @fontsource/noto-sans-sc`，`pip install pymupdf pillow matplotlib`，然后 `./make.sh`。
写法：`$...$` 公式，`{{p:s3.4}}` 引用页码，`{{ix:English|中文}}` 进索引，`[L3 p37]` 讲义页码标签。
