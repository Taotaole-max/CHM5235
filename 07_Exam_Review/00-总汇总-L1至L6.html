第 2 讲　量子力学基础与 Hartree–Fock 理论

详解：L02 完整讲义
必背一句话
何时需要量子力学ΔE ≫ kBT（室温 ≈ 2.5 kJ/mol）；电子跃迁是 100–400 kBT
Ĥψ = Eψ本征值方程；量子化来自边界条件
[x̂, p̂] = iħ不对易 → 不能同时确定 → 不确定性原理
厄米本征值必为实 → 可观测量的算符必须厄米
Born 解释|Ψ|² 是概率密度，Ψ 本身不可观测
五大公设①Ψ 描述状态 ②可观测量↔算符 ③测量值只能是本征值 ④期望值 = Σ|bn|²an ⑤含时方程
三个量子数[Ĥ,L̂²] = [Ĥ,L̂z] = 0（球对称）→ n, l, m；节面总数 n−1
泡利P̂12Ψ = −Ψ；Slater 行列式自动满足
J vs KJ：经典库仑，所有电子对都有；K：纯量子，仅同自旋，降低能量
Hund 规则E(³S) − E(¹S) = −2K：同自旋空间波函数反对称 → Fermi 空穴
BO 近似核不动 → 势能面的概念由此而来
闭壳层 HF 能量E = 2ΣHi + ΣΣ(2Jij − Kij) + VNN
RoothaanFC = SCε；S 因为基函数不正交；F 依赖 C → SCF 迭代
RHF vs UHFH₂ 解离：RHF 锁 50% 离子项（高 ~140 kcal/mol）；UHF 对但自旋污染

第 3 讲　软件工具、变分原理、SCF 实现与基组

详解：L03 完整讲义
必背一句话
变分原理Etrial ≥ Eexact；只保证能量，不保证性质和能量差
变分四步写 ψ(α) → 算 E(α) → dE/dα = 0 → 代回
行列式能量（动笔题）E = Σhii + Σi<j(Jij − Kij)；两个双占据轨道之间：4J − 2K
KoopmansIE ≈ −εHOMO；冻结轨道；HF 误差抵消所以准；DFT 不适用
B 原子2p 三重简并 → 需 3 个行列式 → 静态相关 → CASSCF
自旋污染看 ⟨Ŝ²⟩ vs S(S+1)：0 / 0.75 / 2.00
密度矩阵Dγδ = Σ占据cγjcδj；tr(DS) = N
三种轨道正则（F 对角）· 天然（D 对角）· 定域；能量密度全相同
双电子积分~N⁴/8 个 → direct SCF 现算；RI 降到 N³
收敛技巧阻尼 · 能级移动（可能卡局部极小）· DIIS（误差 FDS−SDF）· 二次收敛
GTO vs STOGTO 核处无尖点、衰减太快，但高斯乘积定理→积分解析
基组命名6-311++G(3df,3pd)；aug-cc-pVnZ；极化 = l+1，弥散 = 阴离子/弱相互作用
BSSE基函数互借 → 高估结合；Counterpoise + 幽灵原子
虚频0 个 = 极小点；1 个 = 过渡态；≥2 = 重做

第 4 讲　电子相关方法

详解：L04 完整讲义
必背一句话
相关能Ecorr = Eexact − EHF < 0；~1% 总能量，但与键能同量级
静态 vs 动态静态：单行列式原理上不够（简并/断键）→ CASSCF；动态：瞬时躲避 → MP2/CC
Brillouin⟨ΨHF|Ĥ|Ψir⟩ = 0 → 单激发不直接混入、MP2 无单激发项
Ne 权重参考 0.96 · 双激发 0.034 · 单激发 0.001 → 双激发是主力
CI 修 H₂Ψ = (a₀+a₁)[离子] + (a₀−a₁)[共价]；R→∞ 时 a₁ = −a₀
尺寸一致性截断 CI ✘（缺 TATB 交叉项）；CC ✔（eTA+TB = eTAeTB）
CCΨ = eTΨ₀；½T₂² 隐含四激发；非变分；CCSD(T) 黄金标准
MP2Σ|⟨ij||ab⟩|²/(εi+εj−εa−εb)；简并时分母→0 发散
MPn 不收敛Be：MP7 = 100.15%，会过冲
标度HF N⁴ · MP2 N⁵ · CCSD N⁶ · CCSD(T) N⁷ · FCI N!
CBSHF 指数收敛；相关能 A/n³ 慢收敛（电子尖点）

第 5 讲　密度泛函理论 (DFT)

详解：L05 完整讲义（每页附原图）
必背一句话
密度ρ(r) 只有 3 个变量，与 N 无关；N = ΣPμνSμν
外势T̂、V̂ee 普适，只有 Vext 区分分子
HK 第一定理基态 ρ ⟺ Vext，一切性质是 ρ 的泛函（反证法证明）
HK 第二定理E[ρ] = FHK[ρ] + ∫ρVext，在 ρ₀ 处最小
泛函函数 → 数；δ(∫ρν)/δρ = ν
Kohn–Sham无相互作用替身重现 ρ；[−½∇² + VH + Vext + Vxc]φ = εφ；只有 Vxc 未知
HF vs KSHF：交换精确非局域、无相关；KS：交换+相关都近似但局域
Jacob 阶梯LDA(ρ) → GGA(∇ρ) → meta-GGA(τ) → 杂化(HF 交换) → 双杂化(MP2)
B3LYP20% HF 交换，3 个经验参数 → 严格说非 ab initio
SIEHF 中 Jii=Kii 抵消；近似 DFT 抵消不净 → 过度离域、能垒低、带隙小
范围分离erf 拆 1/r12，长程 HF 交换 → 修 CT 激发、SIE
色散局域泛函看不到远处 → D3：−ΣC6/R⁶ × 阻尼
不适合 DFT双自由基、开壳层过渡金属、断键；镧系用 4f-in-core
磁耦合Ĥ = −2JŜ₁·Ŝ₂ → ET = −J/2，ES = 3J/2，ΔEST = −2J
BS-DFT单重态需 2 个行列式 → 算 |αβ|；J = (EBS−EHS)/(⟨S²⟩HS−⟨S²⟩BS)
TD-DFT线性响应，极化率极点 = 激发能；绝热近似；CT/Rydberg/双激发差

第 6 讲　波函数分析、相对论效应与溶剂化模型

详解：L06 完整讲义（每页附原图）
必背一句话
Mulliken 电荷QA = ZA − Σμ∈A(PS)μμ：同原子全给、跨原子平分（讲义 p5 式中的 ½ 多乘了）
Mulliken 的毛病布居 >2 或负；平分无依据；依赖基组；不重现多极矩
四种电荷Mulliken/Löwdin（基函数）· Bader（零通量面 ∇ρ·n=0）· Hirshfeld（自由原子密度比例）
原子电荷 vs 静电势电荷不是可观测量；MEP 是（红=负=富电子，蓝=正）
键级qAB = 2ΣΣPS（重叠布居）；Mayer 键级更接近 1/2/3
轨道定域化行列式幺正不变；Boys（质心远）· ER（自排斥大）· PM（原子布居集中，保 σ/π）；定域轨道没有轨道能
相对论1s 速度 ≈ Z/137 c；Au γ≈1.22；s/p 收缩（直接）、d/f 扩张（间接）
Dirac 方程时空都一阶 → 4×4 矩阵、4 分量（大/小分量）、自旋自然出现、正电子态
Pauli 哈密顿量质量-速度 −p⁴/8m³c² + SOC s·l + Darwin δ(r)；标量相对论 = 质量-速度 + Darwin
实用相对论ECP（便宜）· DKH2 / ZORA / X2C（全电子，需专用基组）；1C/2C/4C
溶剂模型显式（氢键、贵）· 隐式 PCM（只有 ε）· 混合
Born / Onsager−(1−1/ε)q²/2R；−[(ε−1)/(2ε+1)]μ²/R³；ε>20 后饱和
PCM原子球空穴 + 表面电荷 σ = −[(ε−1)/4πε]∂φ/∂n，与溶质自洽；ΔG = 空穴 + 色散 + 静电
Poisson–Boltzmann含可移动离子；线性化 → Debye 屏蔽 e−κr/r
色散二阶微扰中两分子同时激发的项 → 需双激发 → HF/常规 DFT 为零；MP2 需 CP、会高估 π 堆积
UV/VisFranck–Condon：垂直吸收 > 绝热 > 垂直发射；跃迁偶极为零即禁阻

高频概念题（一句话答案）

问题答
HF 丢了什么？电子相关：平均场里电子看不到彼此的瞬时位置
J 和 K 的区别J 经典库仑、所有对都有；K 纯量子、仅同自旋、降能量
为什么三重态低于单重态同自旋空间波函数反对称 → 电子不重合 → 排斥小（−2K）
Roothaan 为什么有 S原子轨道基函数不正交
HF 为什么要迭代Fock 算符依赖轨道本身
RHF 为什么 H₂ 解离错单行列式锁死 50% 离子项
静态 vs 动态相关静态：参考态本身错（简并）→ CASSCF；动态：细节缺失 → MP2/CC
为什么 CISD 不尺寸一致缺两片段各双激发的四激发交叉项
为什么 CC 尺寸一致eA+B = eAeB，波函数自动分解
MP2 为什么无单激发Brillouin 定理
MP2 什么时候崩近简并，分母趋零
为什么用 GTO高斯乘积定理 → 积分解析
BSSE 是什么基函数互借 → 结合能偏大；Counterpoise
Koopmans 的假设冻结轨道；HF 靠误差抵消，DFT 不适用
HK 两个定理① ρ 唯一决定 Vext ② E[ρ] 在 ρ₀ 处最小
KS 的核心思想无相互作用替身体系重现同一个密度，未知全放进 Vxc
DFT 是 ab initio 吗原理上是；实用泛函含经验参数，严格说不是
自相互作用误差近似 Exc 不能抵消 Jii → 过度离域
DFT 为什么没色散泛函局域，看不到远处关联涨落 → D3
为什么要 BS-DFT开壳层单重态要 2 个行列式，KS 只有 1 个
变分原理的限制只保证能量上界，不保证其他性质与能量差
虚频的意义0 = 极小点，1 = 过渡态
